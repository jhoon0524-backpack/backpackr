# 결정 기록

왜 이렇게 만들었는지 적는다. 코드는 "무엇"을 보여주지만 "왜"는 보여주지 않는다.
기록이 없으면 다음 세션의 AI 가 같은 고민을 반복하거나, 이유를 모른 채 결정을 뒤집는다.

**언제 쓰나:** 나중에 바꾸기 어려운 선택을 했을 때만. 스택, 데이터 구조, 외부 서비스, 구조를 나누는 방식.
변수 이름이나 작은 구현 방식은 적지 않는다.

**고칠 때:** 지난 기록은 지우지 않는다. 새 항목을 쓰고 옛 항목의 상태를 "대체됨 → N번" 으로 바꾼다.

## 1. 파일 하나 안에서 규칙과 화면을 나누고, 규칙만 Node 로 검사한다
- **날짜:** 2026-09-25
- **상태:** 채택
- **상황:** 기획서가 "HTML 파일 1개, 외부 라이브러리 없음" 을 요구한다. 그런데 AI 가 사람 없이 돌려면
  결과를 기계가 판정할 검사가 있어야 한다. 화면은 브라우저 없이는 검사하기 어렵다.
- **결정:** `index.html` 안에 `<script id="core">` 를 따로 두고 규칙(이동·피해·AI·턴·승패)을 전부 넣는다.
  core 는 화면(DOM)과 `Math.random` 을 직접 쓰지 않는다. `tests/` 가 파일에서 core 를 꺼내 Node 로
  실행하고 `node --test` 로 검사한다.
- **이유:** 파일 1개 조건을 지키면서 설치 없이(Node 만으로) 규칙을 자동 검사할 수 있다.
  기획의 핵심(상성·피해·AI)이 규칙 쪽에 몰려 있어 여기를 잡으면 대부분을 잡는다.
- **포기한 대안:**
  - 규칙을 별도 `.js` 파일로 분리 — 검사는 쉬워지지만 "파일 1개" 조건을 어긴다
  - 브라우저 자동화(Playwright)로 화면까지 검사 — 설치가 필요하고 PC 마다 환경이 달라 루프가 자주 멈춘다.
    대신 화면은 사람이 확인한다

## 2. 맵과 유닛 배치를 "스테이지 데이터"로 분리한다
- **날짜:** 2026-09-25
- **상태:** 채택
- **상황:** v0.1 은 1장 맵(8×8)과 유닛 시작 위치가 코드에 박혀 있었다. 맵 에디터와 2장을 만들려면
  맵 크기·지형·배치가 바뀌어야 한다.
- **결정:** 한 전투를 `{ v, name, rows, cols, map, allies:[{id,r,c}], enemies:[{type,r,c}] }` 데이터로 표현한다.
  유닛 수치는 아군 `id`·요괴 `type` 별 정의표에 따로 둔다. `newBattle(stage)` 가 이 데이터로 전투를 만들고,
  지형 조회는 전투 상태(`state.map`)를 본다. 맵 에디터의 "맵 코드"도 같은 모양이다.
- **이유:** 에디터에서 만든 코드를 그대로 새 장으로 넣을 수 있다. 수치(기획)와 배치(맵)를 따로 고칠 수 있다.
- **포기한 대안:**
  - 장마다 코드를 복사해 따로 만들기 — 규칙이 장마다 갈라져 테스트가 장 수만큼 늘어난다
  - 수치까지 스테이지에 넣기 — 에디터가 커지고, 같은 유닛이 장마다 다른 수치가 되기 쉽다

## 3. 5장부터 그림은 `assets/` 의 개별 파일로 불러온다 (게임 파일은 계속 index.html 1개)
- **날짜:** 2026-09-27
- **상태:** 채택 (Game Director 지시 ART-PHASE-A-01)
- **상황:** 5장에 실제 캐릭터·NPC·귀물 그림(WebP 12개, 약 700KB)을 넣는다. 1번 결정의 "HTML 파일 1개" 조건과 부딪힌다.
- **결정:** 게임 규칙·화면 코드는 그대로 `index.html` 하나. 그림만 `joseon-exorcist/assets/` 에 개별 파일로 두고
  상대 경로(`assets/...`)로 불러온다. 바깥 주소·라이브러리는 여전히 없다(`tests/html.test.mjs` 검사 그대로).
  그림을 못 불러오면 기존 이모지로 돌아가 게임은 멈추지 않는다. 지금은 5장에만 쓴다.
- **이유:** 지시서가 파일 이름 그대로 복사해 쓰라고 정했다. index.html 에 base64 로 넣으면 파일이 3배 가까이 커지고 그림 교체가 어렵다.
- **영향:** Vercel 배포에 `assets/` 가 함께 올라간다(`.vercelignore` 에서 빼지 않음). claude.ai 시험판(아티팩트)은
  index.html 한 파일만 올리므로 그림 없이 이모지로 보인다.
- **포기한 대안:** base64 로 index.html 에 넣기 — 파일 1개는 지키지만 무겁고, 그림 교체 때마다 코드가 바뀐다
- **추가 (2026-09-27, ART-PHASE-C-01):** 1장도 같은 방식으로 그림을 쓴다. 어느 장에서 어떤 종류의 그림을 쓸지는 `ART_ALLOW` 장별 목록으로 정한다 (목록에 없으면 이모지)
