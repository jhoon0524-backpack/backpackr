# qa-scripts — 화면 회귀 확인 스크립트

`node --test` 에는 들어가지 않는다 (브라우저가 필요한 화면 확인용). 이 폴더에는 지금 1장 환경 회귀만 있고, 나머지 화면 확인 스크립트는 저장소 밖에서 돌렸다 (결과는 각 `QA-*.md`).

- `env-ch1-regression.js` — 1장 환경 회귀. 실행 방법은 파일 머리 주석
- `lib/seamcheck.js` — 환경 타일 이음새 판정. 기획자 확정 기준(2026-09-27): **원본 픽셀 완전 연속이 아니라, 실제 게임 표시 크기에서 인위적인 반복 세로 이음새가 눈에 띄지 않는가**
  - 칸 끝에 붙은 급격히 어두운 띠 → 게임 크기에서 칸 사이 틈(2px, 반올림 0.1px 허용)보다 넓으면 이음새
  - 칸 끝에 붙지 않은 어두운 선(양옆에 뚜렷이 밝은 열, 선과 칸 끝 사이가 어둡지 않음) → 틈과 떨어져 모든 칸에 반복되므로 이음새
  - 검증: 지금 쓰는 그림 13개(1장 6 · 2장 7)는 모두 통과, 지금까지 반려된 그림 13개(1장 첫 흙·서낭당·바위·약수터, A2 바위·약수터, 2장 V1 7개)는 모두 걸림 — 26/26
