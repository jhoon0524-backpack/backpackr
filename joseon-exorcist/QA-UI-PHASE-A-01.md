- 성문 칸을 처음부터 주홍으로 칠했더니 운반자 등장 전부터 정답 길처럼 보였다 → 평소엔 먹색, 추격 중 향하는 성문만 주홍
- 조회 카드가 길어 360×740 에서 화면 밖으로 밀렸다 → 두 줄로 줄이고, 누르면 소속·수련 설명까지
- 성문 색을 바꾸면서 2장 탈출로(🌲)까지 흐려졌다 → 2장은 예전 녹색 그대로, 5장 성문만 새 색
- 확인 스크립트 문제 2건 (이동 뒤 메뉴가 열린 상태에서 다른 아군을 눌러 선택이 안 됨 = 규칙대로 / 조회 카드 머리글 읽는 위치) — 게임 코드 문제 아님
