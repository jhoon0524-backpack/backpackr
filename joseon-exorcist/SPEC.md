# 조선 퇴마전 — 벽사청 루트 v0.1 (1장 '흑린 토벌' 전투 1판)

원본 기획서를 AI 작업용으로 옮긴 것이다. 원문에 없던 것을 정한 곳은 **(보충)** 으로 표시했다.
보충 항목은 2026-09-25 기획자가 그대로 확정했다. 바뀌면 이 문서를 먼저 고친다.

## 1. 개요
- **무엇:** 조선 배경 요괴 퇴치 턴제 격자 전술 게임(삼국지 조조전식)의 1장 전투 한 판.
- **누가 쓰나:** 기획 검증용. 폰(세로 화면)과 PC 브라우저에서 파일 하나를 열어 플레이한다.
- **성공 기준:**
  - 시작 대사 → 전투 → 승리/패배 화면 → [다시하기] 로 처음부터 재시작, 이 한 바퀴가 끊김 없이 돈다
  - `node --test tests/` 가 전부 통과한다 (규칙 계산이 이 문서·하위 스펙과 일치)
  - 폭 360px 세로 화면에서 스크롤 없이 8×8 맵 전체가 보인다
  - 외부 파일·라이브러리·네트워크 요청이 0개다

## 세계관 (구현 참고용)
- 벽사청: 조정 비밀 관청. "요괴는 베어서 끝낸다." ← 플레이어 세력
- 청운 도문: 산속 도사 문파. "봉인해서 힘으로 쓴다."
- 신당회: 만신(무당) 연합. "원한을 풀어 보낸다."
- 요괴 세력: 이무기 '흑린'이 수장. 여의주로 승천하려 함.
- 1장: 흑린이 마을을 삼키려 하자 세 세력이 처음으로 손잡는다.
  다른 세력 소속 동료는 '객장'(빌려 쓰는 장수)으로 함께 싸운다.
- 등장인물은 모두 가상 인물이다. **실존 인물 이름을 쓰지 않는다.**

## 3. 기술 규격
- **스택:** HTML 파일 1개(`index.html`), 바닐라 JS, 외부 라이브러리 없음
- **그래픽:** 이모지 + 색칸만. 밤 마을 느낌의 어두운 톤
- **입력:** 모바일 터치와 PC 클릭 둘 다
- **데이터 저장:** 없음 (새로고침하면 처음부터)
- **외부 연동:** 없음
- **배포:** 없음. 파일을 브라우저로 연다
- **검사:** `tests/` 의 Node 내장 테스트(`node --test`). 설치할 패키지 없음

## 4. 경계 (v0.1 에서 만들지 않는 것)
- 레벨업, 품계 승진, 아이템, 저장, 사운드, 요괴 스킬, 2장 이후 스토리
- 공적 → 품계 승진 → 출전 인원 증가는 2장부터. 지금은 공적 숫자만 센다

## 5. 되돌릴 수 없는 지점
- 없음. 돈·메일·데이터 삭제가 없는 오프라인 파일이다
- 대신 **기획 수치와 대사는 AI 가 바꾸지 않는다** (`CLAUDE.md` 4장)
