# v0.8 개인 성장 — 수련 (기획 초안)

- **상태: 초안. 기획자 확인 전에는 코드를 만들지 않는다.** 방향은 기획자 메모(2026-09-26), 구체 규칙·숫자는 AI 제안 **(제안)**
- 목표: "공격 +2"가 아니라 **플레이 방식이 달라지는** 성장. 조조전의 "누구를 어떻게 키울까"를 처음 고민하게 한다
- 공적 → 품계 → 관군(벽사청 조직 성장)은 그대로 둔다. 수련은 그 옆에 붙는 **인물 성장**이다

## 0. 지금 게임의 사실 (설계 전제)

| 사실 | 설계에 주는 뜻 |
|---|---|
| 네 인물의 기술(벽사검·파사궁·축지격·화염부)은 **모두 같은 규칙** — "자기 속성으로 한 번 공격" | 지금은 인물 차이가 수치·속성뿐. 수련이 **첫 번째 역할 차이**가 된다 |
| 행동 순서는 "이동 → 행동(공격·기술·대기·봉인 복구)". 행동하면 그 차례 끝 | "행동 뒤 추가 이동"은 새 규칙이 된다 (집행·벽사가 같은 틀을 공유) |
| 3장 조사는 **칸에 들어서면 자동** (행동 아님). 봉인 복구는 행동 | 벽사의 "조사 뒤에도 이동"은 사실상 이미 된다 → "봉인 복구 뒤 이동"이 핵심 |
| 여울·소운은 **청운 도문 객장**. v0.9 폐사찰에서 도문이 벽사청과 충돌 예정 | 객장을 벽사청 본진에서 수련시키는 것이 이야기와 맞는지 결정 필요 (결정 2) |
| **이미 깬 장을 다시 할 수 없다** (출동은 다음 장만) | 3장 뒤에 수련을 열면 v0.8 안에서는 써 볼 전투가 없다 (결정 1) |
| 기획자 플레이에서 품계 성장을 **전혀 못 느꼈다** (proposal-growth.md) | 수련은 전투 중에 **눈에 보이게** 발동해야 한다 (4장) |

## 1. 수련 방향 — 인물마다 둘 중 하나 **(규칙·숫자 제안)**

원칙: 한 인물 = 한 번 선택, 규칙 한 줄. 발동하면 칸 위에 이름이 뜬다 ("집행!").

| 인물 | 방향 | 규칙 (제안) | 바뀌는 플레이 | 빛나는 장 |
|---|---|---|---|---|
| 윤무겸 | **집행** | 벽사검으로 적을 쓰러뜨리면 **1칸 더 이동**할 수 있다 (기획 예시 그대로) | 마무리 순서를 계산한다 — 막타 뒤 다음 적 앞으로, 또는 뒤로 빠짐 | 1장 토벌 |
| | **벽사** | **봉인 복구 뒤에도 이동**할 수 있다 (남은 이동력만큼) | 봉인 칸을 "들렀다 빠지는" 동선. 원귀가 몰려오기 전에 이탈 | 3장 봉인 |
| 한결 | **사수** | **이번 차례 움직이지 않았으면** 파사궁 사거리 2 → 3 | 좋은 자리를 잡고 버티는 포대 역할 | 넓은 맵 |
| | **추적** | 파사궁에 맞은 적은 **다음 차례 이동력 −2** | 도주하는 적(달래형)·봉인으로 달리는 원귀를 붙잡는다 | 2장 추격 |
| 소운 | **부법** | 화염부가 대상 **옆 칸의 적 하나에게 번진다** (절반 피해, 아군·중립 제외) | 적이 뭉친 곳을 노린다 | 무리 전투 |
| | **진법** | 기술 대신 **결계**: 거리 2 안의 빈 칸 하나를 **다음 아군 차례까지 적이 못 지나간다** (기력 4) | 길목·봉인 칸·탈출로를 막는 판단 | 2장 탈출로, 3장 봉인 |
| 여울 | **기습** | **3칸 이상 이동한 뒤** 축지격을 쓰면 피해 ×1.5 | 멀리서 뛰어드는 돌격. 여울의 이동 5 가 의미를 갖는다 | 후방의 약한 적 |
| | **교란** | 축지격에 맞은 적을 **1칸 밀어낸다** (3장 금역과 같은 밀기 규칙) | 봉인 칸·탈출로에서 적을 떼어 낸다 | 3장 봉인, 2장 |

- 짝마다 "화력 쪽 / 판단 쪽"으로 나눴다. 어느 쪽도 정답이 아니게 하는 것이 목표
- 새 규칙 틀은 4개뿐: **행동 뒤 추가 이동**(집행·벽사), **조건부 사거리·피해**(사수·기습), **적 이동 방해**(추적·교란), **칸 효과**(부법 번짐·진법 결계). 한 틀을 두 인물이 나눠 써서 코드와 설명이 작아진다
- 관군·달래는 수련 없음

## 2. 수련점 — 언제, 몇 개

- 지역 상태처럼 **깬 장에서 계산**한다 (따로 세는 숫자를 저장하지 않음). 저장하는 것은 "누가 무엇을 골랐나"뿐
- 선택은 되돌리지 않는다 (확인창 한 번) **(제안 — v0.8 은 단순하게. 되돌리기는 필요하면 v1.0 장비와 같이)**
- 몇 개를 언제 주느냐는 결정 1

## 3. 본진 화면 — [인물]

월드맵 벽사청 카드: 지금 `품계 · 공적 · [벽사록]` 옆에 **[인물]** 추가. 수련점이 있으면 벽사청 노드와 [인물] 버튼에 작은 표시(●).

인물 목록 → 한 명을 누르면 (기획 모양 그대로):

```
🗡️ 윤무겸
벽사청 종사관
기술  벽사검 (금)

다음 수련            수련점 1
◯ 집행 — 벽사검으로 적을 쓰러뜨리면 1칸 더 이동
◯ 벽사 — 봉인 복구 뒤에도 이동
            [수련한다]
```

- 수련한 뒤: "수련 · 집행" 으로 바뀌고 다른 쪽은 흐리게
- 전투 정보창(유닛을 눌렀을 때)에도 "수련 · 집행" 한 줄
- 장비·인벤토리·경험치 없음

## 4. 느끼게 하기 (품계를 못 느낀 교훈)

- 수련점을 받는 순간: 승리 화면에 "수련점 +N — 본진에서 인물을 수련할 수 있다"
- 전투 중 발동: 칸 위에 수련 이름 ("집행!", "결계") — 지금의 기술 이름 표시와 같은 방식
- 이동·사거리가 바뀌는 수련(집행·벽사·사수)은 파란 칸/빨간 칸이 **실제로 달라져 보인다**

## 5. 검증

- `node --test`: 수련 8종 각각 발동 조건·효과·발동하지 않는 경우
- 시뮬레이션: 기존 1~3장 결과가 **수련 없이 그대로**인지 (회귀 없음)
- 헤드리스 크롬 360×740: [인물] 화면, 선택·확인창, 발동 표시
- 개발자 주소(`?dev=1`)에서 수련을 켜고 3장을 해 볼 수 있게 (결정 1 에 따라)

## 6. 기획자 결정이 필요한 것

1. **수련을 언제 여나** (가장 중요)
   - A. **3장 완료 → 수련점 2** (4명 중 2명만): 기존 1~3장 밸런스를 건드리지 않음. "누구를" 고민이 생김. 대신 v0.8 에서 수련을 쓸 전투가 없다 → 개발자 주소로만 3장 체험, 실제 사용은 v0.9 4장 **(추천)**
   - B. 1·2·3장 완료마다 수련점 1: 1장 뒤부터 바로 써 봄 (품계를 못 느낀 문제에도 도움). 대신 2·3장 밸런스가 바뀌고 "3명 게이트"와 부딪힌다
   - C. 3장 완료 → 4명 모두 1회: 고민은 "어느 방향"만 (누구를 고민 없음)
2. **객장(여울·소운)도 벽사청 본진에서 수련하나** — v0.9 에서 도문과 충돌하면 이 둘은 어떻게 되나? (포함 추천. 이야기상 "도문에서 배운 것"으로 표기할지 결정)
3. **목업의 "파사"** — 윤무겸 아래 "벽사검 / 파사"의 파사가 무엇인지 (지금 윤무겸의 기술은 벽사검 하나. 한결의 기술이 파사궁)
4. 위 8개 규칙과 숫자(1칸, 사거리 3, −2, 절반, ×1.5)
5. 선택 되돌리기 없음으로 가도 되나

## 하지 않는 것
레벨·경험치 막대, 장비·인벤토리, 스탯 +N 성장, 두 번째 수련, 관군·달래 수련, 4장, 기존 1~3장 수치 변경.
