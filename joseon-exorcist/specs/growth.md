# v0.8 개인 성장 — 수련 (확정)

- 기획자 확정 2026-09-26. **(보충)** 은 구현하며 AI 가 정한 곳 (기획자 확인 전)
- 목표: "공격 +2"가 아니라 **플레이 방식이 달라지는** 성장. 4장 전에 처음으로 "누구를 어떻게 키울까"를 고민하게 한다
- 공적 → 품계 → 관군(벽사청 조직 성장)은 그대로. 수련은 그 옆의 **인물 성장**
- 순서: v0.8 개인 성장(기반) → v0.9 4장 폐사찰·도문 본격 등장(첫 실전) → v1.0 장비·출전 편성. v0.8 과 v0.9 는 한 묶음

## 1. 수련 해금
- **3장을 깨면 수련점 2** → 4명 중 2명만 첫 수련. 1~2장에서는 0 (이미 검증한 1~3장 밸런스를 건드리지 않는다)
- 수련점은 깬 장에서 계산한다 (따로 저장하지 않음). 저장은 "누가 무엇을 골랐나"뿐 (`progress.training`)
- **한 사람에 하나만.** 2점을 한 사람에게 몰아 A·B 둘 다 고르는 것은 금지
- 여울·소운도 수련한다. "벽사청이 객장을 훈련시킨다"가 아니라 **지금 일행의 인물이 각자 자기 기술을 갈고닦는다**
- 새 기술을 만들지 않는다 (윤무겸 = 벽사검, 한결 = 파사궁. "파사"는 없음)
- 이름은 당분간 "수련점" (수련 기회·전공·깨달음 등은 세계관 정리 때 검토)

## 2. 수련 8종 (최종안)

| 인물 | 수련 | 규칙 | 역할 문구 (기획자 확정) |
|---|---|---|---|
| 윤무겸 | 집행 | 벽사검으로 적을 쓰러뜨리면 1칸 재이동 | 적을 베며 전선을 뚫는 선봉 |
| 윤무겸 | 벽사 | 봉인 복구 같은 임무 행동 뒤 1칸 재이동 | 괴변의 핵심을 직접 처리하는 임무 수행자 |
| 한결 | 사수 | 이동하지 않은 차례의 파사궁 사거리 2→3 | 멀리서 핵심 표적을 노리는 저격수 |
| 한결 | 추적 | **[견제사격]** 행동 추가: 기력 0, 기본 공격 사거리, 기본 공격 피해의 50%, 맞은 적 다음 차례 이동 −2 (v0.9.3) | 도망치는 적의 발을 묶는 추격자 |

| 여울 | 기습 | 3칸 이상 이동 뒤 축지격 피해 ×1.5 | 거리를 벌렸다 파고드는 돌격수 |
| 여울 | 교란 | **[밀어내기]** 행동 추가: 기력 0, 사거리 1, 기본 공격 피해의 50%, 여울 반대쪽으로 1칸 (v0.9.3) | 적의 위치를 흐트러뜨리는 전장 교란자 |

### 세부 규칙 (기획자 고정)
- **재이동(집행·벽사):** 공격·임무 행동은 다시 못 함. 이동만 1칸. 그 뒤 턴 종료(그 인물 행동 끝)
- **추적 (v0.9.3 기획자 지시 — 적중 시 자동 발동 폐기, 능동 행동으로):** [견제사격] 을 쓰면 그 인물 행동 끝. 적대 대상에게만. 이동 −2, 중첩 안 됨, 최소 이동력 1, 맞은 적의 다음 차례가 끝나면 해제. 파사궁 = 제거, 견제사격 = 통제
  - 이유: 귀화 HP 12 < 기술 피해 13~19 라 "맞고 살아남은 적"이 거의 없어 사람 플레이 2판에서 발동 0회. 수련은 조건부 보너스가 아니라 **새 선택지**여야 한다
- **부법:** 옆 적이 여럿이면 플레이어가 1명 선택. 자동 선택 금지
- **진법:** 지속 2턴. 동시에 1개. 적은 결계 칸에 들어갈 수 없고 아군은 지나감. 출현 칸·봉인 칸·목표 칸에는 설치 불가. 새 결계를 놓으면 기존 결계 제거
- **교란 (v0.9.3 — 능동 행동으로):** [밀어내기] 를 쓰면 그 인물 행동 끝. 적대 대상에게만. 밀릴 칸이 바위·맵 밖·다른 유닛·결계면 밀리지 않고 피해만. 축지격 = 돌입·제거, 밀어내기 = 위치 조작. 기본 공격·축지격에는 더 이상 밀기 없음

- 역할 문구 원칙: 능력 효과를 다시 설명하지 않고, **이걸 고르면 전투에서 어떤 역할을 맡는가**를 한 줄로
- 역할 정리: 윤무겸 = 전진 / 임무, 한결 = 저격 / 추적, 소운 = 광역 / 공간 통제, 여울 = 돌격 / 위치 조작
- **품계 = 내 부대가 강해진다 / 수련 = 내 인물이 달라진다.** 이 구분은 앞으로도 깨지 않는다

### 공통 원칙 (기획자 확정 2026-09-26)
- **강제 이동(밀기)은 도착 즉시 발동하는 탈출·패배 조건을 일으키지 않는다.** 예: 교란으로 달래를 탈출로 칸에 밀 수는 있지만 그 때문에 바로 지지 않는다. 달래는 자기 차례에 행동한 뒤 탈출한다. 앞으로 밀기 기술이 늘어도 같은 규칙
- **수련 효과는 적대 대상에게만.** 특정 유닛(서낭신) 예외가 아니라 편으로 판단 — 중립 신령·NPC 는 자동으로 빠진다

### 구현하며 정한 것 (기획자 승인 2026-09-26)
- 집행: **적**을 쓰러뜨릴 때만 (서낭신 같은 중립은 아님). 마지막 봉인·보스 격파로 전투가 끝나면 재이동 없음
- 재이동: 제자리를 누르면 쓰지 않고 끝. [턴 종료]를 누르면 쓰지 않고 넘어감. 재이동으로 조사 지점에 서면 조사된다 (조사는 행동이 아니라 도착하면 자동이므로)
- 사수: 제자리 "이동"은 움직이지 않은 것. 기본공격 사거리는 그대로 2
- 추적·부법·교란·집행: 적대 대상에게만 (위 공통 원칙). 부법은 대상과 같은 편의 옆 유닛에게만 번진다
- **(보충 v0.9.3)** 견제사격·밀어내기 피해 = 기본 공격 피해 × 0.5 반올림, 최소 1. 설명 문구 "[견제사격] 기력 없이 약하게 쏜다 (기본 공격 피해의 절반). 맞은 적은 다음 차례 이동력 −2 (최소 1)." / "[밀어내기] 기력 없이 옆의 적을 약하게 치고 (기본 공격 피해의 절반) 1칸 밀어낸다." 버튼 아래 작은 글씨 "이동 −2" / "1칸 밀기", 청록색 (기술 금색과 구분). 플레이 기록 `trainingActivations.chujeok/gyoran` = 사용 횟수
- 부법: 옆 적이 하나면 고를 것이 없으므로 그 적에게 바로 번진다. 번진 피해는 그 적 기준 화염부 피해의 절반(반올림, 최소 1)
- 진법: 기력 4 (기술과 같음), 소운에게서 거리 2 안 (승인. v0.9 에서 볼 것: 결계를 아껴 두기만 해서 사용률이 너무 낮은가 → 그때 기력만 조정). "목표 칸" = 3장 조사·봉인·원한 지점, 2장 탈출로. 지속 2턴 = 놓은 턴과 다음 턴의 적 차례, 그다음 아군 차례 시작에 사라짐. 결계 칸은 금역 밀기·원귀 재등장 자리에서도 빠진다
- 교란: 결계 칸으로도 밀리지 않음. 탈출로 칸으로는 밀 수 있다 (위 공통 원칙)
- 기습: 실제로 걸은 칸 수(돌아간 길 포함) 3 이상

## 3. 본진 [인물]
- 월드맵 벽사청 카드: `📖 벽사록 · 인물 · 현재 임무`. 수련점이 남았으면 카드에 "수련점 N", [인물] 버튼과 벽사청 노드에 붉은 점
- 인물 목록(윤무겸·한결·소운·여울) → 한 명을 누르면: 이름 / 소속·칭호 / 기술 / 다음 수련 ◯ A ◯ B (각각 이름·역할 문구·규칙) / [← 인물] [수련한다]
- 방향을 누르면 ◉ 로 고르고 [수련한다] → 확인창:
  > 윤무겸 — 「집행」을 수련하시겠습니까?
  > 한 번 선택한 수련은 현재 버전에서는 되돌릴 수 없습니다.
  >
  > [수련한다] [취소]
- 되돌리기는 플레이어에게 주지 않는다. "절대 초기화 불가" 같은 세계관 규칙으로 만들지 않는다. 개발자 주소(`?dev=1`) 지도의 [수련 초기화]로만 되돌린다
- 장비·인벤토리·경험치 없음

## 4. 전투에서 보이게
- 발동하면 인물 칸 위에 수련 이름 ("집행!", "진법!")
- 정보창: "수련 · 집행 — 규칙", 추적에 걸린 적은 "추적에 걸림 — 다음 차례 이동 −1"
- 재이동·결계·부법 선택 중에는 맵 아래에 무엇을 고르는지 ("집행 — 1칸 더 움직일 수 있다 (제자리를 누르면 끝)")
- 결계 칸: 파란 테두리 + "결계" 표시, 누르면 설명 카드
- 3장 승리 화면: "수련점 +2 — 본진에서 인물을 수련할 수 있다"
- 개발자 주소: 3장을 깬 저장이면 지도에 [3장 수련 시험] (수련을 켜고 3장을 다시 해 본다. 결과는 진행에 영향 없음)

## 5. 성공 기준
- 선택 화면이 작동하는 것만으로는 성공이 아니다. **4명의 카드만 보고** "윤무겸을 세게 만들까, 임무 수행자로 만들까?", "한결을 저격수로 만들까, 추격 담당으로 만들까?"처럼 같은 인물의 두 플레이 방식이 머릿속에 그려져야 한다
- v0.9 폐사찰에서 측정: 어떤 수련을 골랐나(`playlog.training`), 몇 번 발동했나(`trainingTriggers`, `trainingEvents`), 발동 때문에 행동이 달라졌나(발동 턴 전후 이동·대상)

## v0.9 폐사찰로 넘길 것
- 4장 설계에는 **수련을 골랐기 때문에 행동이 달라지는 상황**을 반드시 넣는다. 새 스테이지만 만들면 v0.8 의 의미가 없다

## 하지 않는 것
레벨·경험치 막대, 장비·인벤토리, 스탯 +N 성장, 두 번째 수련, 관군·달래 수련, 4장, 기존 1~3장 수치 변경, 플레이어용 수련 되돌리기.
