# 디자인 감사 기록 (1~5장 UI/비주얼 작업 준비용)

- 목적: 5장 PASS 뒤 1~5장 전체 UI/비주얼 디자인 작업의 재료. 처음 기록할 때(2026-09-27)는 고치지 않고 적기만 했다. 아래 "UI-PHASE-A-01 반영" 에 해결한 항목을 표시한다
- 관찰 조건: 2026-09-27, 헤드리스 크롬 360×740 폰 크기, 5장 실제 클릭 흐름 (시작 → 객사 → 뒷골목 → 관리 → 추격 → 중간 사건 → 결말 → 결과 → 지도). 실제 폰 미확인
- 형식: 화면 / 문제 / 실제 발생 상황 / 개선 필요 이유

## UI-PHASE-A-01 반영 (2026-09-27, 5장 전투 화면 세로 슬라이스)

- 표시: **✅ 해결** (360×740 브라우저 QA 로 확인) / **◐ 일부** / 표시 없음 = **남음**. 37개 중 ✅ 16 · ◐ 5 · 남음 16
- 해결 범위는 **전투 화면만**. 월드맵(7장)·결과 화면(8장)·벽사록은 이번에 손대지 않았고 PASS 처리하지 않는다
- ◐ 이유
  - 쓸 수 없는 버튼: 기술은 [기술] 패널로 모였지만, 사거리 밖일 때 [공격] 은 여전히 회색으로 자리를 차지한다
  - 운반자 정보창: "기력 —" 대신 "이동 4" 를 보여 준다. 노리는 성문은 정보창이 아니라 임무 바·성문 테두리에 있다
  - 알림 모양: 색 토큰으로 정리했지만(임무 = 황토 왼줄 / 벽사록 = 한지 / 일반 = 먹색) 알림 종류 규칙 문서는 아직 없다
  - 버튼·태그 모양: 전투 화면 안에서만 통일 (높이 44 · 모서리 8 · 한 줄). 지도·결과·급보 버튼과 3·4장 봉인·등불 글자 태그는 그대로
- 남은 전투 항목: 남은 조사 지점 찾기(작은 아이콘만) / 관리·서낭신이 같은 중립색(기획 지시대로 중립 공통) / 이동 범위 밖 탭 안내 / 운반자 지나간 길 / 귀화 등장 위치 강조

## ART-PHASE-A/B 반영 (2026-09-27, 5장만)
- ✅ 대사 장면 초상 일관성 — 5장 대사창이 화자 그림(플레이어 초상 · 관리 · 관군 · 운반자)으로, 행동 중 패널·지도 토큰과 같은 인물 그림을 쓴다 (ART-PHASE-B-01)
- ✅ 정보 조회 카드의 시각적 식별 — 5장 조회 카드에 인물 썸네일 36px (플레이어 초상 / NPC·적 전투 그림), "정보 조회" 머리표·두 줄 구조 그대로
- ✅ 행동 주체 vs 조회 대상 — 행동 줄(초상 + "행동 중") 과 조회 카드(한지색 + 썸네일 + "정보 조회") 가 그림까지 서로 달라 한 화면에서 구분된다
- 1장도 같은 방식으로 그림 적용 (ART-PHASE-C-01): 지도·행동 줄·대사·정보 조회가 같은 인물 그림. 2~4장은 이모지 그대로. 칸·임무 정보(📜 🔍 👻 🧿 지형)는 아이콘 그대로
