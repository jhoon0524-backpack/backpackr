# 화면과 연출

`index.html` 의 화면 스크립트가 구현한다. 규칙은 계산하지 않고 core 를 불러 쓴다.
테스트로 확인되지 않으므로 작업마다 사람이 확인할 것을 `PROGRESS.md` 에 남긴다.
원문에 없던 것을 정한 곳은 **(보충)** 으로 표시했다.

## 1. 핵심 흐름
1. 파일을 열면 시작 대사 장면
2. 대사를 다 넘기면 전투 화면 (1턴 아군 페이즈)
3. 아군 행동 → 턴 종료 → 요괴 행동을 반복
4. 승리: 승리 후 대사 → 승리 화면 / 패배: 패배 화면
5. [다시하기] → 시작 대사부터 처음 상태로

## 2. 화면 배치
- 위쪽 줄 항상 표시: `턴 N/10 · 날씨 · 공적 N`
- 가운데 8×8 맵. 세로 화면(폭 360px 이상)에서 스크롤 없이 전체가 보인다
- 아래쪽: [턴 종료] 버튼, 행동 메뉴 자리
- 밤 마을 느낌의 어두운 색. 지형은 색칸으로 구분 (흙길 / 초가집·바위 / 서낭당 / 약수터)

## 3. 세력 표시
- 벽사청(윤무겸·한결): 붉은 테두리
- 객장(여울·소운·달래): 회색 테두리 + 이름 옆 '객장'
- 요괴: 보라색 테두리
- 행동 끝난 아군: 회색으로 흐리게

## 4. 정보창
유닛을 탭하면 작은 정보창: 이름 / 소속 / 칭호 / HP 현재·최대 / 기력 현재·최대 / 속성
- **(보충)** 요괴를 탭해도 정보창만 뜨고 선택되지 않는다. 빈 칸을 탭하면 닫힌다

## 5. 조작
1. 아군 페이즈: 아군 탭 → 이동 가능 칸 파란색 (제자리 포함)
2. 파란 칸 탭 → 이동 → 메뉴 [공격 / 스킬 / 대기 / 취소]
3. 공격·스킬: 사거리 안 대상 빨간색 (정화수는 초록색) → 대상 탭
4. 스킬 대상 위에 "유리!"(×1.5) 또는 "불리"(×0.7) 표시
5. 피해 숫자를 대상 위에 빨갛게 띄웠다 사라지게. 회복은 **(보충)** 초록 숫자
6. 요괴 페이즈: 요괴가 0.5초 간격으로 하나씩 행동
- **(보충)** 요괴 페이즈와 대사 장면 동안에는 맵 입력을 받지 않는다
- **(보충)** 유닛 선택 중 파란 칸 밖을 탭하면 선택 해제

## 6. 대사 장면
초상화(이모지 크게) + 말풍선. 화면을 탭하면 다음 대사.

전투 시작 전:
- 흑린 🐍 "천 년을 기다렸다. 오늘 밤 이 마을을 삼키고 하늘로 오르리라."
- 윤무겸 🗡️ "벽사청의 명이다. 요괴는 벤다."
- 소운 🧙 "닭이 울기 전에 끝냅시다. 난 아침잠이 많아서."
- 여울 🥷 "관군과 한편이라니, 오늘 밤만이오."
- 달래 🔔 "베기 전에 저 원한부터 들어보시지요."

승리 후 (승리 화면 전에):
- 달래 🔔 "원한이 풀렸네. 이제 편히 가시게."
- (달래가 맵에 있으면 달래 유닛이 서서히 사라지는 연출)
- 윤무겸 🗡️ "여의주는 어디 있소?"
- 한결 🏹 "…달래님이 안 보입니다."

퇴각한 아군도 대사 장면에는 나온다.

## 7. 승패 화면
- 승리: "1장 흑린 토벌 완료 · 공적 N / 8" + [다시하기]
- 패배: "날이 밝았다. 흑린이 용이 되어 승천했다." + [다시하기]
