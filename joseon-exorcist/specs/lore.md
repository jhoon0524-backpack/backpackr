# 역사 고증 반영 통합 구현 명세 v0.1 (v0.4, 2026-09-25 기획자 제공)

> 기획자가 준 명세를 요약·정리한 것이다. 사료 인용·수치(예: 진자 48명, 도류 15명)는 **기획자 제공 내용이며 AI 가 원문과 대조하지 않았다.**
> 역사적 사실과 게임 설정을 섞어 사실처럼 설명하지 않는다. **벽사청·신당회·도문은 모두 창작 조직이다.**

## 0. 목표
현재 게임(턴제 격자 전술, 3세력, 1·2장, 공적→품계→관군, 오행·날씨·지형·기력, 진행·저장)을 유지하고,
조선의 국가 의례·무속·민속·도교 요소를 세계관의 뼈대로 추가한다.
목표: "조선 옷을 입힌 판타지"가 아니라 "조선 사람들이 귀신·재액·무속·의례를 받아들였던 방식 자체가 규칙이 되는 전술 RPG".

## 1. 고증 등급 (모든 세계관 데이터에 둔다. 게임 안에서는 벽사록에서만 보인다)
- **A 사료 기반** — 조선왕조실록·국조오례의·경국대전 등
- **B 민속·무속 기반** — 세시풍속·무속·야담·민속 자료
- **C 창작 재구성** — 게임을 위해 만든 조직·규칙·마법

## 2~5. 세력
| 세력 | 철학 | 방식 | 모티프 | 등급 |
|---|---|---|---|---|
| 벽사청 辟邪廳 | "사특한 것은 조정의 법으로 다스린다." | 봉쇄·조사·축귀·체포·토벌. 힘은 국가 조직력(관군·봉쇄선·왕명·역참·관아) | 관상감 나례, 방상씨, 소격서, 관군, 국가 의례 | C |
| 신당회 | "귀신도 사연 없이 생기지 않는다." | 원한을 듣고, 신을 청하고, 혼을 달래고, 부정을 씻고, 떠나보낸다. 회복·정화·소환·상태 변화·교감 | 무선·무령·신칼·정화수·굿·퇴송 | C |
| 도문 | "귀물에도 이치와 법칙이 있다." | 부법·오행·천문·방위·의례·진법 | 소격서의 도류·도교 의례 | C |

- 벽사청: 조정이 공식적으로 존재를 인정하지 않는 별설 기관. 궁궐·도성·왕릉·지방 관아의 괴변·역귀·원혼·요물·신이한 사건을 조사·봉쇄
- 설정: 왕실 의례만으로 막을 수 없는 괴변이 늘자 나례 담당 관원, 폐쇄된 도교 의식의 전승자, 군사를 차출해 비밀리에 벽사청을 만들었다 (창작)
- 소격서를 그대로 벽사청이라고 표현하지 않는다

세력 소개 문구 (첫 시작·세계관 도움말):
- 벽사청: 왕명이 닿지 않는 곳의 괴변을 처리하는 조정의 비밀 관청. 귀물을 조사하고 봉쇄하며, 필요하면 벤다.
- 신당회: 귀신과 사람 사이의 말을 듣는 이들의 모임. 원한은 베어 없애는 것이 아니라 풀어야 한다고 믿는다.
- 도문: 귀물과 천지의 법칙을 연구하는 이들. 부법과 오행으로 인간이 다룰 수 없는 힘을 제어한다.

   회복 시 초록 숫자 + 물방울/푸른 원형 효과 + "정화수" 글자 0.8초. **실제 브라우저에서 확인**

## 9. 아이템 세계관 데이터 (인벤토리·장비·사용 없음. 데이터와 벽사록 항목만)

## 10~12. 벽사록 (도감 + 세계관 사전)
- 메인 화면 작은 버튼 "📖 벽사록". 모바일에서 화면을 가리지 않게 (전투 화면 높이를 늘리지 않는다)
- 카테고리: 인물 / 세력 / 귀물 / 의식 / 물건 / 기록
- 초기 항목: 세력 3, 귀물(흑린·도깨비·장산범), 의식(나례·대나·방상씨), 물건 10
- 플레이로 확인한 항목만 밝아지고, 잠긴 항목은 "????"
- 역사 소재 설명 뒤에 "📜 사료 기반 / 게임에서는 …로 재해석했다" 같은 구분 표시
- 대나는 전투 스킬로 만들지 않는다 (벽사록 소개만)

## 13. 세계관 갈등 (대사·벽사록 소재)
조정: "무격은 미신과 음사를 퍼뜨린다." / 백성: "아이가 죽어가는데 관청은 무엇을 해주었소?" /
신당회: "조정은 우리를 내쫓으면서 사람이 죽으면 우리를 찾는다."

## 14~15. 앞으로의 설계 원칙·백로그 (지금 구현 안 함)
승리 조건을 귀물 종류에 따라 다르게: 요괴 토벌 / 역귀 봉쇄+축역 / 원귀 원인 해결 / 신령 교섭·금기 / 인간 체포·제압·도주 방지.
백로그: 궁궐의 대나, 상여를 따르는 것, 무당마을, 원혼의 객사, 폐도관

## 16. 이번 구현 범위
세계관 텍스트 / 세 세력 설명 / 생명수→정화수 / 무녀 "무령" / 벽사록 UI·기본 항목 / 귀물 entityType /
역사·민속·창작 구분 데이터 / 용어 사전 적용 / 모바일 벽사록

## 17. 구현하지 않음
인벤토리, 장비 장착, 아이템 사용, 제작, 상점, 새 상태이상, 대나 스킬, 원귀 해결 시스템, 3장 전투, 장비 능력치, 방상씨 플레이어블

## 18. 보존 조건
첫 화면·처음부터·이어하기·공적 누계·품계·관군·1장·1→2장·저장·2장 승패·3장 준비 중·맵 에디터. **이전 저장 데이터는 마이그레이션 없이 동작**

## 19. UI 톤 (이번엔 벽사록에 적용, 이모지는 유지)
벽사청 먹색·붉은 관인·관문서·목패·봉인선 / 신당회 종이·천·방울·부채·물·오색 / 도문 먹·도식·별자리·방위·오행

## 20. QA
자동 검사 전부 + 실제 브라우저: 1장·1→2장·새로고침 이어하기·정화수 사용·초록 숫자·정화수 연출·무령 표시·벽사록 열기/닫기·잠긴 항목·모바일 넘침 없음·벽사록 때문에 전투 화면 높이 불변·이전 저장 호환
