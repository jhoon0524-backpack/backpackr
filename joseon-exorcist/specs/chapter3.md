# v0.7 3장 「서낭고개」 — 첫 비토벌형 임무

기획자의 「조선 퇴마전 v0.7 — 3장 「서낭고개」」(2026-09-26)를 옮긴 것이다. **(보충)** 은 원문에 없던 것을 AI 가 정한 곳 (기획자 확인 전).
핵심: 적의 HP 를 0 으로 만드는 것이 승리가 아니다. 조사 → 진실 → 봉인 복구. "1장 칼, 2장 추격, 3장 판단".

## 금지
분기 엔딩, 서낭신 영입·호감도·계약, 대화 선택, 원귀별 사연, 장비·인벤토리·아이템, 시간 시스템, 신당회 추가 등장, 4장 전투, 본격 해원, 민심.

## 1. 월드맵
- 2장 완료 뒤 급보(바뀜): "📜 청령현 북쪽 고개에서 급보가 올라왔다. / 고개를 넘은 사람들이 밤마다 같은 꿈을 꾸고 있다. / 서낭당의 금줄도 사흘째 끊어진 채라고 한다."
- 서낭고개 카드(이상 징후): "고개를 넘은 사람들이 / 밤마다 같은 꿈을 꾸고 있다. // 서낭당의 금줄이 끊어졌다." 버튼 **[조사한다]** (2장 완료 전에는 "조사 준비 중")
- 3장 완료: 서낭고개 → 안정됨 (안개 사라짐), 급보 "서낭고개의 통행이 다시 시작되었다."
- 이어서 폐사찰 봉쇄 → **이상 징후**, 급보 "서낭고개 너머 폐사찰에서 밤마다 불빛이 보인다는 보고가 올라왔다." (전투 없음, "조사 준비 중")
- **(보충)** 서낭고개 안정됨 설명: "안개가 걷혔다. / 고개를 넘는 사람들이 다시 늘기 시작했다." 기록: "3장 서낭고개 — 끊어진 봉인을 복구했다."
- 지역 상태는 여전히 진행(`cleared`)에서 계산. `CAMPAIGN = ['ch1','ch2','ch3']`

## 2. 전투 개요 (`Core.STAGES.ch3`, 10×8, 15턴)
- 아군: 윤무겸·한결·여울·소운 + 품계 관군. 달래 없음
- 서낭신(중립) 1, 떠도는 원귀 4
- 조사 지점 3 (A 끊어진 금줄, B 무너진 돌탑, C 이름 없는 돌무덤), 봉인 지점 3 (금줄, 돌탑, 서낭목)
- **(보충)** 금줄·돌탑은 조사 지점이자 봉인 지점(같은 칸). 서낭목은 봉인만. 돌무덤은 조사만 하고, 원귀가 다시 나타나는 **원한 지점**
- 지점은 지형이 아니라 스테이지 데이터 `points` (지형 글자 추가 없음). 맵 에디터는 지점을 다루지 않는다

## 3. 목표 (전투 중 바뀜)
| 단계 | 화면 목표 | 넘어가는 조건 |
|---|---|---|
| 조사 | 서낭고개의 괴변 원인을 확인하라. (조사 N/2) | 조사 지점 3곳 중 **2곳** |
| 봉인 | 봉인 지점 3곳을 복구하라. (복구 N/3) | 3곳 모두 → **즉시 승리** |
- 조사: 아군이 이동을 마치고 그 칸에 서면 자동 조사 (새 행동 없음, 행동을 소모하지 않음). 그 지점의 글을 짧게 보여 준다
- 2곳째 조사 → 진실 공개 대사(기획서 12장 그대로) → "임무 갱신" → 봉인 지점 강조
- 봉인 복구: 봉인 단계에서 아군이 복구 안 된 봉인 칸에 서 있으면 행동 메뉴 **[봉인 복구]**. 누르면 그 유닛 행동 끝
- 마지막 봉인: "바람이 멎었다." → 남은 원귀가 희미해지며 사라짐 → 승리

## 4. 패배
| 조건 | 문구 |
|---|---|
| 아군 전원 퇴각 | 벽사청 일행이 고개에서 물러났다. |
| 원귀가 서낭신 HP 를 0 으로 | 고개를 지키던 마지막 힘이 사라졌다. |
| 15턴 종료 | 원한이 고개를 넘어 마을로 흘러들었다. |

## 5. 서낭신 (중립, SINRYEONG)
- 적색 표시를 쓰지 않는다 (중립 테두리). 소속 "서낭고개", 칭호 "고개의 신령"
- 움직이지 않는다. 사람을 공격하지 않는다
- 적 차례 맨 앞에 행동: **금역 禁域** — 자기와 거리 2 안의 원귀 중 가장 가까운 **하나**를 자기에게서 먼 쪽으로 한 칸 민다. 피해 0 **(보충: 한 턴에 하나만 — 전부 밀면 원귀가 서낭신에 닿지 못해 패배 조건이 의미 없어짐)**
- 아군이 공격할 수 있다 (막지 않는다). 첫 공격 뒤 한 번: 서낭신 "눈앞의 것만 보는구나." / 소운 "…잠깐. 저것이 우리를 노리고 있지는 않소."
- 아군 공격으로 HP 0 → 패배가 아니다. 서낭신이 사라지고 "봉인이 크게 약해졌다." → 원귀 재등장이 빨라진다 (2턴 → 1턴)
- 공적 없음

## 6. 떠도는 원귀 (WONGWI, 👻)
- 수치(초안, 시뮬레이션으로 조정 가능): HP 16 · 공격 8 · 방어 3 · 이동 3 · 사거리 1 · 속성 없음
- **미련:** HP 0 → "원귀를 물리쳤다." (공적 없음) → 2턴 뒤 원한 지점(돌무덤, 차 있으면 가까운 빈 칸)에서 HP 가득 다시 등장 "원한이 남아 다시 모습을 드러냈다."
- **(보충)** 재등장 시점: 쓰러진 턴 + 2 의 적 차례 시작
- AI 우선순위: ① 복구 안 된 봉인 지점 (이번 턴에 닿으면 그 칸으로, 이미 서 있으면 머문다) ② 서낭신 ③ 가까운 아군. 이동 뒤 칠 수 있으면 서낭신 > HP 낮은 아군 순으로 친다
- 봉인 지점을 부수지 않는다 (이동 목표로만). **(보충)** 원귀가 봉인 칸에 서 있으면 그 칸은 복구할 수 없다 (칸이 막힘) — 압박의 원천
