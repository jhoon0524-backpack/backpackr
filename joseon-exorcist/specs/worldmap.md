# v0.6 월드맵·캠페인 — 청령현 靑嶺縣

기획자의 「조선 퇴마전 v0.6 — 월드맵·캠페인 기획서」(2026-09-26)를 옮긴 것이다. **(보충)** 은 원문에 없던 것을 정한 곳.
노드형 지도: 지역을 누르면 카드가 열리고 [출동]으로 전투에 들어간다. 오픈월드·전략 게임이 아니다.

## 금지
3장, 자유 이동·이동 시간·식량·랜덤 전투, 세금·민심·자원·병력·건설, 관군 이동·점령·상점·아이템, 시간·낮밤·날씨 지도, 서브퀘스트, 월드맵 전투 연출, 실제 조선 전도·다른 도.
공적 지급량·품계 기준·관군 수는 바꾸지 않는다 (성장 게이트, `specs/proposal-growth.md`). 월드맵에 성장 설명을 새로 넣지 않는다 — 현재 값만.

## 1. 흐름
- 새 게임: 첫 화면 → 프롤로그 → [임무를 받는다] → **월드맵** → 흑석촌 [출동] → 1장
- 이어하기: 언제나 **월드맵** (현재 임무 강조)
- 전투 승리: 결과 화면 → [지도로 돌아간다] → 월드맵 (상태 변화·급보). 자동으로 다음 장을 시작하지 않는다
- **(보충)** 전투 패배: [다시하기] / [지도로 돌아간다]
- **(보충)** 결과 화면의 "3장은 준비 중입니다" 는 없앤다 — 지도에서 서낭고개 "조사 준비 중" 으로 보인다. 첫 화면 [이어하기]는 2장을 깬 뒤에도 눌린다 (지도로)
- 1·2장 전투 내용은 그대로 (진입·퇴장만 바뀜)

## 4. 상태는 저장하지 않고 진행에서 계산한다 (`Core.worldState(progress)`)
| 지역 | 새 게임 | 1장 완료 | 2장 완료 |
|---|---|---|---|
| 벽사청 | 본진 | 본진 | 본진 |
| 흑석촌 | 괴변 발생 | 안정됨 | 안정됨 |
| 여우골 | 미확인 | 괴변 발생 | 안정됨 |
| 큰고을 | 평온 | 평온 | 평온 |
| 서낭고개 | 이상 징후 | 이상 징후 | 이상 징후 |
| 폐사찰 | 잠김 | 잠김 | 잠김 |
| 봉쇄된 산길 | 통행 불가 | 통행 불가 | 통행 불가 |
| 나루터 | 평온 | 평온 | 평온 |
- 진행 저장(`cleared`)에서만 계산하므로 "2장은 깼는데 여우골은 미확인" 같은 불일치가 생길 수 없다. v0.3~v0.5 저장은 그대로 이어진다
- 저장하는 것은 이벤트뿐: localStorage `joseon-exorcist.world` = `{ v: 1, seen: ['news:ch1', …] }` (본 급보)

## 5. 급보 (`Core.worldNews(progress, seen)`)
- 1장 완료 뒤 처음 지도: "📜 새로운 급보가 도착했습니다." / "벽사청으로 급보가 도착했다. 여의주를 가지고 사라진 달래가 산 너머 마을에서 목격되었다." → 여우골에 붉은 파동
- 2장 완료 뒤 처음 지도: "서낭고개에서 새로운 보고가 올라오고 있다." → 서낭고개에 파동
- 한 번 보면 `seen` 에 남아 다시 뜨지 않는다. **(보충)** [처음부터]를 누르면 `seen` 도 비운다 (새 게임에서 급보를 다시 본다)

## 6. 화면 (모바일 세로)
- 위: "청령현 靑嶺縣" / "종9품 벽사청 종사관 윤무겸 · 공적 2" / 현재 임무 줄 "현재 임무 🔴 여우골 — 사라진 여의주" (누르면 그 지역 카드)
- 가운데: 한지 색 지도 (먹선 산 능선·강·길), 지역 노드는 44px 이상으로 또렷하게
- 아래: 노드를 누르면 바텀시트 — 이름·상태·설명·버튼. 바깥을 누르면 닫힘
  - 괴변 발생: [출동] / 안정됨: [기록 보기] (재전투 없음 — 해결 기록: "흑린을 퇴치했다." 등) / 이상 징후: "조사 준비 중" / 잠김·통행 불가: 막힌 이유 / 평온: 설명만
  - 본진: 辟邪廳 벽사청 "사특한 것을 막는 조정의 비밀 관청." 현재 품계·누적 공적, [벽사록] [현재 임무]
- 상태 표현: 본진 붉은 인장·조금 크게 / 평온 먹색·작은 불빛 / 이상 징후 옅은 안개·회색 파동 / 괴변 발생 붉은 인장·검은 연기·느린 호흡 / 안정됨 연기 없음·작은 불빛(맑아진 느낌) / 잠김·통행 불가 흐리게·금줄
- before/after: 흑석촌·여우골은 괴변 발생 때 연기, 안정됨이면 연기 없이 창문 불빛

## 7. 벽사록 연동 — 데이터만
- 지역마다 `lore` 필드(지역 기록 id 자리)를 둔다. 벽사록에 '지역' 카테고리는 아직 만들지 않는다

## 8. 개발자 도구 (`?dev=1`)
