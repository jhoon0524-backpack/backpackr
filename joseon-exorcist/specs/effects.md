# 읽기 쉽게 만드는 연출 (v0.2)

장식이 아니라 "방금 무슨 일이 일어났는지" 보이게 하는 연출만 넣는다.
규칙(core)은 바꾸지 않는다. 단, 이동 경로를 보여 주려면 core 가 경로를 알려 줘야 하므로
이동 이벤트에 `path`(지나간 칸 목록)를 더한다.

## 1. 피격
- 맞은 유닛: 흰색으로 0.25초 번쩍 + 좌우로 짧게 흔들림
- 상성 "유리!"(×1.5)로 맞으면 피해 숫자를 1.4배 크게, 숫자 아래 작은 "유리!"
- 상성 "불리"(×0.7)면 피해 숫자를 작게, 회색빛
- 기본공격·상성 중립은 지금처럼

## 2. 이동
- 아군·요괴 모두 이동할 때 지나가는 칸을 따라 한 칸씩 미끄러지듯 움직인다 (칸당 0.08초)
- 요괴가 이동하면 지나간 칸에 보라색 발자국 점이 잠깐 남았다 사라진다 (0.6초)

## 3. 쓰러짐
- 요괴 격파·아군 퇴각 때 바로 사라지지 않고 0.4초 동안 흐려지며 사라진다

## 4. 예외 상황
- 제자리 이동 → 움직임 연출 없음
- 움직임 연출 중에는 입력을 받지 않는다 (요괴 차례와 같은 잠금)
- 기기가 "동작 줄이기" 설정이면 흔들림·미끄러짐 없이 결과만 보인다
