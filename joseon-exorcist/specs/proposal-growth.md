# 수정안 — 성장 전달 (공적 → 품계 → 관군)

- **상태: 제안 (구현 보류).** 코드는 바꾸지 않았다. 처음 하는 사람 3명의 플레이테스트 뒤, 실제로 여러 명이 막힌 곳에 해당하는 항목만 고른다 (한 번에 최대 3개)
- 계기: 2026-09-26 기획자 직접 플레이 — 규칙을 아는 사람도 성장 시스템을 전혀 느끼지 못했다 (`PROGRESS.md` v0.5 참고 기록)
- 판정 (기획자 2026-09-26): 수정안 문서 작성은 진행, 코드 변경은 보류, 3명 게이트 유지, 성장 곡선 변경은 데이터를 본 뒤 결정

## 0. 지금 화면이 보여 주는 것 (현황)

| 때 | 지금 보이는 것 | 빠진 것 |
|---|---|---|
| 적을 쓰러뜨릴 때 | 알림 "○○을 퇴치했다. / 공적 +1" 또는 "공적 없음" | **왜** +1 이고 왜 없음인지 (벽사청의 마지막 일격만 공적) |
| 전투 중 | 위쪽 줄 "공적 N" | 공적이 어디에 쓰이는지, 다음 품계까지 얼마 남았는지 |
| 승리 화면 | "공적 누계 N · 품계 정9품 (승진!)" | 승진하면 **무엇이 달라지는지** (관군 합류) |
| 2장 시작 | 관군이 맵에 서 있다 (종9품이면 아무도 없음) | 관군이 **품계 덕분에** 왔다는 설명. 종9품이면 성장의 결과를 한 번도 못 본다 |
| 첫 화면 | "공적 누계 N · 품계 ○○" | 다음 목표 |

세 고리가 모두 끊겨 있어서, 공적을 모르고 하면 → 1장 공적이 적고 → 2장 관군 0 → 성장의 결과를 못 보고 → 끝까지 모른다.

## 1. 고리 ① — 공적을 얻는 순간을 알아차리게

| 안 | 무엇 | 좋은 점 | 걸리는 점 | 크기 |
|---|---|---|---|---|
| **1-A 이유 붙이기** | 알림 공적 줄에 이유: "공적 +1 · 벽사청의 일격" / "공적 없음 · 객장의 일격" / "공적 없음 · 사람은 공적이 아니다" | 규칙을 볼 때마다 배운다. 기존 알림 그대로 | 글이 길어진다 | 작음 (`Core.defeatMessage`) |
| **1-B 위쪽 숫자 반응** | 공적이 오르면 위쪽 "공적 N" 이 금색으로 반짝이고 "+1" 이 떠오른다 | 눈이 공적 숫자로 간다 | 이유는 안 알려 줌 | 작음 |
| **1-C 처음 한 번 안내** | 벽사청이 처음 공적을 얻을 때 한 번만 알림: "벽사청 관원(윤무겸·한결)이 마지막 일격을 넣으면 공적이 된다" | 규칙 자체를 한 번 알려 줌 | 문구는 기획자가 정해야 함 | 작음 |
| **1-D 공격 전 미리 보기** | 대상 고를 때, 이 일격으로 쓰러지면 대상 위에 "공적 +1" (객장이면 "공적 없음") | "누가 막타를 칠까" **판단**을 만든다 — 전술과 성장이 이어짐 | 대상 칸 위 글자가 늘어남 (유리!/불리 태그와 겹침 정리 필요) | 중간 |

추천: **1-A + 1-D** (이유를 알고, 공격 전에 고를 수 있게)

## 2. 고리 ② — 품계가 오르면 무엇이 달라지는지

| 안 | 무엇 | 좋은 점 | 걸리는 점 | 크기 |
|---|---|---|---|---|
| **2-A 승진 문구** | 승리 화면 "정9품 승진 — 다음 전투부터 관군 1명 합류" | 승진과 보상을 한 줄로 잇는다 | 없음 | 작음 |
| **2-B 합류 알림** | 관군이 있는 전투 시작 때 알림 "품계 정9품 — 관군 1명이 합류했다" (관군 칸 강조) | 성장의 **결과**를 전장에서 본다 | 알림 큐에 하나 더 | 작음 |
| **2-C 관군 정보창** | 관군을 누르면 "품계 정9품으로 합류한 관군" | 궁금한 사람만 본다 | 누르지 않으면 모름 | 작음 |
| **2-D 합류 대사** | 2장 시작 대사에 관군 한 줄 | 세계관과 자연스럽게 | 대사는 기획자가 써야 함 | 작음 (문구 대기) |

추천: **2-A + 2-B**

## 3. 고리 ③ — 아직 못 받은 보상을 미리 보여 주기

| 안 | 무엇 | 좋은 점 | 걸리는 점 | 크기 |
|---|---|---|---|---|
| **3-A 다음 목표 줄** | 승리 화면·첫 화면에 "다음 품계 정9품까지 공적 1 — 관군 1명 합류" (짧은 막대) | 목표가 생긴다 | 없음 | 작음 |
| **3-B 위쪽 줄 표기** | 전투 중 "공적 2/3" 처럼 다음 품계까지 | 전투 중에도 목표 인지 | 3 이 무엇인지 설명 필요 (3-A 와 같이) | 작음 |
| **3-C 종9품 시작 안내** | 관군 없이 2장을 시작하면 알림 "품계가 오르면 관군이 함께 싸운다 (정9품: 공적 3)" | **관군을 못 받은 사람도** 성장 목표를 안다 | 2장은 이미 관군 없이 시작한 뒤라 "다음 장부터" 동기 | 작음 |

추천: **3-A + 3-C**

## 4. 성장 곡선 의심 (UI 가 아니라 구조 문제일 수 있음) — 데이터를 본 뒤 결정

사실:
- 정9품(관군 1)은 공적 3, 종8품(관군 2)은 6. 1장 최대 공적 8
- 흑린 +3 은 **벽사청이 마지막 일격**을 넣어야 받는다. 객장이 흑린을 잡으면 0
- 기획자 플레이 1장 공적 **2** (7마리 중 5마리를 객장이 잡음) → 2장 관군 0
- 자동 플레이(막타를 신경 쓰지 않는 단순 규칙)는 1장 공적 6

즉 처음 하는 사람이 막타를 의식하지 않으면 **1장만으로는 성장을 한 번도 체험하지 못할 수 있다.**

| 안 | 무엇 | 비고 |
|---|---|---|
| G0 유지 | 지금 그대로. 고리 ①~③ 전달만 고친다 | 전달만으로 3 을 넘기는지 먼저 본다 |
| G1 보스 목표 공적 | 장 보스를 물리치면 누가 쳤든 +3 ("장 보스 목표 달성 → +3" 문구에 더 가까움) | 1장을 이기면 최소 정9품 보장 |
| G2 문턱 조정 | 정9품 문턱 3 → 더 낮게 | **기획 수치** — 기획자 결정 |
| G3 장 완료 공적 | 장을 이기면 기본 공적 | 공적의 의미("누가 쳤나")가 약해짐 |

결정 기준 (3명 플레이 기록 JSON 에서 바로 보인다):
- 1장 `meritEarned` 와 2장 `rank`
- **3명 중 2명 이상이 2장을 종9품으로 시작** → 곡선 문제 후보로 올린다 (G1~G3 중 선택)
- 질문 4("공적과 품계를 설명해 달라")에 2명 이상 답하지 못하면 → 고리 ①~③ 중 해당 항목

## 5. 3명 플레이테스트 뒤 고르는 법

| 관찰 (QA.md) | 해당하면 우선 후보 |
|---|---|
| 2-1 #5 "공적을 이해 못 함" 2명 이상 | 1-A, 1-D |
| 2-1 #6 "품계가 오른 이유 모름" 2명 이상 | 2-A, 3-A |
| 2장을 종9품으로 시작한 사람 2명 이상 | 3-C, 그리고 4장 G1~G3 판단 |
| 질문 4 에서 관군을 언급한 사람이 없음 | 2-B |

한 번에 최대 3개만 구현하고, 다시 플레이테스트로 확인한다.

## 하지 않는 것
새 보상·새 성장 시스템·레벨·경험치 추가, 3장. 수치 변경(G2)은 기획자 결정 없이 하지 않는다.
