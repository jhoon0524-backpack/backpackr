# v0.4 몰입·UX (1·2장 다듬기)

기획자의 「조선 퇴마전 v0.4 구현 지침」(2026-09-26)을 옮긴 것이다. 원문에 없던 것을 정한 곳은 **(보충)** 으로 표시했다.
3장은 만들지 않는다. 목표는 "플레이 5분 안에 조선 퇴마전이라는 사실을 느끼게 한다".

## 1. 맵 에디터 숨김 (P0-1)
- 일반 주소에서는 [🛠 맵 에디터] 버튼이 보이지 않는다. 주소 끝에 `?dev=1` 을 붙였을 때만 보인다
- 에디터 기능 자체는 그대로 둔다

## 2. 지형 설명줄 → 누르면 보이는 카드 (P0-2)
- 맵 아래에 늘 보이던 지형 설명줄을 없앤다
- 지형 칸을 누르면 맵 아래 정보 카드(유닛 정보창 자리)에 설명이 나온다
  | 지형 | 제목 | 설명 |
  |---|---|---|
  | 서낭당 | 서낭당 | 받는 피해 20% 감소 |
  | 약수터 | 약수터 | 턴 시작 시 HP +10 |
  | 탈출로 | 탈출로 | 달래가 이 칸에 도착하면 패배합니다. |
  | 초가집·바위 | 초가집·바위 | 지나갈 수 없습니다. **(보충)** |
- 흙길은 카드를 띄우지 않는다
- **(보충)** 유닛을 눌렀을 때 그 유닛이 특수 지형 위에 있으면 정보창에 한 줄 더 적는다 (예: "서낭당 위 · 받는 피해 20% 감소")
- **(보충)** 특수 지형(서낭당·약수터·탈출로)을 처음 만난 전투에서 한 번만, 전투 시작 때 짧은 토스트로 알려 준다.
  본 지형은 브라우저에 기록한다(`joseon-exorcist.tips`). 저장이 막혀 있으면 매번 보여도 괜찮다

## 3. 프롤로그 (P0-3)
- [처음부터](첫 진행이면 [시작하기])를 누르면 1장 전에 프롤로그가 나온다. [이어하기]는 프롤로그 없이 바로 장으로 간다
- 문장(그대로 쓴다):
  ```
  조선 ○○년.
  도성 곳곳에서 / 설명할 수 없는 괴변이 이어졌다.
  조정은 귀신의 존재를 인정하지 않았다.
  대신 기록에 남지 않을 / 관청 하나를 만들었다.
  辟邪廳
  사특한 것을 막는 곳.
  당신은 벽사청 종사관 / 윤무겸이다.
  ```
- 한 덩이씩 페이드로 나타나 약 10초. 어두운 배경, 한지 색 글자, 붉은 인장(辟邪廳)
- 마지막에 [임무를 받는다] → 1장 시작 대사로
- **(보충)** 화면을 누르면 남은 문장이 한 번에 다 나오고 버튼이 바로 보인다 (다시 보는 사람용)

## 4. 퇴장 표현 (P0-4) — core
- 쓰러진 적 이벤트(`defeat`)에 `defeatType` 을 붙인다. 존재 분류 → 퇴장 표현:
  | entityType | defeatType | 표현 |
  |---|---|---|
  | HUMAN | SUBDUE | 제압 |
  | YOGOE | EXORCISE | 퇴치 |
  | JAPGWI | CHUKGWI | 축귀 |
  | YEOKGWI | CHUGYEOK | 축역 |
  | WONGWI | TOESONG | 퇴송 |
  | SINRYEONG | (보충) EXORCISE | 퇴치 |
- `Core.DEFEAT_TYPES`(코드 → 표현), `Core.defeatTypeFor(entityType)`
- 화면 문구 (토스트)
  - 사람: "신당회 무녀를 제압했다." — 죽음·사망 표현 금지
  - 요괴: "정화된 도깨비를 퇴치했다." (조사 을/를 자동)
  - 2장 달래(보스): "달래가 여의주를 떨어뜨리고 물러났다." HP 0 이어도 죽지 않는다 (기존 승리 흐름 그대로)
  - **(보충)** 뒤에 공적을 붙인다: 공적이 생기면 "공적 +1", 사람 제압이면 "공적 없음", 객장의 일격이면 아무것도 안 붙인다

## 5. 공적 (P0-5) — core
- 사람(HUMAN) 제압 → 공적 0 (보스는 예외)
- 귀물(사람이 아닌 일반 적) → +1, 장 보스 → +3 (1장 흑린, 2장 달래 모두 +3 유지)
- 벽사청 소속(윤무겸·한결·관군)의 마지막 일격만 공적이 되는 조건은 그대로
- `Core.maxMerit(stage)` = 사람이 아닌 일반 적 수 + 3. 1장 8 그대로, 2장 8 → **6**
- 사람 공적(`humanMerit`)과 2장 승리 후 한결·윤무겸 두 줄("사람을 베어도 공적입니까?")은 뺀다 (기획자 결정 2026-09-26)

## 6. 정화수·무령 연출 (P1-6·7)
- v0.4 고증 반영에서 만든 연출 유지. 기술 글자에 한자를 작게 붙인다: "정화수 井華水", "무령 巫鈴"
- **(보충)** 다른 스킬(벽사검·파사궁·축지격·화염부)도 쓸 때 대상 위에 이름 글자를 띄운다 (파문 없이 글자만)

## 7. 벽사록 발견 (P1-8·9) — core + 화면
- 처음 밝혀진 항목이 있으면 2~3초 토스트:
  ```
  📖 벽사록에 새 기록이 추가되었습니다.
  정화수 井華水
  ```
  한꺼번에 여럿이면 한 토스트에 이름을 이어 적는다
- 밝힘 조건 변경
  | 항목 | 이전 | 이번 |
  |---|---|---|
  | 벽사청 | 처음부터 | 처음부터 (플레이어 세력) |
  | 도문 | 처음부터 | **(보충)** 1장 전투 시작 (`stage:ch1`) |
  | 신당회 | 처음부터 | 2장 전투 시작 — 처음 신당회와 맞선다 (`stage:ch2`) |
  | 흑린 | 1장 전투 시작 | 그대로 (시작 대사가 끝난 뒤 토스트) |
  | 정화수 | 정화수를 쓰면 | 그대로 (1장 아군 달래가 먼저 쓰면 그때 밝혀진다) |
  | 무령 | 2장 무녀를 만나면 | 무녀가 처음 무령을 쓰면 (`skill:무령`) |
- `Core.loreTokensForBattle(state, stageId)` 에 `stage:장` 토큰을 더한다
- `Core.newlyUnlockedLore(before, after)` — 토큰이 늘어 새로 밝혀진 항목 목록 (토스트용)
- 이전 저장 호환: 깬 장이 있으면 `clear:장` 과 `stage:장` 을 본 것으로 친다 (마이그레이션 없이)
- 잠긴 항목 이름은 `?????`
- 처음 벽사록을 열면 벽사청 1개만 밝혀져 있다

## 8. 벽사록 항목 구조 (P1-10)
- 항목 데이터: `lore`(기록 — 객관적 설명, 이전 `text`), `characterNotes`(캐릭터 시점 짧은 코멘트, `{ yoon: '…' }`), 고증 메모 `note`·`motif` 는 그대로
- 상세 화면: **기록** → **윤무겸의 기록** → 고증 등급 메모 순서
- 정화수 기록은 원문 예시 그대로: "정화수는 이른 새벽 길은 깨끗한 우물물이다. 제의와 기원의 매개로 사용되었다." / 윤무겸: "귀신보다 사람이 정화수를 더 믿는 듯하다."
- **(보충)** 나머지 윤무겸의 기록은 AI 초안이다 (기획자 확인 필요). 후속 장 항목(잠김)은 비워 둔다

## 9. 스킬 이름 크게 (P2-11)
- 스킬 버튼에 스킬 이름을 크게 쓰고 아래에 기력을 작게 쓴다. 이름은 지금 이름 유지 (기획자 결정: 벽사검·파사궁·축지격·화염부·정화수)
- 대상 고르는 중에는 맵 아래 안내줄에 "벽사검 — 대상을 고르세요" 처럼 크게 쓴다
- 관군은 스킬 버튼 비활성 그대로

## 10. 모바일 (P2-12)
- 폭 360px 세로 화면에서 첫 화면·프롤로그·1장·2장·벽사록·확인 화면·승리 화면이 넘치거나 겹치지 않는다
- 전투 중 맵이 화면 밖으로 밀리지 않는다 (지형 설명줄 제거로 공간 확보)

## 하지 않는 것
3장, 인벤토리, 상점, 장비, 아이템 사용, 제작, 방상씨 전투, 대나 스킬, 원귀 시스템, 퀘스트, 레벨, 경험치, 복잡한 컷신, 음성, BGM.
적 HP·공격·방어는 바꾸지 않는다.
