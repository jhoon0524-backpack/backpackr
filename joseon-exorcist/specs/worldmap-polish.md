# v0.6.1 지도 시각 정리 (기능 변경 없음)

기획자 판정 (2026-09-26): v0.6 은 **기능 설계 PASS / 비주얼 1회 폴리시 필요**. 지금 화면은 "고지도 위의 진행도·플로차트"에 가깝다 — 지리보다 노드 연결선이 먼저 읽힌다.
목표: 같은 노드 구조로 **'보드판'에서 '장소'로**. 흐름·상태 계산·저장·출동은 바꾸지 않는다. **(보충)** 은 원문에 없던 것을 정한 곳.

## 1. 길: 점선 → 손으로 그린 산길
- 굵은 점선 직선을 없애고, 흙빛의 굽은 길(곡선)로. 산을 돌아가게 굽힌다
- 여우골↔큰고을 같은 길은 실제 길처럼 굽힌다
- 길 일부가 산 뒤로 사라졌다 다시 나타나게 (산 모양을 길 위에 겹쳐 그림)
- 봉쇄된 길은 **길 위에** 무너진 바위·금줄을 놓는다 (여우골→봉쇄된 산길: 바위 더미 / 서낭고개→폐사찰: 금줄)
- **(보충)** 노드 위치는 대부분 그대로, 일직선 느낌을 줄이려 몇 칸만 좌우로 비튼다 (연결 관계 불변)

## 2. 산: 반복 무늬 → 지역마다 의미 있는 지형
- 같은 ∧ 능선 반복을 줄인다. 네 곳만 지형으로 만든다
  | 지역 | 지형 |
  |---|---|
  | 폐사찰 | 깊은 산 — 봉우리 여러 개, 작은 절 지붕 실루엣 |
  | 서낭고개 | 두 산 사이 좁은 고개 — 길이 실제로 고개를 넘어간다 |
  | 여우골 | 계곡 — 양쪽 산 + 작은 물줄기 |
  | 큰고을 | 평지 — 논밭 몇 칸, 관아 지붕 몇 개 |
- 나루터 강은 유지

## 3. 표식의 뜻을 하나씩 (안전한 곳은 조용하게, 문제 있는 곳만 움직인다)
| 표현 | 뜻 | 쓰는 상태 |
|---|---|---|
| 붉은 파동 | 지금 해결해야 할 괴변 | 괴변 발생 |
| 옅은 황색 파동 | 이상 징후 | 이상 징후 |
| 불빛 | 사람이 정상적으로 사는 곳 | 평온 |
| 회색·금줄 | 접근 불가 | 봉쇄·통행 불가·미확인 |
| 아무 표시 없이 맑게 | 해결됨 | 안정됨 |
- v0.6 의 노란 점(안정됨·평온 모두에 있던 것)을 정리: **안정됨에서는 뺀다**, 평온에만 불빛
- **(보충)** 노드 아래 상태 글자: 평온·본진은 뺀다 (조용하게). 괴변 발생·이상 징후·안정됨·봉쇄·통행 불가·미확인은 남긴다 — "해결한 곳은 안전해졌다"(v0.6 성공 기준 3)를 글자로도 확인
- 본진은 계속 **사각 붉은 관인**, 일반 지역은 **원형 표식** (시각 문법 고정)

## 4. 데이터: 조선 전체 → 권역 → 지역 (구조만, UI 없음)
- `Core.PROVINCES = [{ id: 'cheongryeong', name: '청령현', hanja: '靑嶺縣', regions: [...] }]`, 지역마다 `province`
- 지금 화면 전체가 "청령현 권역맵". 권역 하나는 6~10 지역으로 유지하고, 권역 이야기가 끝나면 나루터로 다음 권역맵 (나루터 설정과 일치). 권역 이동 UI 는 만들지 않는다

기능 변경, 새 지역, 권역 이동 UI, 3장. 상태 계산·저장·급보·출동 흐름 그대로.
