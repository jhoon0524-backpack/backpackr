# 맵 에디터 (v0.2)

기획자가 전투 맵을 직접 만들고, 코드로 복사해 전달하거나 브라우저에 저장해 두는 도구.
게임과 같은 `index.html` 안에 있다 (파일 1개 원칙). 규칙 검사는 core 가 한다.

## 1. 핵심 흐름
1. 전투 화면 맨 아래 작은 [🛠 맵 에디터] 버튼, 또는 주소 끝에 `#editor` → 에디터 화면
2. 1장 맵이 열린 상태로 시작한다
3. 아래 도구 줄에서 칠할 것을 고른다: 지형 4종 / 아군 5명 / 요괴 4종 / 지우개
4. 맵 칸을 누르면 칠해진다. 지형은 손가락을 끌면 여러 칸이 한 번에 칠해진다
5. [코드 복사] → 맵 코드가 복사된다 (복사가 막힌 기기면 코드 칸이 선택된 상태로 보인다)
6. [저장] → 이름을 적어 이 브라우저에 저장. 저장 목록에서 불러오기·삭제
7. [코드 붙여넣기] → 받은 맵 코드를 넣어 불러오기
8. [게임으로] → 전투 화면으로 돌아간다 (에디터 맵으로 플레이하지는 않는다 — v0.2 범위 밖)

## 2. 편집 규칙
- 맵 크기: 행 6~12, 열 6~10 (보충). 크기를 줄이면 밖으로 나간 유닛은 지워진다
- 아군: 5명 각각 최대 1번 배치. 이미 놓인 아군을 다른 칸에 놓으면 옮겨진다
- 요괴: 도깨비·장산범·불가사리는 여러 마리, 보스(흑린·달래)는 1마리만 (놓으면 기존 보스가 옮겨진다)
- 초가집·바위 칸에는 유닛을 놓을 수 없다. 유닛이 있는 칸을 초가집·바위로 칠하면 유닛이 지워진다
- 지우개: 유닛이 있으면 유닛을, 없으면 지형을 흙길로 되돌린다

## 3. 맵 코드
- 사람이 읽을 수 있는 한 줄 JSON: `{"v":1,"name":…,"rows":…,"cols":…,"map":[…],"allies":[…],"enemies":[…]}`
- 게임 안 1장 데이터(`Core.STAGES.ch1`)와 같은 모양이다. 받은 코드는 그대로 새 장 데이터가 된다

## 4. 검사 (core 의 `validateStage`)
문제가 있어도 저장·복사는 된다. 화면에 경고로만 보인다.
- 보스가 없음 → "보스(흑린·달래)가 없으면 이길 수 없습니다" (v0.3 에서 보스 일반화)
- 아군이 0명 → "아군이 한 명도 없습니다"
- 유닛이 초가집·바위 위 / 맵 밖 / 같은 칸에 둘 → 해당 칸 표시
- 알 수 없는 지형 글자·유닛 종류 → 불러오기 거부 + 이유 표시

## 5. 예외 상황
- 브라우저 저장이 막힘(사생활 보호 모드 등) → "이 브라우저에는 저장할 수 없습니다. 코드 복사를 쓰세요"
- 잘못된 코드 붙여넣기 → 지금 맵은 그대로, "맵 코드를 읽을 수 없습니다: (이유)"
- 같은 이름으로 저장 → 덮어쓴다 (보충)
