## 자동 판정 (5장)
- PASS — 5장 진입 때 그림 12개를 미리 요청 (운반자·귀화 포함, 등장 전)
- PASS — 지도 위 유닛 전원 그림 표시 (시작 6 · 추격 8 · 귀화 등장 10)
- PASS — 그림은 세력 테두리 안쪽 · 칸 안 (이웃 칸 침범 없음, 그림은 누를 수 없게 해 두어 칸 누르기 그대로)
- PASS — 맵 위치 85px 그대로 · 가로 스크롤 없음
- PASS — 행동 중 초상 40px, 이름 위치(63px)가 그림 없는 판과 같음 · 행동 패널 화면 안
- PASS — 관리: 그림 + 중립 이중선 + 임무 고리 / 운반자: 그림 + 적갈 각진 테두리 + 사람 표식 + 임무 고리 / 귀화: 그림 + 자주 동그라미 + 불꽃 표식
- PASS — 임무 고리가 그림 밖에 그대로 (그림이 고리를 덮지 않음)
- PASS — 여울·한결 행동 중 → 각자 초상, 기술 패널·정보 조회 카드와 함께여도 레이아웃 그대로
- PASS — 그림을 못 불러오면 맵·초상 모두 이모지, 턴 진행 정상, 스크립트 오류 없음
