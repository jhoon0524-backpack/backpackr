### v2-7. 회전 90°/초에서 어긋나는 8-6 목표 — 기획 판단 필요
**구현.** 기획자 결정대로 경계 회전만 120°/초 → 90°/초 (`K.TURN = π/2`). 봉인 문서 뒤 140°/초(`TURN_SEAL 2.4`)는 "다른 수치는 바꾸지 않는다"에 따라 그대로 두었다.
**측정 (Node, 1/60초, `pilot.test.mjs` 의 봇 — 설계 simv2 봇을 옮긴 것).**
| 목표 | 120°/초 | 90°/초 |
|---|---|---|
| 우회: 여울이 달리는 운반자를 뒤에서 쫓으며 연타 → 져야 함 | 20.2초 탈출 | **42.2초 제압** (옆·뒤 7 / 막힘 0 — 성문에 닿는 순간 뒤에 붙어 있다가 그가 돌아서기 전에 2타) |
| 우회: 아무것도 안 함 / 관군 2 북문 / 관군 북·남 / 윤무겸 뒤쫓기 / 한결 화살만 | 탈출 | 탈출 11.9 / 16.8 / 14.2 / 117.9 / 114.5 (유지) |
| 달려가 연타 5종 → 패배 또는 60초+ | 탈출 | 탈출 44.9 / 52.3 / 29.6 / 43.5 / 19.2 (유지) |
| 옆·뒤 봇 (윤무겸 / 여울 / 사람 손 1.2/0.45 윤무겸 / 여울) | 42.4 / 45.8 / 56.8 / 59.1 | 49.8 / 42.7 / **66.2** / 56.6 |
| 사람 손 옆·뒤 6가지 + 정확 2가지, 바로 추격 | 제압 6 · 탈출 2 | 제압 7 (42.7~79.6초) · 탈출 1 |

**선택지.** (a) 그대로 (뒤에 붙어 쫓다 성문에서 치는 것도 "뒤로 들어가기"로 인정) (b) 도착 순간 110u 안이면 바로 그쪽을 보는 규칙(`ARRIVE_FACE`)은 있으니, 도착 뒤 0.5초 등 짧은 동안만 120°/초로 돈다 (c) 90°/초 대신 조금 빠르게 — 측정(설계 simv2 봇): 여울 뒤쫓기는 1.6 rad(≈92°/초)·1.7·1.8·1.83(105°)·1.9 rad 에서 모두 29.4초 탈출, 정확히 1.5708 rad(90°)에서만 42.2초 제압. 결과가 회전 값에 민감하다(봇이 결정적이라 한 판 모양이 통째로 바뀜) — 90° 근처는 사람 플레이에서도 흔들릴 수 있다.

### v2-1. [해소 — v2-수정2 요약 13번] 관군 시작 자리 — 배치 조정
**문제.** 관군 2명을 (220,380)(260,380) 에 두면 큰길(128u) 에서 두 몸(32u) 옆 틈이 28u·8u·28u 로 모두 몸 폭 32u 보다 좁다. 운반자는 동쪽 골목으로 돌아가(북문 도착 5.9초, 표 4.9초) 표가 어긋나고, 반대로 남쪽으로 달릴 때는 두 몸 사이에 끼어 영영 멈췄다 (시뮬레이션: (231,353) 에서 150초 동안 정지).
**구현.** 관군을 큰길 서쪽 가에 앞뒤로 (196,366)(196,402) 세웠다. 동쪽 52u 가 비어 운반자가 지나간다. 관군 → 북문 지킴 자리 2.3~2.6초(표 2.6), → 남문 4.9~5.2초(표 5.3). 아무것도 안 함 11.9초·관군 2 북문 16.9초는 표와 같다.
**선택지.** (a) 이 자리 확정 (b) 객사 앞 마당을 따로 만들어 큰길 밖에 세운다.

같은 이유로 파티 4명은 (120,590) 한 점에 겹칠 수 없어 갈래 ① 과 중앙 가로골목에 나눠 세웠다: 윤무겸 (120,590) · 여울 (120,632) · 한결 (88,540) · 소운 (152,540). 성문까지 시간 윤무겸 4.2 · 여울 3.8 · 한결 4.4 · 소운 4.0초 (표 3.9 / 3.3 / 4.1 / 4.3, 모두 ±0.5초 안).
운반자 첫 길이 표의 584u 가 되도록 시장 북서 모서리에 길 매듭 하나를 더했다 (좌판을 비켜 큰길로 비스듬히 나감, 실제 4.9초).

### v2-2. [해소 — 브리프 8-4 확정] 돌아온 관군을 다시 밀쳐 내는가

## 2. [2차 수정으로 해소] 북문 첫 명령 여유 "+1.4초"는 성문을 닫을 수는 있지만 운반자를 돌려보내지는 못한다

## 3. [2차 수정으로 해소] 6-1 표의 큰길 경로 N2·S2 는 서로·관군 표와 동시에 성립하지 않는다

**문제.** 표의 관군 → 북문 930u 는 광장 (180,960) 에서 큰길을 곧게 올라간 거리다. 같은 곧은 큰길이면 N2(시장 → 큰길 → 북문)는 1190u 가 아니라 약 1140u 이고, 시장이 중앙 가로골목 높이(y≈1060)에서 큰길로 열려 있으면 S2 는 약 27.7초로 **N1(28.8초)보다 빨라** 운반자가 처음부터 큰길 남쪽으로 간다 (표의 "처음 고르는 길 N1" 과 모순).

**구현에서 고른 것.** 시장은 큰길과 **광장 쪽 60u 어귀(시장 어귀 매듭)로만** 통하게 했다 (나머지 시장 서쪽은 담). 그러면:

| 경로 | 설계값 | 구현 측정 |
|---|---|---|
| N1 | 28.8 | 29.2 (지킴 선 도착, 실제 이동) |
| S1 | 29.5 | 29.9 |
| N2 (광장 관군 벌점 포함) | 40.2 | 40.1 (비용) |
| S2 | 30.1 (벌점 없음) | 약 34.5 + 광장 관군 벌점 11 |

N1 첫 선택, S1 이 0.7초 차 두 번째, 관군이 N2 를 막는 구조는 유지된다. S2 만 표보다 4.4초 느리고 광장 관군 벌점도 받는다.

**가능한 선택지.** (a) 지금 배치를 확정 (b) 중앙 가로골목을 시장까지 이어 S2 를 30초로 맞추고, 대신 운반자 시작점을 시장 동쪽 끝으로 옮겨 N1 이 계속 첫 선택이 되게 (c) 표에서 S2 값을 34.5 로 고친다.

## 5. [2차 수정으로 해소] "궁지"의 시작 시점

**구현.** 길이 끊긴 순간부터 궁지로 본다 (그래서 막다른 갈래로 도망가는 도중에 한 명만 붙어도 구속된다). QA 승리 판에서는 북문 지킴 3명이 성문 안에서 운반자를 궁지+구속해 게이지 28 → 14 까지 깎았다.

**가능한 선택지.** (a) 그대로 (b) 막다른 갈래 사각형 안에 들어간 뒤부터만 궁지.

## 6. [2차 수정으로 해소] 명령판 30% 시간은 "열 때마다" 다시 3초 — 초상을 연달아 누르면 계속 느린 시간
