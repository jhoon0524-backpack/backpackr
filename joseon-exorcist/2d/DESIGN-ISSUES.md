## 7. [해소 — 구현 검수 N-1] 막힌 성문 앞 운반자의 1초 간격 길 바꾸기

**문제.** 북문이 몸으로 막혀 있고 운반자가 성문 앞 마당에 있으면, 지금 길의 비용이 ∞ 라 규칙 2(3초 이상 나을 때만)가 "무조건 바꿈"이 되어 N2 ↔ SW (↔ S1) 로 1초마다 예고 "!"가 뜬다. 브리프 6-2 참고 줄에 적힌 현상과 같다.
**근거.** `여울·한결→북문 t=2`: 27.8 N1→S1, 28.8 S1→N2, 29.8 N2→S1, 30.8 S1→N2, 31.8 N2→SW, 32.8 SW→N2, 33.8 N2→SW (결과는 제압 39.2 로 같음).
**가능한 선택지.** (a) 그대로 (b) 길을 바꾼 뒤 N초 동안은 다음 전환을 막는다 (c) ∞ 에서 벗어나는 전환도 새 길끼리 3초 차이 규칙을 적용.
**해소.** 원인은 E-3("지나친 몸" 제외) 구현이 운반자의 **순간 걸음 방향**으로 앞/뒤를 판단한 것이었다. 성문 앞에서 한 걸음 물러설 때마다 성문 지킴이 "뒤"가 되어 북문 길이 열려 보였다. 규칙은 새로 만들지 않고, 판단 기준을 **따져 보는 경로의 방향**(북문 길 = 북쪽, 남문 길 = 남쪽)으로 바꿨다.
한 추격당 길 전환 횟수 (검수 `sim4.mjs`·`sim3.mjs`): 수정 전 최대 9회(B+뒤쫓기 t=3) · 7회(H2 t=2) → 수정 후 전 배치 최대 3회. 승패 표·E-3 성문 통과(y=30·20·14·5)는 그대로. `pilot.test.mjs` N-1 테스트로 고정.

## 아래는 1차 기록 (해소된 항목은 제목에 표시)

## 1. [2차 수정으로 해소] 전환점 ③ 강제 뿌리침이 성문에서 일어나면 1~2초 안에 탈출한다

**문제.** 성문 지킴 2명이 운반자를 성문 안에서 붙잡으면 구속(−6/초) → 게이지 14 → 봉인 문서 강제 뿌리침(팔 길이 안 아군 전원 24u 밀림 + 0.6초 굳음). 성문 72u 가 지킴 0~1명 상태가 되고, 운반자는 이미 문턱 바로 앞이라 굳음이 풀리기 전에 넘어간다. 브리프 8-5 의 "잡았다고 생각한 순간 놓친다"가 **"놓치고 바로 진다"**가 된다.

**근거.**

| 첫 수 (0.3초 뒤) | 결과 | 구속 시작 → 봉인 문서 → 탈출 |
|---|---|---|
| 관군 2 → 북문, 여울·한결 → 남문 (브리프 6-1 "자연스러운 첫 수") | 탈출 33.3초 | 30.4 → 32.2 → 33.3 |
| 여울 → 시장뒷골목, 관군 2 → 북문, 한결·소운 → 남문 | 탈출 34.0초 | 31.5 → 33.0 → 34.0 |
| 같은 첫 수를 1.0초 늦게 (사람 손으로 현실적인 속도) | 탈출 34.4초 | 30.4 → 32.8 → 34.4 |
| 여울·관군 2 → 북문 (3명), 한결·소운 → 남문 | **제압 42.2초** | 29.3 → 31.3 → (궁지로 ③까지 도망) → 42.2 |

북문에 몸이 3명이면 한 명이 밀려도 2명이 남아 닫혀 있어 이긴다. 2명이면 거의 진다.

**가능한 선택지.**
- (a) 그대로 둔다 — "성문에서 붙잡지 말고 성문 앞에서 끊어라"를 배우는 실패로 본다. 단 첫 판 실패 원인이 "내 판단"으로 읽히는지(H3) 확인 필요.
- (b) 강제 뿌리침 뒤 운반자가 장부를 줍느라 1초 멈춘다 (지킴이 돌아올 틈).
- (c) 강제 뿌리침은 붙잡은 사람만 밀고, 지킴(guard) 상태로 성문 자리에 선 사람은 밀지 않는다.
- (d) 성문 선 72u 안쪽에서는 봉인 문서가 나오지 않고, 성문을 벗어난 뒤 나온다.

## 2. [2차 수정으로 해소] 북문 첫 명령 여유 "+1.4초"는 성문을 닫을 수는 있지만 운반자를 돌려보내지는 못한다

**문제.** 6-1 표대로 관군은 운반자보다 1.4초 먼저 북문 지킴 자리에 닿는다. 그런데 운반자는 1초마다 길을 다시 보고, 바꾸기 전 0.8초 예고가 있다. 성문이 닫혔다는 것을 알아챌 때 운반자는 이미 북문 앞 마당(성문까지 약 60u)에 있어, 돌아서기 전에 두 번째 관군과 몸이 닿아 혼자 붙잡기·뿌리침이 성문 안에서 벌어진다 → 1번 문제로 이어진다.

**근거.** 첫 명령 지연별 결과(관군 2 → 북문, 여울·한결 → 남문): 0.3초 → 탈출 33.3초 / 1.0초 → 탈출 34.4초. 명령판 30% 시간 안에서 사람이 관군 두 명 + 인물 두 명에게 명령하는 데 실제 QA 입력으로 게임 시간 약 2.0초가 걸렸다 (`playlog-run1.json` 의 commands: 0.18 / 0.62 / 1.05 / 1.48 / 2.03초).

**가능한 선택지.**
- (a) 그대로 둔다 — 3명을 북문에 보내거나(1번 표 4행), 여울을 먼저 보내는 등 "앞질러 끊기"를 찾아야 이기는 구조로 본다 (H1 과 맞음).
- (b) 운반자 등장 위치나 시장 넓이를 조금 늘려 여유를 +3초 이상으로 (브리프 38장 "HP 부터 높이지 말고 등장 위치·거리를 조정").
- (c) 성문이 닫힌 걸 "보는" 거리를 늘린다 (예: 성문 지킴이 등롱 빛 안에 있으면 멀리서도 계산에 들어감 — 지금도 들어가 있으나 몸이 늦게 닿는 문제라 효과 적음).

## 3. [2차 수정으로 해소] 6-1 표의 큰길 경로 N2·S2 는 서로·관군 표와 동시에 성립하지 않는다

**문제.** 표의 관군 → 북문 930u 는 광장 (180,960) 에서 큰길을 곧게 올라간 거리다. 같은 곧은 큰길이면 N2(시장 → 큰길 → 북문)는 1190u 가 아니라 약 1140u 이고, 시장이 중앙 가로골목 높이(y≈1060)에서 큰길로 열려 있으면 S2 는 약 27.7초로 **N1(28.8초)보다 빨라** 운반자가 처음부터 큰길 남쪽으로 간다 (표의 "처음 고르는 길 N1" 과 모순).

**구현에서 고른 것.** 시장은 큰길과 **광장 쪽 60u 어귀(시장 어귀 매듭)로만** 통하게 했다 (나머지 시장 서쪽은 담). 그러면:

| 경로 | 설계값 | 구현 측정 |
|---|---|---|
| N1 | 28.8 | 29.2 (지킴 선 도착, 실제 이동) |
| S1 | 29.5 | 29.9 |
| N2 (광장 관군 벌점 포함) | 40.2 | 40.1 (비용) |
| S2 | 30.1 (벌점 없음) | 약 34.5 + 광장 관군 벌점 11 |

N1 첫 선택, S1 이 0.7초 차 두 번째, 관군이 N2 를 막는 구조는 유지된다. S2 만 표보다 4.4초 느리고 광장 관군 벌점도 받는다.

**가능한 선택지.** (a) 지금 배치를 확정 (b) 중앙 가로골목을 시장까지 이어 S2 를 30초로 맞추고, 대신 운반자 시작점을 시장 동쪽 끝으로 옮겨 N1 이 계속 첫 선택이 되게 (c) 표에서 S2 값을 34.5 로 고친다.

## 4. [남음 — 2차 수정에서 원문 유지로 확정] 객사에서 "가장 가까운 동료가 한마디" — 원본 대사가 없다

**문제.** 브리프 7-1 은 살필 때마다 가장 가까운 동료가 한마디 하라고 하지만, `specs/chapter5.md` 에는 조사 지점별 동료 대사가 없다. 대사는 원본 그대로여야 하므로 새로 쓰지 않았다.

**구현.** 가장 가까운 동료 머리 위에 말 없는 반응 말풍선 "…"(출입패 걸이는 "…!")만 띄우고, 사실 내용은 사건 수첩 한 줄(UI 문구)로만 보여 준다.

**가능한 선택지.** (a) 그대로 (b) 기획자가 4줄(빗장·창·보따리·출입패 걸이)을 써 준다 (c) 시작 대사 6줄 중 맞는 줄을 다시 쓴다 (빗장 → 한결 "문은 안에서 잠겨 있었다고 합니다." 등 — 반복이라 비추천).

## 5. [2차 수정으로 해소] "궁지"의 시작 시점

**문제.** 8-2 규칙 7 은 "성문 길이 없으면 막다른 갈래로 도망쳐 웅크림 = 궁지", 8-3 은 "궁지 상태에서 1명 이상이면 구속". 궁지가 **길이 끊긴 순간**부터인지 **막다른 갈래에 웅크린 뒤**부터인지 비어 있다.

**구현.** 길이 끊긴 순간부터 궁지로 본다 (그래서 막다른 갈래로 도망가는 도중에 한 명만 붙어도 구속된다). QA 승리 판에서는 북문 지킴 3명이 성문 안에서 운반자를 궁지+구속해 게이지 28 → 14 까지 깎았다.

**가능한 선택지.** (a) 그대로 (b) 막다른 갈래 사각형 안에 들어간 뒤부터만 궁지.

## 6. [2차 수정으로 해소] 명령판 30% 시간은 "열 때마다" 다시 3초 — 초상을 연달아 누르면 계속 느린 시간

**문제.** 브리프 4장 "명령판이 열려 있는 동안 시간 30% (최대 3초)". 구현은 명령판을 **열 때마다** 3초를 다시 준다. 그래서 초상 → 매듭 → 초상 → 매듭 … 을 이어 가면 사실상 계속 30% 시간으로 명령할 수 있다.

**근거.** QA 첫 판: 관군1·관군2·여울·한결·소운 5명 명령에 실제 약 7초가 걸렸고 게임 시간은 2.02초만 흘렀다 (`qa-shots/2d-pilot/playlog-run1.json` commands). 이 여유 덕분에 2번 문제(북문 +1.4초)가 사람 손으로도 풀린다 — 이 규칙을 좁히면 2번이 더 어려워진다.

**가능한 선택지.** (a) 그대로 (명령을 여러 개 내리는 게 "지휘하는 맛") (b) 3초 한도를 추격 전체 또는 N초 창 안에서 합산 (c) 느린 시간은 초동 명령판에만.
| 갈래 ① 마당 모서리 | — | 마당 오른쪽 위와 중앙 가로골목이 만나는 곳에 둥근 모서리 땅 (x 80~150, y 1060~1095) 추가 | 구현 검수 E-1. 대각선 입력이 30u 골목(몸 24u → 유효 폭 6u) 입구에서 멈추던 문제. 아래 가장자리를 1095 로 맞춰 큰길 단면 폭(S2 시작 막힘)은 바꾸지 않음 |
| 벽 미끄러짐 | 브리프 6장 "미끄러지듯" | 막히면 ① 서 있는 길 안에서 제 속도로 벽을 따라 ② 안 되면 골목 입구 쪽 옆걸음 ③ 방향을 20~80° 틀어 보기 | 구현 검수 E-1. 추격 시작 네 자리 북동·북북동 2초 이동 66~88u. 큰길 가운데에서 정동쪽은 시장 담(평평한 벽)이라 20~44u 에서 멈추는 게 맞다 |
