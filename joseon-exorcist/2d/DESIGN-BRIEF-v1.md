# DESIGN-BRIEF — 조선 퇴마전 2D 파일럿 「사라진 장부」

> **검증할 질문 하나:** 조선 퇴마전이 격자판을 복제한 것이 아니라 **격자 없는 2D 게임**으로 실제로 더 재미있을 수 있는가.
> 세로 슬라이스 1개 = 스테이지 1개(큰고을의 밤) · 플레이 루프 1개 · 핵심 재미 1개.
> 스토리 기준: `specs/chapter5.md`. 이 문서는 5장을 **2D에 맞게 다시 짠 것**이고, 사건·진실·대사·나루터 훅은 그대로 둔다.

---

## 1. 장르

**최종 선택: 탑다운 2D 액션 어드벤처 (조사 + 추격·차단). 직접 조종 1명 + 길목에 세우는 동료.**

| 후보 | 판단 | 이유 |
|---|---|---|
| **탑다운 액션 어드벤처 (조사+추격)** | **채택** | 골목·큰길·성문을 한눈에 내려다봐야 "어디를 끊을지"가 판단된다. 조사(돌아다니며 살핌)와 추격(몸으로 길 막기)을 같은 조작 하나로 한다 |
| 탑다운 스텔스 추격 | 일부만 흡수 | "어둠 속에서는 운반자가 실루엣과 발소리만 보인다" 한 가지 규칙만 가져온다. 들키지 않기 게임이 되면 5장의 "포위"가 흐려진다 |
| 탑다운 조사+체이스 (조종 없는 지휘형) | 기각 | 네 명을 모두 명령으로만 움직이면 격자판 턴제를 실시간으로 바꾼 것에 가깝다. 손맛이 없다 |
| 사이드뷰 | 기각 | 골목이 옆으로 이어지는 도시 구조(북문↔남문, 가로골목)가 한 줄로 눌려서 "길목 선택"이 사라진다 |

한 줄: **밤의 큰고을을 직접 뛰어다니며 흔적을 쫓고, 동료를 골목에 세워 장부 운반자를 막다른 곳으로 몰아 붙잡는 탑다운 추격극.**

### 1-1. 왜 이 방향이 조선 퇴마전에 맞는가
- 5장의 질문이 "누구를 쫓게 하고, 누구를 길목에 세울 것인가"다. **내가 쫓는 사람 1명 + 길목에 세운 사람들** 구조가 그 질문을 그대로 손가락 조작으로 만든다.
- 퇴마전의 적은 늘 "눈앞의 괴물"보다 "사건의 흐름"이었다(3장 전멸이 정답 아님, 4장 공간 통제). 실시간 추격은 잡아야 할 것이 **괴물이 아니라 사람과 경로**라는 걸 몸으로 느끼게 한다.
- 수사물(조사) → 인간의 배신(관리) → 괴이의 전조(귀화) → 더 큰 괴이 예고(나루터)로 가는 흐름이 한 판 안에 들어간다.

## 2. 핵심 재미 (1문장)

**도망치는 사람이 갈 길을 먼저 읽고, 동료를 골목에 세워 길을 하나씩 끊은 뒤, 마지막 막다른 곳에서 둘이 함께 붙잡는 맛.**

- 제압 게이지는 **둘 이상이 함께 붙잡았을 때(또는 궁지)만** 줄어든다 (8-3). 혼자 쫓기·원거리 사격으로는 게이지가 0에서 움직이지 않는다.
- 그래서 매 순간 "지금 내가 뛸까 / 누구를 어디에 세울까 / 누구로 갈아탈까"를 고른다.

## 3. 플레이 루프

한 판 목표: **8~12분** (첫 판). 추격에서 지면 **추격 시작부터 바로 다시** (재도전 1판 = 2~4분).

| 시간 | 단계 | 플레이어가 하는 것 | 선택 | 긴장 |
|---|---|---|---|---|
| 0:00–0:40 | 도입 | **메뉴 없이** 바로 객사 마당. 윤무겸을 조종해 걸어 들어가는 동안 시작 대사 6줄이 머리 위 말풍선으로 흐름 (기획서 6장 그대로). 방문 앞에서 "방부터 본다." → 방 안 | 걷는 방향 | 잠긴 방 |
| 0:40–2:00 | **객사 조사** | 방 안을 걸어 다니며 4곳을 살핀다 | 어느 것부터 볼지. 3곳을 보면 결론이 열림 | 사건 수첩이 채워짐 |
| 2:00–4:00 | **뒷골목 조사** | 객사 뒤 골목으로 나가 흔적을 따라간다. **이 골목이 추격 맵이다** | 갈래길에서 어느 쪽으로. 동료를 다른 갈래로 보낼지 | 지붕 위 청백 불티가 잠깐 보였다 사라짐 (설명 없음) |
| 4:00–4:40 | **전환점 ① 관리 발견** | 골목 깊은 곳 관리에게 다가가면 대화 (기획서 12장) | — | "장부요." |
| 4:40 | **전환점 ② 운반자 등장** | 시장 쪽 소란 → 카메라가 실제로 시장까지 이동 → "저 자요!" → **초동**: 명령판이 저절로 열리고 시간 30% | 첫 명령: 누구를 어느 문 쪽으로 | 두 성문까지 남은 거리 막대가 나타남 |
| 4:40–8:00 | **추격 (본게임)** | 한 명을 직접 조종해 뛰고, 나머지를 길목에 세우고, 운반자를 궁지로 | 뛰기/세우기/갈아타기/기술 | 운반자 → 성문 거리, 제한 시간 3:00 |
| (제압 게이지 절반) | **전환점 ③ 봉인 문서 낙하** | 붙잡았던 운반자가 뿌리치고, 장부 한 장이 떨어지고, 귀화 2마리 등장 (기획서 19장) | 귀화를 치울지, 버티고 다시 쫓을지 | 잡았던 것을 놓침. 세워 둔 성문이 흔들림 |
| 8:00–10:00 | **제압 → 장부 → 나루터** | 대사 (23·24·26장 그대로) → 암전 → "제6장 — 잠김" | — | 뜯긴 한 장, 배 밑의 두드림 |

- 조사(약 3분) < 추격(약 3~4분 + 재도전). 기획서 37장 "후반 추격에 시간이 더 많이" 유지.
- **다시 해보고 싶은 이유:** 진 판은 "어디를 안 막았는지"가 결과 화면 경로선으로 보인다 → 다른 배치·다른 조종 인물로 바로 재도전.

## 4. 조작 (모바일 세로, 360px 폭 기준)

**결정: 플로팅 가상 스틱 (이동) + 오른쪽 버튼 1~2개 + 아래 초상 줄 + 명령판.**

| 입력 | 어디서 | 하는 것 |
|---|---|---|
| **왼엄지 드래그** | 화면 아래 왼쪽 절반 아무 곳 (누른 곳이 스틱 중심) | 조종 중인 인물 이동 (360° 연속, 누른 거리만큼 속도) |
| **행동 버튼** (큰 원, 오른쪽 아래) | 오른엄지 | 가까운 것에 맞춰 바뀜: 살피기 / 대화 / **붙잡기** / 치기(귀화) |
| **기술 버튼** (작은 원, 행동 위) | 오른엄지 | 한결·소운을 조종할 때만 보임 (8-4). 누른 채 끌면 조준선·결계선, 떼면 사용 |
| **초상 탭** | 아래 초상 줄 | 그 인물(또는 관군)의 **명령판**이 열림 (10장) |
| **명령판 매듭 탭** | 명령판 (화면 아래) | 그 인물이 그 길목까지 알아서 가서 **선다(지킴)** |
| **명령판 [조종] 탭** | 명령판 왼쪽 위 | 그 인물로 **갈아타기**. 방금 조종하던 인물은 그 자리에 **선다** |

- 버튼 수: 추격 중 버튼 **1~2개 + 초상 6개**(인물 4, 관군 2). 조사 중에는 관군 초상·기술 버튼 숨김.
- **왜 가상 스틱인가 (탭 이동이 아니라):** 추격의 손맛은 모서리를 깎아 도는 각도, 골목 입구에 몸을 대는 타이밍이다. 탭 이동은 길찾기가 대신 뛰어 줘서 그 손맛이 없고, 목적지를 누르는 손가락이 운반자를 가린다. 스틱은 화면 아래에서만 받는다.
- **동료 지시는 맵 위가 아니라 명령판에서** 끝난다. 맵 위에 손가락을 올리는 명령은 하나도 없다 → 운반자와 성문 거리 막대를 가리지 않는다.
- **[2차 수정] 명령판 느린 시간 (한 추격에 총량 제한):**
  - **초동** (운반자 등장 직후 저절로 열리는 판): 시간 30%, 실제 3초. 이 3초는 따로 준다.
  - **그 뒤 명령판 느린 시간은 한 추격에 합계 실제 6초까지.** 판이 열려 있는 동안만 줄어든다. 다 쓰면 판은 정상 속도로 열린다. 다시 채워지지 않는다 (추격을 다시 시작할 때만 초동 3초 + 6초가 새로 주어진다).
  - 판 머리에 남은 느린 시간을 가는 막대로 보여 준다. 초상을 연달아 눌러도 총량 밖으로는 느려지지 않는다.
  - 이유: 초동 3초(게임 시간 0.9초) 안에 명령 2~3개, 이어서 느린 시간 몇 초로 나머지를 넣으면 6-1 의 "게임 시간 3초 안"이 사람 손으로 된다. 느린 시간이 무한이면 첫 30초의 판단 압박이 사라진다.
- 명령판이 열려 있는 동안 조종 중인 인물은 멈춰 선다.
- 조종하지 않는 인물: 서 있음(지킴). 몸으로 길을 막는다. 운반자가 팔 길이 안에 오면 **자동 붙잡기**, 귀화가 붙으면 **자동 반격**만 한다. 기술은 안 씀 → 기술을 쓰려면 그 인물로 갈아타야 한다 = 선택.

## 5. 카메라

- **탑다운 (약간 기울인 3/4 지붕)**. 확대 고정 (핀치 없음). 보이는 영역 ≈ 360u × 약 300~470u (맵 높이의 1/5~1/7).
- 기본: **조종 중인 인물**을 맵 영역 높이 45% 지점에 둔다.
- **명령판이 열리면 카메라는 운반자로** 옮겨 가 운반자와 진행 방향 화살표를 명령판 위 영역 가운데에 둔다. 닫으면 조종 인물로 돌아옴.
- 운반자가 화면 밖이면: 화면 가장자리에 **주황 화살표 + 거리**.
- 오른쪽 가장자리 **세로 도시 띠(미니맵, 폭 28px)**: 북문·남문·운반자·아군·관군 점. 보기 전용.
- 연출용 이동 2번만: 운반자 등장(시장으로 이동, 기획서 13장 "카메라 이동"을 실제로 함), 봉인 문서 낙하(그 자리로 짧게).

## 6. 공간 구조

맵은 **세로로 긴 도시 한 장**. 위 = 북문, 아래 = 남문 → 세로 화면과 방향이 맞는다.

**단위 한 줄:** 1u = 360폭 화면에서 CSS 1px. **충돌 지름 24u** / 그림 토큰 36u(충돌보다 크게 그리고 발밑 원 24u 로 판정을 보여 줌) / 지킴 폭 36u / 통과에 필요한 최소 틈 28u / **골목 30u** (몸 1개가 지나감, 누구든 서 있으면 틈 ≤ 6u 라 막힘) / **성문 72u** (지킴 2명 = 막힘, 1명 = 틈 36u 라 뚫림) / **큰길 120u** (지킴 3명이어야 막힘).

맵 **360u × 2160u**. 좌표 (x, y), 위가 y=0.

     서쪽골목 ┃  관아 뒤 막다른 갈래(③)              ┃ 시장뒷골목

| 공간 | 폭 | 게임에서의 쓰임 |
|---|---|---|
| **큰길** | 120u | 빠르지만 **관군 2명으로도 못 막는다** (3명 필요). 한결의 긴 사격선이 나오는 곳 |
| **골목** | 30u | **누구든 한 명이 있으면 완전히 막힌다** (지킴이 풀려도 몸만으로 막힘). 대신 어둡다 |
| **가로골목 A·중앙·C** | 30u | 동↔서 갈아타는 길. 여기를 끊으면 운반자가 한쪽 편에 갇힌다 |
| **성문** | 72u | 지킴 2명(또는 지킴 1명 + 결계)이어야 닫힌다 |
| **시장** | x 240~360, y 900~1200 + 좌판(통과 불가) | 모두 이동 −30%. 사격선이 좌판에 가림. **[2차 수정]** 큰길과는 광장 쪽 **시장 어귀**(x 200~270, y 900~960)로만 통한다. 나머지 서쪽은 담 (구현 DESIGN-ISSUES 3번 (a) 확정) |
| **막다른 갈래 ①②③** | 30u | 운반자는 스스로 들어가지 않는다. **궁지**(8-2 규칙 7)일 때만 도망쳐 들어감. ①은 관리가 숨은 곳 |
| **건물** | — | 통과 불가. 모서리가 둥글어 미끄러지듯 돌아감 (격자 모서리에 걸리지 않게) |

- **탈출 경로:** 북문 2갈래(큰길 북쪽 / 시장뒷골목), 남문 2갈래(큰길 남쪽 / 창고골목) + 서쪽 골목들이 가로골목으로 이어짐. **한 몸으로 두 성문을 동시에 끊는 지점은 없다** (기획서 16·38장).
- **공간이 게임에 쓰이는 방식 = "폭" 규칙 하나:** 좁은 곳은 한 몸으로 닫히고, 넓은 곳은 여러 몸이 필요하다. 그래서 "몇 명을 어디에"가 매번 다른 답이 된다.

### 6-1. 추격 시작 수치 (한 장으로 맞춘 표)

**[2차 수정]** 이전 표의 문제 세 가지를 고쳤다.
- (a) 관군 여유 1.4초가 운반자 재계산 1초 + 예고 0.8초보다 짧았다.
- (b) 파티가 서쪽 끝에서 출발해 동쪽 골목에 먼저 닿을 수 없었다.
- (c) 큰길 경로 N2·S2 값이 관군 930u 와 동시에 성립하지 않았다.

아래 값은 모두 `core.js` 복사본 시뮬레이션(1/60초)에서 **측정한 값**이다 (재현 방법은 6-2).

**아군 근처 벌점** (규칙은 그대로, 작동 방식만 명확히):
- 남은 경로가 어떤 아군(인물·관군)의 72u 안을 지나면 1명당 +5.5초.
- 1초마다 다시 계산하고, 새 길이 3초 이상 나을 때만 바꾼다 (바꾸기 0.8초 전 예고).
- 운반자가 1초 달릴 때마다 지금 길은 1초 짧아지고 반대편 길은 약 1초 길어진다. 그래서 **벌점만으로 방향을 바꾸는 건 출발 직후(약 1초 안)뿐**이다. 그 뒤에 길을 바꾸게 하는 것은 **몸으로 막은 길(∞)** 이다.

**두 성문이 실제 선택지인가:**
- 파티는 두 성문 지킴 자리까지 차이가 0.4초 안이다. 운반자의 N1·S1 차이는 0.7초다.
- 관군만 북쪽(25.0 / 36.8)으로 치우쳐 있다. → "관군은 북문이 가깝고, 남문은 인물이 막아야 한다"는 비대칭이 첫 판의 판단거리다.
- 어느 성문도 처음부터 반쯤 막혀 있지 않다. S2 막힘은 경로 하나일 뿐, 남문 자체는 S1 으로 열려 있다.

**첫 명령 시각 t(게임 시간)에 따른 결과 — 관군 2 → 북문 기준 (관군 도착 25.0 + t, 운반자 29.2):**

| t | 무슨 일이 생기나 | 결과 |
|---|---|---|
| ≤ 3초 | 관군이 먼저 서고, 운반자가 재계산 + 예고(1.8초) 안에 **돌아선다** (몸이 닿기 전) | 남문도 인물이 막았으면 → 궁지 → 제압 |
| 4~5초 | 돌아서기 전에 **성문 앞에서 부딪혀 구속**된다. 8-5 성문 구역 규칙 때문에 뿌리치지 못한다 | 제압 (성문 앞) |
| ≥ 6초 | 관군이 닿기 전에 운반자가 성문 선을 넘는다 | 탈출 |

여울+한결 → 북문도 같은 모양이다. 나중에 닿는 한결(25.1 + t)이 관군(25.0 + t)과 거의 같은 시각에 닿도록 시작 위치를 맞췄다.

**골목 끊기가 경로를 바꾸는 예:**
- 여울 → 시장뒷골목(E1) 명령을 0.3초에 넣으면, 여울이 16.8초에 가로골목 A 동쪽 끝에서 골목에 들어선다.
- 그 순간 N1 이 막혀(∞) 운반자는 가로골목 A → 큰길 북쪽(N2)으로 길을 바꾼다.
- 여기에 관군 2 → 북문, 한결·소운 → 남문을 더하면 궁지 → 제압 (49.1초).

**그 밖의 수치:**
- **아무것도 안 하면** 29.9초에 북문으로 탈출한다.
- 제압 시간 (시뮬레이션): 성문 앞 구속 33~36초, 돌려보낸 뒤 궁지 제압 45~60초.
- 첫 판 목표 1분 30초~3분. 제한 시간 3:00 (변경 없음).

## 7. 조사 (반복 심부름이 되지 않게)

원칙: **걸어 다니는 게 곧 조사이고, 조사하며 본 길이 추격 때 쓰는 길이다.** 조사 지점은 객사·뒷골목 2곳뿐 (기획서 38장).

### 7-1. 객사 (한 화면 방 안)
- **윤무겸만 조종.** 한결은 문 옆, 여울은 창 옆, 소운은 방 가운데에 서 있다 (움직이지 않음, 초상 잠김). 윤무겸이 무언가를 살피면 가장 가까운 동료가 한마디.
- 방 안을 스틱으로 걷는다. 가까이 가면 대상이 은은히 빛나고 행동 버튼이 "살피기"로 바뀐다.
- 살필 곳 4개: **빗장**(안에서 걸림) / **창**(닫힘) / **보따리**(물건 그대로, 핏자국 없음) / **출입패 걸이**(비어 있음).
- 살필 때마다 화면 위 **사건 수첩**에 한 줄씩 쌓인다.
- 3곳을 살피면 수첩 맨 아래가 "귀신이 데려갔다 → ?"에서 **"스스로 나갔다"**로 바뀌며 대사 (한결 "끌려간 사람치곤…", 윤무겸 "스스로 나갔다는 건가."). 출입패 걸이는 3곳 안에 반드시 포함돼야 결론이 난다 (나머지 순서 자유).
- 진전 느낌: 목표 문구가 "관리의 흔적을 찾아라 → 객사 밖으로 나간 길을 찾아라"로 바뀌고, **뒷문 밖 땅에 첫 발자국이 켜진다.**

### 7-2. 뒷골목 (추격 맵의 서쪽·가운데 절반)
- 동료 3명은 조종 인물 뒤를 **한 줄로 따라온다** (몸 1개 간격). 명령판에서 갈래 매듭을 누르면 그 인물만 그리로 가서 서고, **[따라와]** 를 누르면 다시 줄에 붙는다. 조종 갈아타기도 가능.
- 흔적은 **아군 누구든** 가까이(반경 60u) 가면 보인다: 발자국 → **관청 문서 조각** → 무언가를 끌고 간 자국.
- 흔적 하나를 찾으면 **다음 흔적 방향으로 희미한 선**이 잠깐 그어진다. 헤매지 않지만 직접 뛰어가야 한다.
- **갈래길 1곳 (가로골목 A 서쪽):** 흔적이 두 갈래로 보인다. 한쪽은 관아 뒤 막다른 갈래 ③. 동료를 다른 갈래로 보내면 동시에 확인 → **"사람을 나눠 세우는" 명령판 조작을 여기서 처음 배운다.** 막다른 갈래도 헛걸음이 아니라, 추격 때 운반자가 궁지에 몰려 도망칠 곳을 미리 보여 준다.
- 문서 조각을 찾으면 소운 "뭔가를 들고 나갔군." → 목표 "골목 깊숙이 숨은 관리를 찾아라".
- 조사 중 괴이 전조: 가로골목 A 지붕 위에 청백 불티가 한 번 보였다 꺼진다. 설명 없음.
- 금지: 랜덤 단서, 범인 고르기, 추리 퍼즐 (기획서 39장). 단서 순서는 고정.

### 7-3. 관리 대화와 추격 시작 위치
- 관리는 막다른 갈래 ① 안쪽 (40,1160)에 웅크려 있다. 공격 불가, 움직이지 않음.
- **아군 누구든** 관리 48u 안에 들어가면 대화 시작. 대화 전에 나머지 동료는 1.5초 화면 전환(어둑해졌다 밝아짐)으로 **관리 앞에 모인다** — 대사에 윤무겸·소운·한결이 모두 나오기 때문.
- **[2차 수정]** "저 자요!" 뒤 카메라가 시장으로 가는 동안(연출 약 1.5초) 네 명은 **큰길 가운데(중앙 가로골목 어귀)** 로 뛰어나오고, 관군 2명은 광장 북쪽에 선다. 관리는 갈래 ① 에 남는다. 추격은 항상 6-1 표의 고정 좌표에서 시작한다. 조사를 어떻게 했든 같다 (공정한 재도전, 기록 비교).

| 심부름이 아닌가 | 같은 길을 되돌아가는 구간 0. 모든 이동이 다음 단서 쪽으로 전진 |
| 길이 | 객사 ≤ 80초, 뒷골목 ≤ 120초 |

| 5 | 아군이 72u 안에 오면 비켜 달림 = **숨** −25 (숨 100). 숨 0이면 3초 동안 걷는다(22u/초) 후 숨 100 | 몰아붙이면 걷는 3초가 생긴다 |
| 6 | 틈이 28u 이상이면 지나간다. 큰길 한 명·성문 한 명은 옆으로 지나침. **골목 안 사람·성문 두 명·결계는 못 지나감** | 폭 규칙 |
| 7 | 어느 성문으로도 길이 없으면 → 가장 가까운 막다른 갈래(①②③)로 도망쳐 웅크림 = **궁지**. **[2차 수정] 궁지는 "운반자가 이미 지나친 몸(진행 방향 뒤쪽 몸)을 빼고 계산해도 어느 성문으로도 길이 없어진 순간"부터 시작한다** (막다른 갈래에 들어가기 전부터. 길이 다시 열리면 즉시 풀리고 0.8초 예고 후 달아남) | 포위 완성 신호 |

### 8-3. 붙잡기 · 제압 (죽지 않음)

**제압 게이지 28** (기획서 HP 28을 게이지로). 0이 되면 **제압** — 운반자는 쓰러지지 않고 주저앉는다.

| 상황 | 게이지 | 결과 |
|---|---|---|
| **혼자 붙잡기** (팔 길이 36u 안에 아군 1명) | **변화 없음 (0)** | 운반자 0.4초 멈춤 → 뿌리침: 붙잡은 쪽이 24u 밀리고 0.6초 굳음. 운반자 숨 −25 |
| 원거리 (한결 견제사격) | **변화 없음 (0)** | 4초 동안 −40% 느려짐만 |
| **구속** = 팔 길이 안에 아군(인물·관군) **2명 이상**, 또는 **궁지** 상태에서 1명 이상 | **초당 −6** (조종 인물이 행동 버튼 연타 시 초당 −9) | 약 3~5초에 제압. 구속 조건이 깨지면 즉시 뿌리치고 달아남 (게이지는 회복 안 됨) |

- **"한 명이 뒤쫓기만"으로는 이길 수 없다:** 게이지가 줄어드는 유일한 조건이 구속인데, 혼자서는 구속이 안 된다. 궁지를 혼자 만들 수도 없다 — 한 몸으로 막히는 곳은 골목·막다른 갈래 입구뿐인데, 운반자는 막다른 갈래에 스스로 들어가지 않고(규칙 7), 골목 한 토막에 가두려면 양쪽 끝에 한 명씩 **2명**이 필요하다.
- **"원거리 공격만"으로도 이길 수 없다:** 견제사격의 게이지 효과는 0이다. 사격은 **시간을 버는 도구**다.
- 혼자 붙잡기도 쓸모는 있다: 숨을 깎아 **걷는 3초**를 만들고, 그 사이 두 번째 사람이 도착한다. → **"한 명이 몰고, 한 명이 기다린다."**

### 8-4. 인물 · 관군 역할 (첫 빌드: 고정 기술 2개)
| 인물 | 첫 빌드 능력 | 추격에서의 역할 |
|---|---|---|
| 윤무겸 | 기술 없음. 운반자와 같은 속도, 체력 30 | 처음 조종하는 몸. 붙잡기·귀화 치기 |
| 여울 | 기술 없음. **가장 빠름 (50)** | 먼 길목에 먼저 도착 / 운반자에게 붙어 숨 깎기 |
| 한결 | **견제사격**: 끌어서 조준, 직선 사거리 200u. 건물·좌판에 가리면 못 쏨. 맞으면 운반자 4초 −40%. 재사용 10초 | 큰길 반대편에서 사선을 잡아 **시간을 번다** |
| 소운 | **결계**: 끌어서 선을 긋는다 (최대 45u). 12초 동안 운반자·귀화 통과 불가. 재사용 15초 | 골목 하나를 닫거나, 성문을 지킴 1명 + 결계로 닫기 |
| 관군 ×2 | 명령판으로만 움직임. 싸우지 않음(귀화에게 반격 못 함). 구속 인원에는 들어감 | 성문 하나를 통째로 닫거나 골목 두 개를 끊는 **길목 병사** (기획서 17장) |

- 기술은 **조종 중인 인물만** 쓴다 → "견제사격 하려면 한결로 갈아타야 하고, 그 순간 윤무겸은 그 자리에 선다".
- 기획서 18장의 수련 2택 1(8종)은 **다음 단계**로 미룬다 (부록 B).

### 8-5. 전환점 ③ 봉인 문서와 귀화
- 조건: 제압 게이지 14 이하 (기획서 확정: HP 절반). 게이지는 구속 중에만 줄기 때문에 **이 사건은 항상 "잡았다" 싶은 순간에 온다.** 파일럿 한정 보조: 추격 2분 30초가 지나도 안 나왔으면 그때 발생 (모든 테스터가 이 장면을 보게).
- 연출: 운반자가 구속을 **강제로 뿌리침**(팔 길이 안 아군 전원 24u 밀림) → 장부 한 장이 떨어짐 → 짧은 줌 → 소운 "그건 평범한 장부가 아니오." / "봉인에 쓰던 문서요."
- **[2차 수정] 성문 구역 예외:** 게이지 14 에 닿은 곳이 **성문 선에서 200u 안**(북 y < 200, 남 y > 1960)이면 **뿌리치지 못한다.** 문서는 떨어지고 귀화도 나오지만 구속은 그대로 이어진다.
  - 이유: 성문 앞에서 뿌리치면 지킴이 밀려 문이 열리고 1~2초 안에 탈출한다. 둘이 제대로 잡은 플레이어가 "왜 놓쳤지?"로 읽는다 (H3). "잡았다 놓친다"는 성문에서 먼 곳에서만 일어난다.
- **[2차 수정] 귀화 피어오름 2.5초:** 귀화는 나타난 뒤 2.5초 동안 움직이지도 치지도 않는다 (청백 불이 피어오르는 연출).
  - 성문 앞 구속은 게이지 14 → 0 에 약 2.3초(연타 시 1.6초)라서, 구속을 놓지 않으면 귀화가 움직이기 전에 끝난다.
  - 성문에서 먼 곳에서는 뿌리친 운반자를 다시 쫓을 2.5초의 틈이 된다.
- 귀화 2마리: ① 문서가 떨어진 자리, ② **운반자에게 가장 가까운 "서 있는" 아군**(관군 포함) 옆.

| 항목 | 값 |
|---|---|
| 귀화 체력 | 12 |
| 귀화 공격 | 2초마다 붙은 아군 1명에게 피해 4 + **48u 밀어냄 + 1초 굳음**. 밀린 아군은 굳음이 풀리면 제자리로 걸어 돌아감 |
| 아군 체력 | 윤무겸 30 / 한결 24 / 여울 34 / 소운 22 / 관군 20. 회복 없음. 0 = 퇴장 (그 자리에서 빠짐, 길을 막지 않음) |
| 치우는 기본 수단 | **누구나**: 조종 인물은 행동 버튼 "치기" (피해 4, 0.4초 간격 → 약 1.2초에 퇴송). 조종하지 않는 **인물**은 굳지 않은 동안 1.2초마다 자동 반격 4. **관군은 반격 못 함** |
| 귀화 몸 | 아군은 못 지나가고, 운반자는 지나간다 |
| 퇴송 후 | 다시 나오지 않음. 전멸은 승리 조건 아님 |

**귀화를 무시해도 되는가 (인물 구성과 상관없이 이렇게 읽힌다):**
| 귀화가 붙은 곳 | 무슨 일이 생기나 | 판단 |
|---|---|---|
| **골목**을 지키는 아군 | 48u 밀려도 대부분 골목 안 → 몸만으로 계속 막힘 | **무시하고 버틸 수 있다** |
| **성문·큰길**을 지키는 **인물** | 밀려난 동안 성문에 틈이 생김. 자동 반격으로 약 6초 뒤 스스로 퇴송 | **6초 동안 문이 열린다.** 운반자가 가까우면 치워야 한다 |
| **관군** (어디든) | 반격 못 함 → 계속 밀리고, 약 10초(5대) 뒤 관군 퇴장 = 그 길목이 영영 빔 | **반드시 치워야 한다** |

- **전원 퇴장 패배와의 관계:** 귀화 1마리는 초당 최대 2의 피해. 인물 4명 체력 합 110. 두 마리를 끝까지 무시해도 인물 전원이 쓰러지기 전에 자동 반격으로 퇴송된다 → **전원 퇴장은 사실상 일어나지 않는다.** 규칙으로만 남긴다 (기획서 22장). 귀화의 진짜 위협은 **"세워 둔 길목을 여는 것"**이다.

## 9. 실패 / 압박 구조

| 패배 | 조건 | 플레이어가 느끼는 원인 |
|---|---|---|
| **탈출** | 운반자가 북문 또는 남문 선(y=0 / y=2160)을 넘음 | "저 길을 안 막았다" |
| **시간 초과** | 추격 제한 시간 3:00 | "몰기만 하고 둘이 붙잡지 못했다" |
| **전원 퇴장** | 인물 4명 체력 0 | 규칙상만 존재 (8-5) |

압박을 만드는 것:
- 화면 위 **성문 거리 막대 2개** (북 ▲ / 남 ▼) — 운반자가 다가가는 쪽이 붉어지고 맥박처럼 뛴다. 절반 이하에서 심장 소리.
- **[2차 수정]** 첫 명령을 게임 시간 3초 안에 넣으면 돌려보내고, 4~5초면 성문 앞에서 겨우 잡고, 6초 넘으면 놓친다 (6-1). **먼저 읽은 사람이 이긴다.**
- 혼자 붙잡으면 뿌리친다. 구속이 깨지면 바로 달아난다.
- 전환점 ③: 잡았다고 생각한 순간 놓치고(성문 구역 밖), 2.5초 뒤 귀화가 움직여 성문 지킴을 흔든다.
- 퇴장한 인물은 그 자리에 주저앉아 빠진다. 조종 중이던 인물이면 다음 인물로 자동 전환.

지면: 짧은 컷 — 운반자가 성문 밖 어둠으로 사라짐 → **이번 판 운반자 경로선 + 내가 세운 자리**를 맵 위에 겹쳐 보여 줌 → [추격부터 다시]. 조사는 다시 하지 않는다.

## 11. 아트 / 비주얼 방향

| 항목 | 방향 |
|---|---|
| 시점 | 탑다운에 약간 기울인 3/4. 지붕(기와·초가)의 윗면이 보이고, 사람은 살짝 앞모습 |
| 톤 | **조선의 밤. 저채도 청회색 바탕 + 등롱의 따뜻한 주황 빛웅덩이.** 사실적이지 않게, 평면 채색 + 부드러운 그림자 |
| 격자처럼 보이지 않게 | 타일 반복 금지. 길은 **이어진 곡선 띠**로 그리고 가장자리를 흙·돌 테두리로 흐리게. 건물은 크기가 제각각인 지붕 덩어리, 모서리 둥글게. 등롱 빛은 원형 그라데이션이라 격자 선이 생기지 않음. 명령판도 칸이 아니라 **길 선 위의 매듭**으로 그린다 |
| 플레이 영역 vs 장식 | **걸을 수 있는 땅 = 밝다 (길·마당)**, 못 가는 곳 = 어두운 지붕·담. 지붕 위 장식(빨래·장독)은 채도 더 낮게. 경계는 담장 선 하나로 분명하게 |

## 12. 2D 전환이라서 새로 생기는 재미 (격자를 숨긴 게 아니라는 근거)

| # | 새 재미 | 격자 턴제에서 안 되던 이유 |
|---|---|---|
| 1 | **몸의 폭으로 길을 막는다** — 골목 1명, 성문 2명, 큰길 3명. 틈이 28u 이상이면 운반자가 비집고 지나감 | 격자는 칸 하나 = 완전 봉쇄/완전 통과 둘뿐 |
| 2 | **가로채기 각도** — 운반자가 갈 곳을 향해 비스듬히 뛰어 앞을 끊는다 | 턴제는 "이동력 안의 칸"이라 각도·타이밍이 없다 |
| 3 | **동시에 일어나는 일** — 내가 뛰는 동안 관군이 걸어가고, 운반자는 돌아서고, 귀화가 온다. **[2차 수정]** 첫 명령이 게임 시간 3초 안이냐 6초 뒤냐가 승패를 가른다 | 턴제는 상대가 기다려 준다 |
| 4 | **빛과 어둠** — 등롱 아래선 운반자의 방향이 읽히고 골목 어둠에선 놓친다 | 격자판은 전부 보인다 |
| 5 | **자유 방향 기술** — 결계를 원하는 각도로 긋기, 좌판·건물 사이로 사선 찾기 | 격자는 4방향·직선 |
| 6 | **숨의 리듬** — 혼자 붙어 숨을 깎으면 운반자가 걷는 3초가 온다. 그 3초에 두 번째 사람이 닿는다 | 턴 단위로는 긴장-이완 리듬이 안 생긴다 |
| 7 | **조사 = 정찰** — 조사하며 걸은 골목이 추격 맵 그대로. 막다른 갈래를 미리 알면 이긴다 | 기존 조사는 "칸에 서면 자동" |
| 8 | **밀려나는 지킴** — 귀화에 밀려 성문에 틈이 생기는 몇 초. 골목은 버티고 성문은 흔들린다 | 격자에서는 유닛이 칸에 서 있거나 없거나 |

## 14. 플레이어에게 확인할 재미 가설

플레이 기록(JSON 한 벌, 판 끝에 화면에 표시·복사): 명령 매듭과 시각, 운반자 경로, 갈아타기 횟수, 기술 사용, 구속 시도(혼자/둘), 조사 소요 시간, 패배 원인, 재도전 여부.

| # | 가설 | 관찰 | 판단 기준 |
|---|---|---|---|
| H1 | **플레이어는 뒤쫓기보다 "앞질러 끊기"를 스스로 찾아낸다** | 추격 1분 이후 명령 매듭이 운반자 **앞쪽**(가려는 성문 쪽)인지 뒤쪽인지. 혼자 붙잡기 → 구속으로 바뀌는 시점 | 테스터 과반이 첫 판 안에 앞쪽 명령 비율 ≥ 50%. 인터뷰 "가장 고민한 순간"에 길목·골목 이야기가 나옴 |
| H2 | **"골목은 한 명, 성문은 둘, 큰길은 못 막는다" 폭 규칙이 설명 없이 읽힌다** (관군 2명이 쓸모 있게 느껴진다) | 첫 탈출 뒤 다음 판에서 관군 매듭이 큰길 → 골목/성문으로 바뀌는가. 결계를 골목·성문 중 어디에 쓰는가 | 두 번째 판에서 관군 배치의 70% 이상이 골목·성문. "관군이 도움이 됐다" 응답 과반 |
| H3 | **지면 바로 다시 하고 싶다** (실패가 억울하지 않고 내 판단 탓으로 보인다) | 패배 후 [다시]를 10초 안에 누르는 비율. 두 번째 판 첫 명령(매듭·인물)이 첫 판과 달라지는 비율 | 70% 이상이 10초 안에 재도전. "왜 졌는지 아는가" 질문에 경로로 답함 |
