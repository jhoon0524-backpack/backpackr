## A. 실제 폰 확인 (실기기)

적어 둘 것: 기기 이름 ______ / 브라우저(사파리·크롬·삼성 인터넷) ______ / 날짜 ______

| # | 화면 | 해 볼 것 | 이러면 통과 | 결과 (○ / ✕ / 메모) |
|---|---|---|---|---|
| 1 | 첫 화면 | 주소를 연다 | 제목·[시작하기]·[📖 벽사록]이 한 화면에 보인다. 옆으로 밀리지 않는다 | |
| 2 | 프롤로그 | [시작하기]를 누르고 기다린다 | 약 10초 동안 문장이 차례로 나타나고, 붉은 辟邪廳 인장이 보이고, 마지막에 [임무를 받는다]가 나온다 | |
| 3 | 프롤로그 | 한 번 더 해 보면서 중간에 화면을 누른다 | 남은 문장이 한 번에 다 나오고 버튼을 바로 누를 수 있다 | |
| 4 | 대사 | 시작 대사를 누르며 넘긴다 | 한 번 누르면 한 줄씩 넘어간다. 글씨가 잘리지 않는다 | |
| 5 | 전투 터치 | 윤무겸을 누른다 → 파란 칸을 누른다 | 한 번 누르면 선택된다. 화면이 확대되지 않는다. 유닛이 미끄러져 이동한다 | |
| 6 | 전투 화면 | 전투 중에 화면을 위아래로 밀어 본다 | 맵·[턴 종료]가 한 화면 안에 있다. 스크롤해야 보이는 곳이 없다 | |
| 7 | 스킬 대상 | 이동 후 [벽사검]을 누른다 | 버튼에 스킬 이름이 크게 보이고, 맵 아래에 "벽사검 — 대상을 고르세요"가 뜬다. 빨간 칸을 누르면 공격한다 | |
| 8 | 지형 카드 | 빈 🏮·💧·🛖 칸을 각각 누른다 | 맵 아래 카드에 이름과 효과가 나온다. 맵을 가리지 않는다 | |
| 9 | 알림 | 1장이 시작된 직후 화면 아래를 본다 | 알림이 **한 번에 하나씩** 뜬다(벽사록 → 지형 순서). 겹쳐 쌓이지 않는다 | |
| 10 | 알림 | 요괴를 쓰러뜨린다 | "○○을 퇴치했다. / 공적 +1"이 뜬다. [턴 종료] 버튼을 가려도 버튼은 눌린다 | |
| 11 | 벽사록 | 전투 중 오른쪽 위 📖를 누른다 | 한지 색 창이 뜬다. 탭을 바꿔도 창이 화면을 넘지 않는다. [닫기]·바깥 누르기로 닫힌다 | |
| 12 | 벽사록 | 항목 하나를 눌러 읽는다 | "기록 / 윤무겸의 기록 / 고증 등급" 순서로 보인다. 글이 길면 손가락으로 스크롤된다 | |
| 13 | 승리 화면 | 1장을 이긴다 | 승리 대사 → "1장 흑린 토벌 완료 · 공적 N / 8", 공적 누계·품계가 보인다. 대사가 나오는 동안 알림이 대사 상자를 가리지 않는다 | |
| 14 | 이어하기 | 1장을 이긴 뒤 브라우저를 완전히 닫았다가 다시 연다 | [이어하기 · 2장 사라진 여의주]가 보이고, 공적 누계·품계가 그대로다 | |
| 15 | 2장 | 2장을 끝까지 한다 | 무녀를 쓰러뜨리면 "제압했다 / 공적 없음", 달래를 쓰러뜨리면 "여의주를 떨어뜨리고 물러났다 / 공적 +3"(벽사청이 쓰러뜨렸을 때) | |
| 16 | 가로 화면 | 폰을 눕혀 본다 | 크게 깨지지 않는다 (세로 화면이 기준이라 참고만) | |

## B. 처음 하는 사람 플레이 기록 (1장 → 2장)

**부탁하는 법:** 게임 설명을 하지 않고 주소만 건넨다. 옆에서 보되 도와주지 않는다.
끝난 뒤 아래를 함께 적는다. 정답은 없다. 느낀 그대로 적는다.

플레이한 사람 ______ / 날짜 ______ / 기기 ______ / 걸린 시간: 1장 ____분, 2장 ____분 / 1장 결과(승·패, 몇 번 만에) ______ / 2장 결과 ______

| # | 질문 | 적는 칸 |
|---|---|---|
| 1 | 막히거나 무엇을 해야 할지 몰랐던 순간이 있었나? (언제, 어떤 화면에서) | |
| 2 | 할 일이 없어서 [턴 종료]만 눌렀던 구간이 있었나? (몇 턴째쯤) | |
| 3 | 한 번도 쓸 이유가 없었던 스킬은? (벽사검·파사궁·축지격·화염부·정화수) | |
| 4 | 너무 쉬웠던 순간 / 갑자기 어려워진 순간은? | |
| 5 | 2장에서 달래를 쫓을 때 긴장됐나? 탈출로 🌲 를 의식했나? | |
| 6 | 설명 없이 "제압(사람) / 퇴치(요괴) / 달래는 물러남"의 차이를 알아챘나? 어떻게 이해했는지 그 사람 말로 | |
| 7 | 공적과 품계(승진, 관군 합류)가 다음 전투를 하고 싶게 만드는 보상으로 느껴졌나? | |
| 8 | 벽사록(📖)을 누가 시키지 않았는데 열어 봤나? 열었다면 무엇을 읽었나 | |
| 9 | 2장이 끝난 뒤 3장이 궁금한가? 무엇이 궁금한가 | |
| 10 | (자유) 가장 좋았던 것 하나 / 가장 불편했던 것 하나 | |

지켜본 사람이 따로 적을 것: 처음 눌러 본 곳, 오래 멈춰 있던 화면, 혼잣말.
