# 조선 퇴마전 1·2장 — 사람이 하는 확인 (v0.5 플레이테스트)

자동 검사(`node --test`)와 컴퓨터의 360px 화면 흉내로는 알 수 없는 것만 모았다.
**직접 해 본 항목만 체크한다.** 해 보지 않은 칸은 비워 둔다. 실제 폰 확인 전에는 "모바일 QA 완료"라고 하지 않는다.

- 주소: https://joseon-exorcist.vercel.app
- 기록 보기(개발자용): https://joseon-exorcist.vercel.app/?dev=1 → [🧪 플레이 기록]

---

## 0. 플레이테스트 진행 순서 (한 사람당)

1. 테스트할 폰에서 **개발자 주소**(`?dev=1`)를 연다 → [🧪 플레이 기록] → [기록 지우기]를 두 번 눌러 비운다
2. 같은 폰, 같은 브라우저로 **일반 주소**를 열어 건넨다. 이전 진행이 있으면 [처음부터]로 시작하게 한다 (시크릿 창은 쓰지 않는다 — 창을 닫으면 기록이 사라진다)
3. 1장 → 2장이 끝날 때까지 옆에서 **보기만** 한다 (아래 1·2절을 적는다)
4. 끝나면 3절의 다섯 가지를 묻고, 그 사람의 말을 그대로 적는다
5. 개발자 주소를 다시 열어 [JSON 복사] → 이 기록지와 함께 보관한다 (파일 이름 예: `playtest-이름-날짜.json`)

## 1. 진행 원칙 — 게임이 설명해야 한다

옆에서 설명하지 않는다. 특히:
- 탈출로를 설명하지 않는다
- 공적을 설명하지 않는다
- 어떤 스킬이 좋은지 알려 주지 않는다
- 벽사록을 열어 보라고 말하지 않는다
- 정화수 효과를 설명하지 않는다

플레이어가 물으면 먼저 이렇게 말하고 지켜본다:
> "지금 화면만 보고 어떻게 생각되는지 말해 주세요."

### 2-3. 발견한 것 — BUG 와 DESIGN 을 섞지 않는다

- **BUG** = 의도대로 작동하지 않음 (예: 정화수 숫자가 안 뜸)
- **DESIGN** = 의도대로 작동하지만 재미·이해에 문제 (예: 탈출로를 끝까지 못 봄)

| 종류 | 무엇을 | 어디서 (장·턴·화면) | 몇 번 |
|---|---|---|---|
| BUG | | | |
| DESIGN | | | |

## 3. 2장 가설 — 이번 플레이테스트로 확인할 네 가지

| | 가설 | 성공 신호 | 볼 기록 (JSON) | 볼 관찰 |
|---|---|---|---|---|
| H1 | 달래를 쫓는 느낌이 있다 | 모든 적을 치기보다 달래의 이동 방향과 탈출로를 의식한다 | `dalraeTrail`(달래 위치·탈출로 거리), `moves`, 달래를 처음 친 턴(`hits`), `totalTurns` | 2-1 #7·#8 |
| H2 | 무녀 때문에 판단이 생긴다 | "달래를 쫓을까, 무녀부터?" 고민. 무녀가 늘 의미 없이 먼저 쓰러지거나 늘 무시되면 실패 | `defeatedUnits` 순서, 무녀가 준 피해(`damageDealt.munyeo1·2`) | 2-1 #13, 질문 3 |
| H3 | 정화수가 전술을 바꾼다 | "지금 마무리하지 않으면 달래가 회복시킨다" | `dalraeHealCount`, `heals`(대상), `healFollowUps`(다시 쳤나·버틴 턴) | 2-1 #9 |
| H4 | 품계가 전술을 바꾼다 | 관군 0/1/2 가 난이도만이 아니라 선택을 바꾼다 | `rank`·`soldierCount` 별 `moves`·`hits`, 관군 id(`gwangun1·2`)의 행동 | 사람마다 품계가 다르면 비교 |

참고 — 자동 플레이 시뮬레이션(`node tests/sim-report.mjs`)은 **밸런스 이상 탐지용**이다. AI 승률로 재미를 판정하지 않는다.

## 4. 수정 게이트와 분석

- 플레이테스트 전에는 밸런스를 고치지 않는다. 치명적 버그만 바로 고친다
- **처음 하는 사람 3명**의 기록을 받은 뒤 수정안을 낸다. 가능하면 게임 경험이 서로 다른 사람
- 3명 중 2명 이상이 같은 곳에서 막히면 우선 수정 후보

분석 보고는 이 형식만 쓴다:
1. **그대로 유지** — 실제로 잘 작동한 것
2. **이해 실패** — 의도가 전달되지 않은 것
3. **재미 발생** — 플레이어가 고민하거나 좋아한 순간
4. **의미 없는 시스템** — 있지만 행동을 바꾸지 못한 규칙
5. **다음 수정 후보** — 최대 3개

| 2 | 프롤로그 | 약 10초 문장 → 붉은 辟邪廳 인장 → [임무를 받는다]. 중간에 누르면 한 번에 다 나온다 | |
