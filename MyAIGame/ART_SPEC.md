# 화풍 규격 (Art Spec)

**모든 그래픽은 예외 없이 이 규격을 거친다.**
규격 밖의 에셋은 쓰지 않는다. 하나라도 어긋나면 화면 전체가 싸구려로 보인다.

## 1. 캔버스 크기

| 대상 | 크기 | 비고 |
|---|---|---|
| 필드 타일 | 16 x 16 | 맵의 기본 단위 |
| 플레이어 · NPC | 32 x 32 | 발밑이 타일 격자에 맞아야 한다 |
| 아이디 1단계 | 32 x 32 | |
| 아이디 2단계 | 48 x 48 | 진화가 눈에 띄게 커져야 한다 |
| 아이디 3단계 | 64 x 64 | |
| 전투 배경 | 640 x 360 | 기준 해상도와 동일 |

기준 해상도가 640x360 이므로 3단계 아이디는 화면 세로의 약 1/6 을 차지한다.

## 2. 팔레트

**아래 색만 쓴다. 새 색을 만들지 않는다.**
색을 제한하는 것이 화풍 통일의 핵심이다.

### 속성 색 (각 4단계)
| 속성 | 밝음 | 기본 | 그림자 | 외곽선 |
|---|---|---|---|---|
| 게임 | `#FFB3A7` | `#F4796B` | `#C4574C` | `#8E3A33` |
| 테크 | `#A7D8FF` | `#6BAEF4` | `#4C7FC4` | `#33578E` |
| 디자인 | `#D4BBFF` | `#A87DF4` | `#7C57C4` | `#553A8E` |
| 만화 | `#A7F4C8` | `#6BD9A0` | `#4CA678` | `#337555` |

### 중립 램프 (배경 · UI · 그림자)
`#FFFFFF` `#F5F0E8` `#DCD3C6` `#B5A99A` `#8A7D6E` `#5C5247` `#332E28`

총 23색. 이 밖의 색은 쓰지 않는다.

## 3. 그리기 규칙

- **외곽선:** 1px. **검정을 쓰지 않는다.** 해당 색의 외곽선 단계를 쓴다.
  검정 외곽선은 무겁고 어두워 보여 "가볍고 밝은" 톤을 깨뜨린다.
- **명암:** 밝음 / 기본 / 그림자 3단계만. 그라데이션 금지.
- **광원 방향:** 항상 **좌측 상단**. 모든 에셋에서 동일해야 한다.
- **안티에일리어싱 금지.** 픽셀 경계가 흐려지면 안 된다.
- **디더링 금지.** 톤이 지저분해진다.

## 4. 애니메이션

| 대상 | 프레임 | 속도 |
|---|---|---|
| 아이디 대기 | 2 | 0.5초 루프 |
| 플레이어 걷기 | 2 | 0.25초 루프 |
| 이펙트 | 4 이하 | 0.1초 |

프레임을 늘리지 않는다. 2프레임 대기 애니메이션만으로도 충분히 살아 있어 보인다.

## 5. 뷰 각도

- **필드:** 탑다운. 캐릭터는 정면 상반신이 보이는 쿼터뷰.
- **전투:** 내 아이디는 뒷모습, 상대 아이디는 정면. 포켓몬과 같다.

## 6. 필요 에셋 수량

| 분류 | 수량 | 내역 |
|---|---|---|
| 아이디 전투 | 48 | 12종 x 정면/후면 x 2프레임 |
| 플레이어 필드 | 8 | 4방향 x 2프레임 |
| 필드 타일셋 | 1 | 바닥/벽/장애물 통합 |
| UI | 10 | HP바, 명령 메뉴, 텍스트 박스, 후원 카드, 파티 슬롯 |
| 이펙트 | 15 | 타격, 카드 던지기, 영입 성공/실패, 진화 |
| 전투 배경 | 4 | 지역별 |
| **합계** | **86** | |

한 번에 다 만들지 않는다. 개발 루프마다 **그 작업에 필요한 것만** 만든다.

## 7. 생성 도구

- 스프라이트 생성 도구는 **하나로 고정한다.** 도구를 섞으면 화풍이 갈린다.
- 도구에 넣는 프롬프트에는 항상 이 문서의 **2번 팔레트와 3번 그리기 규칙**을
  그대로 붙여 넣는다.
- 생성 결과가 규격에서 벗어나면 채택하지 않는다. 다시 만든다.

## 8. 검수 항목

새 에셋을 프로젝트에 넣기 전 확인한다.

- [ ] 캔버스 크기가 1번 표와 같은가
- [ ] 팔레트 밖의 색이 섞이지 않았는가
- [ ] 외곽선이 검정이 아닌가
- [ ] 광원이 좌측 상단인가
- [ ] 안티에일리어싱된 반투명 픽셀이 없는가
- [ ] 같은 분류의 기존 에셋과 나란히 놓았을 때 따로 놀지 않는가
