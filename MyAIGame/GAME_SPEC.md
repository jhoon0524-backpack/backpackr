# [게임 이름] 기획서 (Game Spec)

## 1. 개요
- **장르:** 2D 로그라이트 탑다운 슈팅
- **타깃:** 스팀 인디 게이머
- **한 줄 콘셉트:** 야근하는 직장인이 퇴근을 방해하는 괴물들을 물리치고 이직하는 게임

## 2. 핵심 루프 (Core Loop)
1. 몬스터 처치 및 경험치/재화 획득
2. 레벨업 시 무작위 무기/스킬 선택 (3중 택 1)
3. 정해진 시간(예: 5분) 버틴 후 보스전 진입
4. 승리 시 다음 회사(다음 단계)로 이동 / 사망 시 초기 화면 리셋

## 3. 주요 메커니즘 & 규격
- **조작:** WASD(이동), 마우스(조준 및 공격)
- **화면 해상도:** 1920x1080 (비율 유지)
- **아트 스타일:** 16bit 픽셀 아트, 어두운 사무실 배경 + 화려한 광원(Glow) 효과

## 4. 플레이어 & 몬스터 규격
- **플레이어:** 기본 HP 100, 이동속도 200
- **일반 몬스터:** 근접형(사원), 원거리형(대리), 탱커형(부장)
- **보스:** 패턴 3개를 가진 최종 사장 몬스터
