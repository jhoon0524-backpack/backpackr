# 펀딩몬 (가칭) 기획서 (Game Spec)

## 1. 개요
- **장르:** 2D 탑다운 수집형 턴제 RPG (포켓몬 스타일)
- **타깃:** 포켓몬류 수집·육성 게임에 익숙한 라이트 게이머
- **한 줄 콘셉트:** 세상에 떠도는 '아이디어 생명체'를 후원해 내 편으로 만들고, 펀딩 대결로 키워 나가는 게임
- **톤앤매너:** 가볍고 밝게. 죽음·패널티 없이, 지면 응원 게이지만 소모하고 다시 도전한다.

## 2. 핵심 루프 (Core Loop)
1. 필드를 탐험하며 야생 **아이디**(아이디어 생명체)와 조우
2. 턴제 전투로 약화시킨 뒤 **후원 카드**를 던져 영입 (포켓볼 대응)
3. 전투 승리와 영입으로 **후원금**을 모아 파티를 육성
4. 아이디별 **목표 금액** 달성 시 '펀딩 성공' 연출과 함께 진화
5. 지역 보스(대형 프로젝트 창작자)와 대결 → 승리 시 다음 지역 개방 → 1번으로

## 3. 주요 메커니즘 & 규격
- **조작:** 방향키/WASD(이동), Z 또는 Enter(상호작용·확인), X(취소), 전투는 메뉴 선택
- **화면 해상도:** 기준 640x360, 창 1280x720 (정수 배율 스케일, 비율 유지)
- **아트 스타일:** 밝은 파스텔 톤의 픽셀 아트. 굵은 외곽선, 채도 높은 색. 어두운 연출 없음
- **속성 상성:** 크라우드펀딩 카테고리 4종이 속성 역할. 순환 상성 구조
  - 게임 → 테크 → 디자인 → 만화 → 게임 (유리한 쪽 데미지 2배)
- **전투 규칙:** 1:1 턴제, 속도 스탯 순으로 행동, 기술은 최대 4개 보유
- **전투 명령:** 기술 / 후원(영입) / 교체 / 도망
- **영입 판정:** 상대 HP 비율이 낮을수록 성공률 상승
- **진화 조건:** 레벨이 아니라 누적 후원금이 아이디별 목표 금액에 도달할 때

## 4. 플레이어 & 몬스터 규격
- **플레이어:** 이동속도 120px/s, 파티 최대 3마리, 소지 후원 카드 초기 5장
- **아이디 공통:** 레벨 1~30, 기본 HP 40, 스탯 4종(HP/공격/방어/속도)
- **야생 아이디:** 각 지역 레벨대에 맞춰 3~5종 출현
- **지역 보스:** 파티 3마리 운용, 영입 불가, 승리 시 다음 지역 개방
