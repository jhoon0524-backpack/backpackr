# backpackr — 실험 창고

여러 실험 프로젝트가 모여 있는 저장소입니다. 독립한 프로젝트는 아래 저장소로 이사했습니다.

## 이사한 프로젝트

| 프로젝트 | 새 위치 |
|---|---|
| AI 자율 개발 루프 킷 (재사용 원본) | https://github.com/jhoon0524-backpack/ai-loop-kit |
| 펀딩몬 게임 + 루프 설치본 | https://github.com/jhoon0524-backpack/Fundingmon |

## 실험 목록

| 폴더 | 무엇 |
|---|---|
| `booking/` | 예약 서비스 실험 |
| `dropbid/`, `dropbid-mobile/` | 입찰 서비스 실험 (웹 + 네이티브) |
| `sales-crm/` | 영업 파이프라인 CRM 실험 (Node + SQLite) |
| `meeting-recorder/` | 사이드 키 2회로 녹음→전사→회의록 (Android) |
| `llm-wiki/` | LLM 위키 실험 (Karpathy 방식) |
| `agent-starter/` | 에이전트 스타터 실험 |
