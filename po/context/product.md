## 프로젝트 타입

| 타입 | 설명 | 제약 |
|---|---|---|
| 펀딩형 | 기간 내 목표 금액 달성 시 성사 | — |

| 공개예정 | 오픈 전 수요조사 | Run 이상 요금제 |

## 핵심 플로우

```
창작자   기획 → 심사 → 공개예정 → 오픈 → 결제 → 정산/배송
후원자   탐색 → 알림신청 → 후원 → 모니터링 → 수령/리뷰
```

## 창작생태계 기여도 레벨 (7단계)

| 레벨 | 이름 | 기준 |
|---|---|---|
| 1 | 초심자 | 약 200만 명 |
| 2 | 탐색자 | 상위 30% |
| 3 | 발견자 | 상위 5% |
| 4 | 동행자 | 상위 3% |
| 5 | 길잡이 | 상위 1% |
| 6 | 개척자 | 상위 0.1% |
| 7 | 선구자 | 상위 0.01% |

상승 조건: 후원(최근 100일 가중치) + 후기 좋아요/Pick 선정

레벨 기반 기능을 기획할 때는 7단계 전체와의 정합성을 확인한다.
특정 레벨 이상에만 주는 혜택은 그 아래 레벨의 상승 동기를 어떻게 바꾸는지 함께 적는다.
