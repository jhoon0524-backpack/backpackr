## 왜 여기에 복사하지 않나

정책은 Notion에서 계속 갱신된다. 레포에 옮겨 적으면 사본이 생기고, 정책이 바뀔 때 레포 것만
낡은 채 남는다. **낡은 정책은 없는 정책보다 나쁘다** — 확인했다는 착각을 준다.

## 쓰는 법

정책 확인이 필요하면 위 허브 URL을 fetch하고, 아래 분류에서 해당 영역의 하위 페이지로 내려간다.

| 영역 | 다루는 것 |
|---|---|
| 계정/인증 | 앱 토큰, 연락처 점유인증, 프로필·계정 정보 입력 조건 |
| 창작자/입점 | 창작자 권한(에디터·관리 메뉴), 칭호·좋은창작자 뱃지, 창작생태계 기여도 |
| 프로젝트/심사 | 프로젝트 생애주기(상태머신), 책임심사, 공개예정, 오픈런, 팬콜 |
| 선물/구성 | 선물 구성·옵션, 한정수량, 추가구성, 디지털선물, 에디터 입력 조건 |
| 후원/결제 | 예약결제(All-or-Nothing)·즉시결제, 결제수단, 청구 배치, 결제수수료 |
| 정산/수익 | 창작자 정산, 수수료 요금제 |
| 이행/후기 | 선물 전달 상태, 후기 작성·노출, 후원자명단 다운로드 |
| 취소/환불 | 후원 취소(전체·부분), 환불 상태머신 |
| 탐색/추천 | 검색, 추천, 홈·둘러보기, 키워드알림 |
| 커뮤니케이션 | 커뮤니티, 알림·푸시, 메시지, UGC 신고 |
| 광고/마케팅 | 광고센터, 비즈머니, SNS 셀프 광고, 럭키드로우 |

**정책을 확인하지 못했으면 확인했다고 쓰지 않는다.** Notion에 접근할 수 없는 실행 환경
(헤드리스·크론)이 있으므로, 못 읽었으면 논의사항에 `[정책 확인 필요]`로 올린다.

## 상태머신 주의

프로젝트 생애주기와 환불은 **상태머신**으로 정의되어 있다. 상태 전이를 건드리는 기획은
정책의 전이표를 직접 확인해야 한다. 추측으로 쓰면 기존 전이와 충돌한다.
