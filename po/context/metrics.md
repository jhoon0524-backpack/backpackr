# 지표 사전

> 기준일: 2026-08-02 · 담당: PO
> **상태: 골격만 있음.** 지표 이름은 GMV 지표트리 대시보드에서 가져왔고, 정의·측정 경로는 비어 있다.

## 이 문서가 있는 이유

PRD의 성공 지표는 "측정 가능한 숫자"여야 하는데, 측정 가능한지는 **지표 정의와 데이터 출처를 알아야만**
판정할 수 있다. 그게 없으면 그럴듯한 지표를 쓰고 출시 후에 못 잰다는 걸 발견한다.

## 규칙

- PRD 성공 지표는 **아래 등재된 지표를 우선 사용**한다.
- 없는 지표를 새로 쓰려면 PRD의 논의사항에 `[신규 지표]`로 올리고, 확정되면 여기에 등재한다.
- 정의가 `[TODO]`인 지표를 성공 지표로 쓰면 PRD에 `[측정 경로 미확인]`을 붙인다. 조용히 넘어가지 않는다.

## 등재 형식

| 항목 | 설명 |
|---|---|
| 정의 | 한 문장 |
| 분자 / 분모 | 비율 지표는 반드시 둘 다 |
| 출처 | 어느 테이블·이벤트·도구에서 재는가 (MySQL / Datadog / Sentry / Algolia / 대시보드) |
| 기준 | 집계 주기, 기간 정의 |
