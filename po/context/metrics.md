# 지표 사전

> 기준일: 2026-08-02 · 담당: PO
> **상태: 골격만 있음.** 지표 이름은 GMV 지표트리 대시보드에서 가져왔고, 정의·측정 경로는 비어 있다.

## 이 문서가 있는 이유

**에이전트는 프로덕션 지표에 접근할 수 없다** (2026-08-02 확인). 즉 성공 지표가 실제로 측정 가능한지를
데이터로 확인할 방법이 없다. 이 사전이 그 자리를 대신하는 유일한 수단이다.

따라서 PRD 검증의 기준은 "측정 가능한가"(확인 불가)가 아니라 **"누가 어떻게 재는지 적혀 있는가"**다.
측정 담당과 방법이 비어 있으면 그 지표는 출시 후에 아무도 재지 않는다.

## 규칙

- PRD 성공 지표는 **아래 등재된 지표를 우선 사용**한다.
- 없는 지표를 새로 쓰려면 PRD의 논의사항에 `[신규 지표]`로 올리고, 확정되면 여기에 등재한다.
- 정의가 `[TODO]`인 지표를 성공 지표로 쓰면 PRD에 `[측정 경로 미확인]`을 붙인다. 조용히 넘어가지 않는다.
- 등재 시 **측정 담당자 이름을 반드시 적는다.** 자동 확인이 불가능하므로 사람이 유일한 안전장치다.

## 등재 형식

| 항목 | 설명 |
|---|---|
| 정의 | 한 문장 |
| 분자 / 분모 | 비율 지표는 반드시 둘 다 |
| 출처 | 어느 테이블·이벤트·도구에서 재는가 (MySQL / Datadog / Sentry / Algolia / 대시보드) |
| 기준 | 집계 주기, 기간 정의 |
| 측정 담당 | 실제로 조회해서 값을 가져올 사람 |
