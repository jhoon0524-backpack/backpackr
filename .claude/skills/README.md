# PO 에이전트 정본

**이 디렉토리에 있는 것이 PO 에이전트다.** 여기 없으면 없는 것이다.

별도의 스킬 목록 파일을 두지 않는다. 목록을 파일로 관리하면 그 파일이 실물과 갈라진다 —
지금 이 레포가 만들어진 이유가 정확히 그 갈라짐이다.

## 동작 방식

이 레포를 클론한 상태에서 Claude Code를 실행하면 여기 있는 스킬이 자동으로 잡힌다.
설치 과정이 없다. `git pull`이 업데이트다.

## 개인 스킬과 겹치면

`~/.claude/skills/`에 같은 이름의 스킬이 있으면 어느 쪽이 뜨는지 보장할 수 없다.
**개인본을 지운다.** 정본은 여기다.

겹치는지 확인:

```
po/check.sh
```

## 스킬을 추가할 때

- 산출물 1개당 스킬 1개. 역할("너는 PO다")로 자르지 않는다.
- 회사 사실(수수료·인력·스택·지표)은 스킬에 적지 않고 `po/context/`를 참조한다.
- PR로 올린다. 스킬 한 줄이 팀 전체의 산출물을 바꾼다.
