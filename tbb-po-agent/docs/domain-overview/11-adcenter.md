## 1. 광고센터 진입 게이트

광고센터는 **창작자 전용** 메뉴다. 다음 3개 조건을 모두 만족해야(AND) 진입할 수 있으며, 순차 검증이라 앞 조건이 실패하면 다음 조건은 확인하지 않는다.

1. **광고센터 이용약관 동의** — "광고센터 이용약관" 팝업에서 필수 항목에 체크·동의해야 한다. 미동의 시 진입 불가.
2. **광고 가능한 프로젝트 유무** — `isExistVerified` 조건. 창작자가 보유한 프로젝트 중 다음 8개 `ProjectState` 중 하나에 속하는 프로젝트가 있어야 한다: `VERIFIED`(승인 됨)·`CANCELLED`·`FAILED`·`ONGOING_NOT_REACHED`(진행 중/목표 미도달)·`ONGOING_REACHED`(진행 중/목표 도달)·`SUCCEEDED_NOT_BALANCED`(성공/정산 전)·`SUCCEEDED_BALANCED`(성공/정산완료)·`PRELAUNCHED`. 전체 한글 라벨과 상태 전이는 `03-project.md` 참조. 조건을 만족하는 프로젝트가 없으면 다음 단계(세금계산서)로 진입할 수 없다.
3. **세금계산서 발행 정보 등록** — "세금계산서 발행 정보 팝업"에서 등록 여부를 확인한다. 미등록 시 진입 불가하며, 팝업에서 "다음에 하기"를 선택하면 광고센터 가이드 화면으로 리다이렉트된다.

## 2. 비즈머니 (BizMoney)

**정의**: 광고센터 내 광고 상품(SNS 셀프 광고 등) 결제 시 창작자가 사용하는 선충전금. 창작자 계정 단위로 관리된다.

### 2-1. 충전

| 항목 | 값 |
|---|---|
| 충전 수단 | 토스페이먼츠(신용/체크 카드)만 |
| 최소 충전 금액 | 100원 |
| 최대 충전 금액 | 카드 한도에 따라 상이 |
| 창작자 1명(계정 기준) 최대 보유 금액 | 50,000,000원 — 충전 요청액 + 기존 잔액이 이 금액을 초과하면 결제 자체가 차단된다 |
| 유효기간 | 5년(채권 관련 법률 기준). 충전일로부터 5년 이내 사용 가능, 경과 시 자동 소멸 |

결제 시 결제 금액 전액이 비즈머니로 전환된다.

**카드사별 결제 한도**

| 카드사 | 1회 한도 | 1일 한도 | 월 한도 |
|---|---|---|---|
| 우리카드·국민카드·신한카드·삼성카드·롯데카드 | 1,000만원 | 1,000만원 | (기재 없음) |
| 비씨카드 | 제한 없음 | 제한 없음 | 제한 없음 |
| 농협카드 | 10만원 | 누적 50만원 | 없음 |
| 현대카드 | 100만원 | 200만원 | 1,000만원 |
| 하나카드 | 미정 | 미정 | 미정 |

`[확인 필요]` 하나카드 결제 한도는 카드사 측 최종 회신이 지연되어 미정 상태(노션 원문 기준).

### 2-2. 환불 (비즈머니 → 결제 취소/계좌 입금)

창작자가 충전한 비즈머니를 되돌려받는 경로다. 환불 금액은 광고 상품에 소진된 비즈머니를 제외한 **잔여 비즈머니 전액**이며, 결제일이 오래된 내역부터 순차 처리된다.

**환불 불가 케이스**
- 예약/집행 중인 광고 상품이 있는 경우
- 비즈머니 잔액이 없는 경우
- 비즈머니 잔액이 환불 요청액보다 작은 경우(환불 수수료 제외 후 잔액 기준으로도 부족한 경우 포함)

**거래 내역별 처리 방식 (2가지)**

| 방식 | 대상 | 처리 |
|---|---|---|
| 결제 취소 | 충전일로부터 365일(1년) 이내 거래 내역 | 소진된 비즈머니 금액을 제외한 전액 취소(수수료 없음). 창작자 계정으로 결제된 모든 카드(제3자 명의 카드 포함) 대상 |
| 개별 입금 처리 | 충전일로부터 365일(1년)이 지난 거래 내역 | 남은 금액에서 수수료 3%를 제외한 금액을 본인 명의 환불 계좌로 입금(수수료 계산 시 소수점 첫째 자리에서 올림). 본인 명의 환불 계좌 등록이 선행되어야 환불 요청 가능 |

365일 기준일과 3% 수수료 반올림 방식은 노션 원문에 구체 수치가 없어 코드 기준으로 확정한 값이다.

**환불 계좌 등록**
- 창작자 계정의 본인 인증과 명의가 동일한 계좌만 등록/변경 가능하다.
- 절차: 본인 인증 → 계좌 정보 입력 → 등록 완료.
  - 일반 개인: 본인 명의 계좌
  - 개인사업자: 대표자 명의 계좌
  - 법인사업자: 법인명 계좌
- 계좌정보 입력 항목: 개인(계좌은행·계좌번호) / 사업자(사업자번호·계좌은행·계좌주·계좌번호·사업자사본).
- 사업자는 등록 시 내부 승인이 필요하다. `[확인 필요]` 승인 주체(담당 팀/담당자)와 처리 SLA는 노션 원문에 명시되어 있지 않다.

### 2-3. 비즈머니 환급 (환불과 구분되는 별도 용어)

**정의**: 광고 상품 구매 취소 시 취소 수수료를 제한 금액을, 또는 광고 집행 중 남은 금액을 비즈머니로 반환하는 행위. 창작자가 충전금을 회수하는 "환불"과 달리, 광고 취소·종료분을 비즈머니로 되돌리는 것이다.

- 광고 상품 구매 시 보유 비즈머니에서 상품 금액만큼 차감된다(가장 오래된 충전분부터 차감).
- 취소 시 취소 수수료를 제한 금액이 비즈머니로 환급된다.
- SNS 셀프 광고의 구체적 환급 로직·시점은 §3-8 참조.

### 2-4. 세금계산서

| 대상 | 발행 여부 | 비고 |
|---|---|---|
| 비즈머니 충전 | 미발행 | 카드 전표·영수증만 발행(결제 증빙 용도로만 사용 가능, 회계 처리 증빙 불가) |
| 광고 상품 결제 | 발행 | 해당 월 사용 금액 합산 후 익월 초 일괄 발행, "알림받을 이메일"로 발송 |

### 2-5. 비즈머니 계정 상태 (`UserCreditState`, 5종)

| 상태값 | 한글 라벨 |
|---|---|
| `PENDING` | 결제 대기 |
| `ACTIVE` | 사용 가능 |
| `EXPIRE` | 만료 |
| `REFUNDED` | 환불 완료 |
| `CONSUMED` | 전액 소진 |

## 3. SNS 셀프 광고 (SNS Self Ads / MPA)

> ⚠️ **현행 이용불가 (PO 확인 2026-07-10)**: SNS 셀프 광고 메뉴는 현재 제거되어 창작자가 이용할 수 없다. 아래 정책·상태머신은 노션(2025-05-23 기준)과 코드에 남아 있는 스펙 기록이며, 재오픈 여부·시점은 미정.

> ⚠️ **유지보수 경고**: 메타(페이스북/인스타그램) API는 6개월~1년 단위로 업데이트되며, 이전 버전 API는 6개월만 사용 가능하다. 노션 원문은 반기 1회 API 점검을 권장한다.

**정의**: 창작자가 직접 예산·소재를 세팅해 메타 광고를 텀블벅 메타 계정으로 집행하는 광고 서비스.

### 3-1. 광고 만들기 플로우

캠페인 설정 → 신규 타겟 설정 → 소재 설정 → 광고 결제 → 심사 → 광고 집행

### 3-2. 광고 구조

캠페인 하나당 광고 그룹 2개(동일 소재를 각각 세팅):
- **신규 타겟 그룹**: 창작자가 직접 설정한 타겟
- **텀블벅 유저 그룹**: 텀블벅이 사전 설정한 타겟 — 타겟팅은 WEB/APP 최근 180일 후원자, 디타겟팅은 WEB/APP 최근 7일 방문·WEB/APP 최근 30일 후원자를 제외

### 3-3. 동일 프로젝트 중복 캠페인 제한

동일 프로젝트·동일 기간에는 캠페인을 중복 생성할 수 없다(반려·취소반려/종료/취소된 캠페인은 제한 기준에서 제외). 예: 기존 캠페인 기간이 01.15~01.20이면 새 캠페인은 01.15 이전 또는 01.20 이후만 가능하다.

### 3-4. 광고 만들기 조건

| 항목 | 조건 |
|---|---|
| 캠페인명 | 최대 25자 |
| 광고 대상 프로젝트 | 승인·공개예정·진행중 프로젝트 |
| 일예산 | 15만원 / 8만원 / 3만원 / 직접 입력(최소 10,000원 이상) — 4개 프리셋 옵션 |
| 광고 노출 일정 | 오늘로부터 3영업일 이후부터 선택 가능. 기간 = `{공개예정시작일 또는 프로젝트 시작일} ~ {프로젝트 종료일}` |
| 신규 타겟 커스텀 설정 | PREMIUM 요금제만 가능(PRO·BASIC은 기본 디폴트값 자동 설정). 항목: 성별(다중), 연령 18~65+, 관심사(9개 카테고리), 노출 지면(페이스북/인스타그램, 다중) |

일예산 프리셋은 코드상 `MpaOptionCode` 4종(`AGGRESSIVE`=공격적·`RECOMMENDED`=추천·`ECONOMICAL`=경제적·`CUSTOM`=직접설정)으로 관리되며, 노션의 15만/8만/3만/직접입력 프리셋과 대응하는 구조로 보인다. 다만 어느 코드가 정확히 어느 금액에 매핑되는지는 DB 시드 데이터라 이번 조사에서 확정하지 못했다.

**소재 설정**
- 소재 제한 개수: 5개
- 이미지: JPG/PNG/JPEG, 5MB 이하, 정방향 비율(1:1), 1080×1080 이상
- 영상: MP4/MOV(H.264 권장), 100MB 이하, 1:1 또는 9:16, 권장 10초~1분
- 게시글 125자, 광고 제목 40자, 광고 설명 30자, 행동 유도 버튼(더 알아보기/지금 구매하기/지금 주문하기)

### 3-5. 광고 결제 금액 (계산식)

| 구분 | 설명 | 수식 |
|---|---|---|
| 총 결제 금액 | 실제 청구 총액 | 캠페인 총 예산 + 텀블벅 수수료 + 보증금 + 부가세 |
| ㄴ 총 예산 | 광고 집행 전체 예산 | 일예산 × 광고일수 |
| ㄴ 텀블벅 수수료 | 서비스 수수료(총 예산 비례, 요금제별 상이) | 캠페인 총 예산 × 요금제별 SNS 광고 수수료율 |
| ㄴ 보증금 | 초과 소진 대비 예치금(사용 후 잔액 환급) | 캠페인 총 예산 × 5% |
| ㄴ 부가세 | 세금 | (캠페인 총예산 + 텀블벅 수수료 + 보증금) × 10% |

### 3-6. 요금제별 SNS 광고 수수료율 — 정산 수수료율과는 별개의 축

`AdsProductCommission`(요금제 × 수수료율 조합, DB 설정값)에 저장되는 값으로, `06-settlement.md`의 정산 수수료율(`RatePlanType.commissionRate`, 코드 하드코딩)과 저장 위치·용도가 다른 완전히 별개의 값이다. 요금제 명(BASIC/PRO/PREMIUM)은 같지만 수치가 다르므로 혼동하지 않도록 주의해야 한다.

| 요금제(코드 Enum) | 정산 수수료율(`06-settlement.md` 참조) | SNS 광고 수수료율(광고센터, 2025-05-23 기준) |
|---|---|---|
| BASIC | 5% | 15% |
| PRO | 9% | 10% |
| PREMIUM | 15% | 0%(면제) |

구 노션(2023-09-12) 기재였던 `06-settlement.md` §1-C 표의 "RUN(PRO): SNS 광고 대행(수수료 면제)"는 위 표(최신 노션 2025-05-23 + 코드 확인)와 상충했으나, **PO 승인(2026-07-10)으로 06-settlement.md가 최신 정책(RUN 10%·BOOST 0% 면제)에 맞춰 정정 완료**됐다. 완전 면제(0%)는 PREMIUM 요금제뿐이며, 커스텀 타겟 설정 기능도 PREMIUM 요금제 전용이다(§3-4).

### 3-7. 광고 심사

- 과정: 심사요청 → 텀블벅 심사 → 메타 심사
  - 텀블벅 반려 시: 심사요청 → 반려
  - 메타 반려 시: 심사요청 → 텀블벅 승인 → 반려
  - 최종 승인: 심사요청 → 텀블벅 승인 → 메타 승인 → 승인
- 반려 기준: 소재 1개라도 반려되면 **캠페인 전체가 반려**된다.
- `[확인 필요]` 반려된 소재를 수정해 재심사를 요청하는 구체적 플로우(재심사 큐잉·소요 기간 등)는 노션 원문에 명시되어 있지 않다.

### 3-8. 캠페인 상태 (`AdsOrderStatus`, 8종)

| 상태값 | 한글 라벨 | 비고 |
|---|---|---|
| `SUBMITTED` | 심사중 | 심사요청 접수, 텀블벅 심사 전 |
| `TUMBLBUG_VERIFIED` | 심사중 | 텀블벅 승인 완료, 메타 심사 전. 사용자 노출 라벨은 `SUBMITTED`와 동일하게 "심사중"이며 내부적으로만 2단계로 구분된다 |
| `VERIFIED` | 승인 | 텀블벅·메타 모두 승인 완료 |
| `REJECTED` | 반려 | 텀블벅 또는 메타 반려. 반려 즉시 비즈머니 전액 환급 |
| `ONGOING` | 광고중 | 집행 중 |
| `ENDED` | 종료 | 집행 종료 |
| `CANCELLED` | 취소 | 창작자 취소(심사중·승인·광고중·중단 상태에서 취소 가능) |
| `ABORTED` | 중단 | 내부 임직원 강제 중단. 노션 원문에 "추후 추가 예정, 현재 기능 구현 X"로 명시되어 있어 실제 미구현 상태로 보인다 |

광고그룹·소재 단위는 `AdsOrderBasicStatus` 4종(`SUBMITTED`·`TUMBLBUG_VERIFIED`·`VERIFIED`·`REJECTED`)만 갖는다. 진행중/종료/취소/중단 상태는 광고그룹·소재 단위에는 없고, 상위 캠페인 상태를 반영한 계산값 `AdsEffectiveStatus` 9종(위 8종 + 상위 캠페인이 중단되어 하위가 연쇄 중단된 경우를 구분하는 `CAMPAIGN_ABORTED`)이 API 응답에 사용된다.

**광고 결제 상태** (`AdsPaymentStatus`, 6종): `PENDING`(대기)·`SUCCESS`(완료)·`CANCELLED`(취소)·`PART_CANCELLED`(부분취소)·`FAILED`(실패)·`RETURNED`(환불)

### 3-9. 광고 관리 (리스트·성과)

- 상세(결제 정보)/관리(설정 정보) 탭으로 구분된다.
- ON/OFF 토글: 캠페인/광고그룹/소재 단위로 가능하다. OFF 상태면 집행일이라도 노출되지 않는다.
- 삭제: 캠페인만 삭제 가능(광고그룹·소재는 개별 삭제 불가). 종료/취소/반려 상태이면서 환급까지 완료된 캠페인만 삭제 가능하며, 캠페인 삭제 시 하위 광고그룹·소재가 전체 삭제되고 복구할 수 없다.
- **성과 지표**
  - 클릭수/노출수/클릭률: 메타 데이터 소스, 실시간
  - 후원액/후원수: 텀블벅 에어브릿지(airbridge) 데이터 소스. 취소액은 미반영되어 오차가 발생할 수 있다. 맵핑 기준은 메타 유료광고 + 프로젝트 pid + 광고 일자(캠페인/광고그룹/소재 id 기준이 아님). 적재 주기 1시간, insert 방식.
  - 알림신청수(`notification_count`) 지표가 2025-06-26 논의에서 추가되었다.
  - `[확인 필요]` 성과 지표 오차범위 5% 안내를 헬프센터·가이드·리스트 안내문구에 반영할지는 담당자 지정만 되어 있고 완료 여부가 노션 원문에서 확인되지 않는다.

### 3-10. 광고 환급 로직

| 캠페인 상태 | 환급액 | 환급 시점 |
|---|---|---|
| 반려 | 비즈머니 전액 | 즉시 |
| 종료 | 소진 비용 제외 잔액 | 종료일로부터 2일 뒤 |
| 취소 — 심사중 | 비즈머니 전액 | 즉시 |
| 취소 — 승인, 광고시작일 전날 오후 11시까지 취소 | 비즈머니 전액 | 즉시 |
| 취소 — 승인, 광고시작일 전날 오후 11시 이후 취소 | 소진 비용 제외 잔액 | 취소일로부터 2일 뒤 |
| 취소 — 광고중·중단 | 소진 비용 제외 잔액 | 취소일로부터 2일 뒤 |

- **소진 비용**: 메타 광고 비용 + 광고 수수료(요금제별 상이) + VAT 포함 금액. 광고 집행 중 취소 시 실제 소진 비용은 예상 소진 비용과 다를 수 있다.
- 코드 확인 결과 즉시환급 대상 상태 목록에는 `SUBMITTED`·`TUMBLBUG_VERIFIED`·`VERIFIED`(승인)가 시각 조건 없이 포함되어 있다. 위 표의 "광고시작일 전날 오후 11시" 컷오프는 노션 원문 서술을 그대로 반영한 것이며, 이 시각 분기가 구현되는 정확한 코드 위치는 이번 조사에서 특정하지 못했다.

### 3-11. 참고 — 메타 연동 세팅값

- 광고센터에서 세팅한 캠페인은 메타 계정 `Tumblbug_MPA`에 생성된다. 텀블벅 승인 시 메타에 캠페인이 생성되고, 메타의 승인/반려 결과를 수신해 운영한다.
- 캠페인 예산 전략은 캠페인 예산이 아닌 **일일 예산(daily budget)** 방식이다. 구매 유형은 경매(`OUTCOME_SALE`), 캠페인 목표는 판매, 어드밴티지+ 카탈로그 광고는 해제, 특별 광고 카테고리는 none이다.
- 텀블벅 유저 광고세트는 최근 180일 내 후원자 중 7일 방문·30일 후원자를 제외한 타겟으로 자동 세팅되며 Advantage+ 타깃 기능은 off다. 신규 유저 광고세트는 Advantage+ 타깃 기능이 PREMIUM은 off, BASIC/PRO는 on이다(커스텀 타겟 설정이 불가한 요금제에 대한 자동 확장 타겟팅으로 해석된다).
- 광고소재 랜딩페이지는 에어브릿지 링크가 자동 생성된다(웹 `https://tumblbug.com/{permalink}`, iOS/AOS 딥링크 `tumblbug://tumblbug.view/project?permalink={permalink}`).
