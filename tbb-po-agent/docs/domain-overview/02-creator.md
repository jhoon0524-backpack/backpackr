## 창작자 칭호 (Creator Title)

주 1회 배치로 산정·부여되는 5종 타이틀(2개 그룹). 창작자 프로필에 노출된다.

**운영 로직**

| 항목 | 값 |
|---|---|
| 업데이트 주기 | 주 1회, 일요일→월요일로 넘어가는 새벽 |
| 회수 여부 | 업데이트 시점에 발급 조건 미충족 시 즉시 회수(삭제) |
| 로직 우선순위 | 칭호 삭제 기준 > 칭호 발급 기준 |
| 노출 영역 | 창작자 프로필 |

**삭제 기준** (발급 기준보다 우선 적용)
1. 칭호 발급 조건 미충족
2. 운영셀에서 '경고' 제재를 받은 창작자 — 제재 시점으로부터 1년간 뱃지 발급 불가
3. 운영셀이 제공하는 리스트에 오른 창작자 — 배포 시점(2024-11-28)으로부터 1년간. 현재 '신고 및 창작자 관리 시스템'이 없어 리스트 방식으로 임시 처리하는 것이며, 만료 후 연장·시스템화 여부는 노션에 명시돼 있지 않다. `[확인 필요]`

**발급 기준**
- 노출 순서: 발급 최신순
- 발급 개수: 그룹별 1개씩, 총 최대 2개 (그룹당 1개 / 우선순위는 그룹 내 낮은 번호 순: 1번 그룹 1>2, 2번 그룹 3>4>5)

**칭호별 발급 로직 (2그룹 5종)**

| 그룹 | 칭호명 | 발급 로직 | 한 줄 설명(노출용) |
|---|---|---|---|
| 1번 그룹 | 1) 펀딩블루칩 | 기준1: 누적 성사 후원액 5천만원 이상(최근 540일) · 기준2: 누적 성사 후원자 수 2천명 이상(최근 540일) · 기준3: 성사 프로젝트 4회 이상(최근 540일) · 기준4: 최근 성사 후원액 1천만원 이상(최근 120일) | 후원자들에게 새로운 프로젝트를 꾸준히 선보이고 있는 우량 창작자입니다 |
| 1번 그룹 | 2) 트렌드 메이커 | 기준1: 성사 프로젝트 1회 이상(최근 120일) · 기준2: 최근 성사 후원액 1천만원 이상(최근 120일) · 기준3: 최근 성사 후원자 수 300명 이상(최근 120일) | 최근 핫한 트렌드를 만들어 내며 빠르게 성장하고 있는 창작자입니다 |
| 2번 그룹 | 3) 팬덤 파워 | 프로젝트 후기 '재후원 하실건가요?' 질문에 긍정 응답 비중 99% 이상(전제: 누적 프로젝트 후기 10개 이상) / 기준: 누적 프로젝트 스탬프 후기 20개 이상 | 해당 창작자의 프로젝트를 후원한 분들의 반응이 뜨거운 창작자입니다 |
| 2번 그룹 | 4) 신뢰의 아이콘 | '프로젝트 계획' 평점×0.5 + '이슈를 잘 해결했는지(optional)' 평점×0.5 (이슈 평가가 없으면 프로젝트 계획 평점×1.0) → 환산 점수 18점 이상(전제: 누적 프로젝트 스탬프 후기 20개 이상) | 프로젝트 진행과 리워드 전달을 안정적으로 수행하여 후원자의 신뢰를 받는 창작자입니다 |
| 2번 그룹 | 5) 소통의 대가 | '소통이 잘 되었나요?' 응답 환산 점수 17점 이상(전제: 누적 프로젝트 스탬프 후기 20개 이상) | 후원자들과 따뜻하게 소통하며 프로젝트 상황을 적극적으로 공유해주는 창작자입니다 |

**환산 점수 계산식** (후기 응답 점수 → 칭호 판정용 점수)
- 응답 척도: 아쉬워요 -1점 / 보통이에요 1점 / 만족해요 2점
- 기준: 10개 응답 가정 시 -20~+20점 범위
- 10개 초과 응답은 배수(실 응답수 / 10)로 나눠 환산
- 예시: 실 응답 20개, (1명×-1점 + 1명×1점 + 18명×2점) = 36점 → 배수 2 → 환산 점수 18점

## 창작생태계 기여도 (Creator Ecosystem Contribution)

창작자 활동 기여도를 주 1회 배치로 산정, 랭킹·티어로 노출하는 지표 체계.

| 항목 | 값 |
|---|---|
| 데이터 테이블 | `user_contribution_stats`(항목별 카운트) / `user_tiers`(랭킹 변화·티어 변화·이전 랭킹·이전 티어·현재 랭킹) |
| 업데이트 방식 | 배치마다 백업 없이 테이블 업데이트. DA 분석은 스냅샷 마트화해서 확인 |
| 업데이트 주기 | 주 1회, 월요일 오전 4시 |
| 기여도 알림 조건 (2가지 모두 충족 시) | ① 기여도 단계 신규 획득 또는 단계 상승 AND ② 전주 대비 점수 상승 |
| 알림 방식 | 팝업 + 푸시 알림 |

**관련 네이티브/웹뷰 페이지 (4종)**

| 페이지 | 유형 | 진입 경로 |
|---|---|---|
| 기여도 랭킹 전체 | 네이티브 | 홈 > GNB(tab) 탭 이동 / 프로필 > [기여도 개인 상세] > 전체보기 버튼 |
| 기여도 랭킹 더보기 | 네이티브 | [랭킹] 페이지 > 더보기 버튼 |
| 기여도 개인 상세 | 네이티브 | 프로필 > [창작생태계 기여도] 클릭 |
| 기여도 안내 | 웹뷰 | [랭킹 전체]·[개인 상세] > 안내 배너 |

**기여도 뱃지 노출**
- 큰 뱃지: 팝업 / 기여도 개인상세페이지
- 작은 뱃지: 프로필(유저명 우측) / 응원글·후기·댓글(유저이름 우측) / 기여도 전체·상세 랭킹(유저이름 우측)

- **기여도 단계 구간·산정 알고리즘 상세식**: 노션 페이지 본문에는 없고 외부 구글시트 링크로만 존재해 이번 분석에서 확정하지 못했다. `[확인 필요]`
