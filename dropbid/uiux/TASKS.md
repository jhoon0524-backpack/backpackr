# UI/UX 점검표

한 항목은 **화면 하나 · 사람 하나** 크기로 유지한다.
`- [x]` 는 **캡처를 실제로 열어 봤다**는 뜻이다. DOM 만 읽은 것은 체크가 아니다.

## [첫인상] 처음 온 구경꾼
- [ ] 홈에서 5초 안에 "여기가 뭐 하는 데" 인지 알 수 있다
- [ ] "드롭" 이 무슨 뜻인지 화면이 알려 준다
- [x] 지금 무엇을 눌러야 하는지 분명하다
- [x] 로그인 대신 있는 사람 고르기가 뭔지 알 수 있다

## [입찰] 입찰하려는 사람
- [x] 얼마를 넣어야 하는지 입력칸을 보기 전에 안다
- [x] 최소 금액이 왜 그 금액인지 알 수 있다
- [x] 입찰이 되돌릴 수 없다는 것을 누르기 전에 안다
- [x] 입찰 뒤 무슨 일이 일어났는지 화면이 알려 준다
- [x] 남은 시간이 얼마 안 남았을 때 그것이 눈에 띈다
- [x] 마감된 경매에서 다음에 뭘 할지 알 수 있다

## [판매] 팔려는 사람
- [x] 등록 전에 무엇을 준비해야 하는지 미리 안다
- [x] "후원 인증" 이 무엇을 넣으라는 것인지 안다
- [x] 사진을 주소로 넣어야 한다는 것이 분명하다
- [x] 낸 뒤 지금 어디까지 왔는지 알 수 있다
- [ ] 반려되면 왜 반려됐는지 보인다

## [낙찰] 낙찰된 사람
- [x] 얼마를 내야 하는지가 화면에서 가장 크다
- [x] 언제까지 내야 하는지가 화면에서 가장 크다
- [x] 안 내면 어떻게 되는지 적혀 있다
- [x] 다음에 누를 것이 하나로 분명하다

## [일관성] 화면을 가로질러
- [x] 같은 것을 같은 이름으로 부른다 (회차/드롭, 시작가/현재가)
- [x] 금액 표기가 모든 화면에서 같다
- [x] 시각 표기가 모든 화면에서 같다
- [x] 버튼의 말투가 일관된다

## [기기] 실제 조건
- [x] 폭 390 에서 화면이 무너지지 않는다
- [x] 어두운 테마에서 밝을 때와 같다
- [x] 손가락으로 누르는 것이 44px 이상이다
- [x] 빈 화면마다 나가는 길이 있다

## [원칙] 두 번 이상 지적된 것
- [x] 돈이 걸린 숫자가 그 화면에서 가장 크다
- [x] 빈 화면에 나가는 길이 있다
- [x] 실제 기기 조건(390·어두운 테마)에서 봤다
