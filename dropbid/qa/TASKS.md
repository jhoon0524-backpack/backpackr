# QA 체크리스트

한 항목은 화면 하나 · 10분 이내 크기로 유지한다.
`- [x]` 는 **실제로 열어 봤다**는 뜻이다. 코드를 읽은 것은 체크가 아니다.

## [스모크] 배포본이 살아 있나
- [x] `/` 200 으로 열린다
- [x] `/sell` `/me` `/admin` 200 으로 열린다
- [x] 존재하지 않는 경매 주소에 한국어 안내와 돌아갈 길이 나온다
      (상태 코드는 200 이다 — `qa/TRIAGE.md` 7번에서 안 고치기로 정함)
- [x] 화면 본문에 영어 잔재(`AM` `PM` `Please enter`)가 없다
- [x] 서버 오류 로그가 비어 있다

## [구경] 드롭 목록
- [x] 진행 중인 경매가 보인다 (제목·금액·남은 시간)
- [x] 입찰 0회인 상품은 "현재가" 가 아니라 "시작가" 로 나온다
- [x] 사진이 보인다. 주소가 죽었으면 자리표시로 대체된다
- [x] 드롭이 끝나면 "지난 드롭 결과" 가 나온다 (홈이 백지가 되지 않는다)
- [x] 모바일 폭(390)에서 제목이 잘리지 않는다

## [입찰] 상품 상세
- [x] 현재가·남은 시간·입찰 수·최고입찰자가 보인다
- [x] 최고입찰자 닉네임이 가려져 있다
- [x] 입찰가에 자릿수 구분이 붙는다
- [x] 정상 입찰이 반영된다
- [x] 판매자 본인 입찰이 거부되고 이유가 뜬다
- [x] 연락처 없는 사용자의 입찰이 거부되고 이유가 뜬다
- [x] 최소 입찰가 미만이 거부되고 최소액이 안내된다
- [x] 새로고침 없이 현재가가 갱신된다

## [판매] 상품 등록
- [x] 사용자를 고르기 전에는 폼이 열리지 않는다
- [x] 연락처가 없으면 폼이 열리지 않는다
- [x] 사진 3장 미만이면 문구가 뜬다
- [x] 후원 인증이 없으면 문구가 뜬다
- [x] 시작가 1,000원 미만이면 문구가 뜬다
- [x] 1,000원 단위가 아닌 금액도 등록된다
- [x] 등록에 성공하면 확인 문구가 보인다

## [검수] 운영자
- [x] 일반 사용자에게 "검수" 메뉴가 안 보인다
- [x] 일반 사용자가 주소로 직접 들어가도 막힌다
- [x] 운영자에게 후원 인증 이미지가 **크게** 보인다
- [x] 승인하면 회차에 배정된다
- [x] 사유 없이 반려하면 막힌다

## [마감] 결과
- [x] 낙찰 화면에 금액과 낙찰자가 보인다
- [x] 낙찰자에게 결제 기한이 보이고 남은 시간이 센다
- [x] 낙찰자가 아닌 사람에게는 결제 기한이 안 보인다
- [x] 유찰 화면이 뜬다
- [x] 미결제 종료 화면이 뜬다
- [x] 유찰·미결제 상품을 판매자가 다시 올릴 수 있다

## [회귀] 같은 버그가 두 번 이상 났던 것
- [x] 한국어 화면에 영어가 안 나온다
- [x] 폼이 조용히 실패하지 않는다
- [x] 금액에 자릿수 구분이 붙는다
