# 인터넷에 올리기 (Vercel)

**현재 상태**: Vercel 프로젝트 `dropbid` 생성 완료, GitHub 저장소 연결 완료,
Supabase 실제 DB 구축·시연 데이터 투입 완료, `DATABASE_URL` 입력 완료.

앞으로는 **코드를 저장소에 올리면 Vercel 이 알아서 다시 배포합니다.** 손댈 것이 없습니다.

---

## 알아 두실 것

- **주소를 아는 사람은 누구나 들어옵니다.** Vercel 무료 플랜은 비밀번호를 걸 수 없습니다.
- **아직 로그인이 없습니다.** 화면 위쪽 선택으로 아무나 판매자·운영자가 될 수 있습니다.
  들어온 사람이 상품을 승인하거나 반려할 수 있다는 뜻입니다.
- 그래서 주소를 아무 데나 올리지 마시고, 보여 줄 사람에게만 알려 주세요.
- 내리려면: Vercel → `dropbid` → Settings → 맨 아래 Delete Project.

---

## 환경변수를 바꿨을 때 — 반드시 다시 배포해야 합니다

**이것 때문에 한 번 막혔습니다.** `DATABASE_URL` 같은 환경변수는 **배포하는 순간의 값이
그대로 박힙니다.** Vercel 화면에서 값을 고쳐도 이미 돌고 있는 배포는 옛 값을 그대로 씁니다.

값을 고쳤으면 둘 중 하나를 해야 합니다:

- Vercel → `dropbid` → **Deployments → 맨 위 항목 → `⋯` → `Redeploy`**
- 또는 저장소에 아무 코드나 올리기 (그러면 자동으로 새로 배포됩니다)

---

## 안 될 때

| 화면에 뜨는 것 | 원인과 해결 |
|---|---|
| 500 오류, 로그에 `ECONNREFUSED 127.0.0.1:5432` | `DATABASE_URL` 이 없거나, 넣고 나서 **다시 배포하지 않았습니다** |
| 500 오류, 로그에 `password authentication failed` | 문자열의 `[YOUR-PASSWORD]` 를 안 바꿨거나 대괄호가 남아 있습니다 |
| 접속이 끊겼다 붙었다 함 | `Transaction pooler`(`:6543`) 가 아닌 다른 연결 문자열을 쓰셨습니다 |
| 빌드 실패, `No Next.js version detected` | Root Directory 가 `dropbid` 가 아닙니다. Settings → General |

로그 보는 곳: Vercel → `dropbid` → 해당 배포 클릭 → **Runtime Logs**.

---

## 연결 문자열을 다시 만들어야 하면

1. https://supabase.com/dashboard → **dropbid** → 위쪽 **`Connect`**
2. **`Direct` (Connection string)** 탭 → **`Transaction pooler`**
   - `pooler.supabase.com` 이 들어있고 `:6543` 으로 끝나는 것이 맞습니다
   - `db.xxx.supabase.co:5432`(Direct)나 `:5432` pooler(Session)는 **아닙니다**
3. `[YOUR-PASSWORD]` 를 실제 비밀번호로 교체 (대괄호도 지우기)
   - 비밀번호를 모르면 Settings → Database → `Reset database password`
4. Vercel → Settings → Environment Variables → `DATABASE_URL` 수정 → **다시 배포**

오른쪽 위 "로그인 대신" 에서 사람을 바꿔 가며 보세요.

| 누구로 | 볼 수 있는 것 |
|---|---|
| 이수집 / 박덕후 | 경매 목록, 입찰. 번갈아 입찰하면 경쟁이 붙습니다 |
| 김창작 | 상품 등록, 내가 올린 것 상태 |
| 운영자 | 검수 — 승인해야 경매가 열립니다. 다른 사람에겐 이 메뉴가 안 보입니다 |
| 최신규 | 연락처가 없어 입찰이 막힙니다. 마이페이지에서 등록하면 풀립니다 |
