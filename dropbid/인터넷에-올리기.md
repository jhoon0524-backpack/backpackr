# 인터넷에 올리기 (Vercel)

DB(Supabase)는 이미 준비를 끝냈습니다. **Vercel 쪽만 남았고, 여기는 직접 하셔야 합니다.**
제 권한으로는 Vercel 프로젝트를 만들 수 없어서(403) 대신 해 드릴 수가 없습니다.

10~15분이면 끝납니다.

---

## 먼저 알아 두실 것

- **주소를 아는 사람은 누구나 들어옵니다.** Vercel 무료 플랜은 비밀번호를 걸 수 없습니다.
- **아직 로그인이 없습니다.** 화면 위쪽 선택으로 아무나 판매자·운영자가 될 수 있습니다.
  들어온 사람이 상품을 승인하거나 반려할 수 있다는 뜻입니다.
- 그래서 **주소를 아무 데나 올리지 마시고**, 보여 줄 사람에게만 알려 주세요.
- 나중에 내리려면: Vercel 프로젝트 → Settings → 맨 아래 Delete Project.

---

## 1단계 — 데이터베이스 주소 챙기기 (5분)

1. https://supabase.com/dashboard 접속 → **dropbid** 프로젝트를 엽니다.
2. 화면 위쪽 **`Connect`** 버튼을 누릅니다.
3. **`Transaction pooler`** 라고 적힌 칸의 문자열을 복사합니다.
   `postgresql://postgres.watereetyukaayzbvkkt:[YOUR-PASSWORD]@...pooler.supabase.com:6543/postgres`
   처럼 생겼습니다.

   > **`Session pooler` 나 `Direct connection` 말고 반드시 `Transaction pooler`** 입니다.
   > 나머지는 Vercel 같은 환경에서 접속이 금방 동납니다.

4. 복사한 문자열에서 **`[YOUR-PASSWORD]` 부분을 실제 비밀번호로 바꿉니다.** 대괄호도 지웁니다.
   - 비밀번호가 기억나지 않으면: 왼쪽 아래 **Settings → Database →
     `Reset database password`** 로 새로 정합니다. (지금은 데이터가 연습용뿐이라 바꿔도 됩니다)

5. 완성된 문자열을 메모장에 잠깐 붙여 둡니다. 2단계에서 씁니다.

---

## 2단계 — Vercel에 올리기 (5분)

1. https://vercel.com 접속 → 로그인 → **`Add New...` → `Project`**
2. **`Import Git Repository`** 에서 **`backpackr`** 를 찾아 **`Import`**.
   - 목록에 없으면 **`Adjust GitHub App Permissions`** 를 눌러 이 저장소를 허용해 주세요.
3. 설정 화면에서 **두 가지**를 만집니다.

   **(1) Root Directory** — `Edit` 을 누르고 **`dropbid`** 를 고릅니다.
   > 이걸 안 하면 "폴더를 못 찾겠다"며 실패합니다. 가장 많이 놓치는 부분입니다.

   **(2) Environment Variables** — 펼쳐서 한 줄 추가합니다.

   | 칸 | 넣을 값 |
   |---|---|
   | Name | `DATABASE_URL` |
   | Value | 1단계에서 만든 문자열 |

4. **`Deploy`** 를 누릅니다. 2~3분 걸립니다.

---

## 3단계 — 확인

배포가 끝나면 `dropbid-....vercel.app` 주소가 나옵니다. 눌러서 들어가 보세요.

**경매 3건이 보이면 성공입니다.**

화면 오른쪽 위 "로그인 대신" 에서 사람을 바꿔 가며 보세요.

| 누구로 | 볼 수 있는 것 |
|---|---|
| 이수집 / 박덕후 | 경매 목록, 입찰. 번갈아 입찰하면 경쟁이 붙습니다 |
| 김창작 | 상품 등록, 내가 올린 것 상태 |
| 운영자 | 검수 — 승인해야 경매가 열립니다. 다른 사람에겐 이 메뉴가 안 보입니다 |
| 최신규 | 연락처가 없어 입찰이 막힙니다. 마이페이지에서 등록하면 풀립니다 |

---

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| 빌드 실패, "No Next.js version detected" | Root Directory 가 `dropbid` 가 아닙니다. Settings → General 에서 고치고 재배포 |
| 화면은 뜨는데 경매가 안 보이고 오류 | `DATABASE_URL` 이 틀렸습니다. Settings → Environment Variables 에서 고친 뒤 **재배포해야** 반영됩니다 |
| `password authentication failed` | `[YOUR-PASSWORD]` 를 안 바꿨거나 대괄호가 남아 있습니다 |
| 접속이 끊겼다 붙었다 함 | `Transaction pooler` 가 아닌 다른 문자열을 쓰셨습니다 |

고칠 때마다 **Deployments → 맨 위 항목 → `⋯` → `Redeploy`** 를 눌러야 반영됩니다.
