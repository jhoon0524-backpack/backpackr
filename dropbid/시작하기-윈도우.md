# 내 컴퓨터에서 Dropbid 켜기 (윈도우)

개발을 해 본 적 없어도 따라 할 수 있게 썼습니다.
**처음 한 번만 30~40분** 걸리고, 그다음부터는 켜는 데 10초입니다.

중간에 막히면 그 단계 번호와 화면에 뜬 글자를 그대로 알려 주세요.

---

## 미리 알아 둘 것

- **인터넷에 올라가지 않습니다.** 전부 내 컴퓨터 안에서만 돕니다. 나 말고는 아무도 못 봅니다.
- **뭘 잘못 눌러도 괜찮습니다.** 연습용 데이터라 언제든 지우고 다시 시작할 수 있습니다.
- 로그인·결제·사진 업로드·알림은 아직 안 붙어 있습니다. 화면 위쪽에서 **사람을 골라 가며**
  판매자·구매자·운영자 입장을 오갈 수 있습니다.

---

## 1단계 — Node.js 설치 (약 5분)

앱을 돌리는 프로그램입니다.

1. https://nodejs.org 에 들어갑니다.
2. **LTS** 라고 쓰인 초록색 버튼을 누릅니다. (두 개 중 왼쪽, "권장" 쪽)
3. 내려받은 파일을 두 번 눌러 실행합니다.
4. **계속 "Next" 만 누르면 됩니다.** 아무것도 바꾸지 마세요. 마지막에 "Install" → "Finish".

---

## 2단계 — PostgreSQL 설치 (약 10분)

데이터를 담아 두는 곳입니다. 상품·입찰 기록이 여기 들어갑니다.

1. https://www.postgresql.org/download/windows/ 에서
   **"Download the installer"** 를 누릅니다.
2. 가장 위(최신 버전) 윈도우용을 내려받아 실행합니다.
3. 설치 화면에서:
   - 설치 위치, 구성 요소 → **그대로 두고 Next**
   - **비밀번호를 정하라는 화면이 나옵니다.** 여기가 유일하게 중요합니다.
     - 원하는 비밀번호를 넣고 **꼭 어딘가에 적어 두세요.** 4단계에서 씁니다.
     - 예: `dropbid1234` (한글·공백·따옴표는 넣지 마세요)
   - 포트 → **5432 그대로 두고 Next**
   - 나머지 → 계속 Next → Install
4. 맨 마지막에 **"Stack Builder"** 를 실행할지 묻는 체크박스가 있으면 **체크를 풀고** 끝냅니다.

---

## 3단계 — 코드 내려받기 (약 3분)

1. https://github.com/jhoon0524-backpack/backpackr/tree/claude/godot-dev-setup-3kkgnt 에 들어갑니다.
2. 초록색 **`< > Code`** 버튼 → **`Download ZIP`**
3. 내려받은 ZIP 파일에서 **마우스 오른쪽 → "압축 풀기"**
4. 압축을 푼 폴더 안으로 들어가면 `dropbid` 라는 폴더가 있습니다. **이 폴더를 기억해 두세요.**

---

## 4단계 — 비밀번호 알려 주기 (약 2분)

2단계에서 정한 비밀번호를 앱에게 알려 줍니다.

1. `dropbid` 폴더 안에서 **오른쪽 클릭 → 새로 만들기 → 텍스트 문서**
2. 파일을 열고 아래 한 줄을 씁니다. `여기에비밀번호` 자리에 2단계 비밀번호를 넣으세요.

   ```
   POSTGRES_PASSWORD=여기에비밀번호
   ```

3. 저장하고 닫습니다.
4. 파일 이름을 **`.env.local`** 로 바꿉니다. (앞의 점까지 포함)
   - 이름 바꾸기가 안 되면: 탐색기 위쪽 **보기 → 파일 확장명** 체크를 켜고 다시 하세요.
   - `.env.local.txt` 가 되면 안 됩니다. 뒤의 `.txt` 를 지워야 합니다.

---

## 5단계 — 준비하고 켜기 (약 10분, 처음만)

1. `dropbid` 폴더 안에서 **주소창을 누르고** `cmd` 라고 친 뒤 Enter.
   (검은 창이 뜹니다. 이게 명령을 넣는 곳입니다.)

2. 아래를 한 줄씩 복사해 붙여넣고 Enter. **한 줄이 끝날 때까지 기다렸다가** 다음 줄로 갑니다.

   ```
   npm install
   ```
   → 몇 분 걸립니다. 글자가 잔뜩 올라가는 게 정상입니다.

   ```
   npm run db:setup
   ```
   → `완료` 가 나오면 성공입니다.

   ```
   npm run dev
   ```
   → `Ready` 또는 `localhost:3000` 이 보이면 켜진 것입니다.

3. 브라우저를 열고 주소창에 **`localhost:3000`** 을 칩니다.

**이 검은 창은 끄지 마세요.** 끄면 앱도 꺼집니다.

---

## 다음부터 켤 때

1~4단계는 다시 안 해도 됩니다.

1. `dropbid` 폴더에서 주소창에 `cmd` → Enter
2. `npm run dev`
3. 브라우저에서 `localhost:3000`

---

## 무엇을 볼 수 있나

화면 오른쪽 위 **"로그인 대신"** 에서 사람을 바꿔 가며 보세요.

| 누구로 | 볼 수 있는 것 |
|---|---|
| **이수집 / 박덕후** | 경매 목록, 입찰. 두 사람으로 번갈아 입찰하면 경쟁이 붙습니다 |
| **김창작** | 상품 등록(`상품 등록`), 내가 올린 것 상태(`마이페이지`) |
| **운영자** | 검수(`검수`) — 승인해야 경매가 열립니다. 다른 사람에게는 이 메뉴가 안 보입니다 |
| **최신규** | 연락처가 없어 입찰이 막힙니다. 마이페이지에서 등록하면 풀립니다 |

**한 바퀴 돌려 보기**: 김창작으로 상품 등록 → 운영자로 검수 승인 →
이수집·박덕후로 번갈아 입찰 → 마이페이지에서 결과 확인.

---

## 처음부터 다시 하고 싶으면

연습하다 데이터가 엉키면 검은 창에서:

```
npm run db:seed
```

연습용 데이터가 처음 상태로 돌아갑니다.

## 자주 막히는 곳

| 화면에 뜬 글자 | 뜻과 해결 |
|---|---|
| `POSTGRES_PASSWORD 가 없습니다` | 4단계의 `.env.local` 파일이 없거나 이름이 `.env.local.txt` 입니다 |
| `PostgreSQL 에 연결하지 못했습니다` | 비밀번호가 틀렸거나 PostgreSQL 이 꺼져 있습니다. 컴퓨터를 한 번 재시작해 보세요 |
| `'npm' 은(는) ... 명령이 아닙니다` | 1단계 Node.js 설치 후 **검은 창을 껐다 다시** 열어야 합니다 |
| 브라우저에 아무것도 안 뜸 | `npm run dev` 를 실행한 검은 창이 켜져 있는지 확인하세요 |
