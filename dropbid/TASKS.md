# 할 일 목록

한 항목은 30분 이내에 끝낼 크기로 유지한다.
"~시스템 구현", "~전체 완성" 같은 항목이 보이면 그 자리에서 쪼갠다.
위에서부터 순서대로 진행한다.

## [기반]
- [ ] Next.js(App Router) + TypeScript + Tailwind 프로젝트 생성 및 의존성 설치
- [ ] 검증 명령 3개(`npm test`, `npm run lint`, `npx tsc --noEmit`)가 빈 프로젝트에서 통과하는지 확인 (테스트 러너 셋업 포함)
- [ ] CI 설정 — 푸시할 때 검증 명령 3개 자동 실행
- [ ] Supabase 로컬 개발 환경 셋업 (`supabase init` + `supabase start`, 접속 확인)
- [ ] 환경변수 골격 정리 (`.env.example` — Supabase, 카카오, 포트원 키 자리만)

## [데이터]
- [ ] 스키마 정의 1 — `profiles`(연락처 포함), `products`(상태 등급·후원 인증 이미지·`pending/scheduled` 상태)
- [ ] 스키마 정의 2 — `drops`(회차·시작/마감 시각), `auctions`(현재가·최고입찰자·마감 시각·연장 횟수·`live/sold/unsold/payment_failed` 상태)
- [ ] 스키마 정의 3 — `bids`(입찰 시도 기록: 성공·거부 모두, 사유 코드 포함), `orders`(결제 기한·상태), `notifications`(발송 기록·실패 로그)
- [ ] 마이그레이션 파일 작성 (실행은 사람이)
- [ ] `place_bid(auction_id, user_id, amount)` DB 함수 작성 — `FOR UPDATE` 잠금, 거부 규칙 4종, 현재가 갱신, 30초 연장(최대 20회)
- [ ] `place_bid` 단위 테스트 — 거부 4종 + 연장 + 연장 상한 (로컬 Supabase 대상)
- [ ] `place_bid` 동시성 테스트 — 동일 금액 동시 입찰 100건 중 1건만 성공 (인수 조건)
- [ ] 마감 처리 DB 함수 작성 — 기한 지난 `live` 를 `sold`/`unsold` 전환, 멱등 보장
- [ ] 마감 처리 멱등 테스트 — 두 번 연속 실행해도 낙찰 확정 1회 (인수 조건)
- [ ] DB 권한 설정 — 앱 역할에서 `bids`/`auctions` 직접 쓰기 REVOKE, `place_bid` 만 EXECUTE 허용
- [ ] pg_cron 잡 정의 작성 — 1분 주기 마감 처리, 실행·처리 건수 기록 (등록은 사람이)

## [기능]
- [ ] 카카오 로그인 연동 (Supabase Auth) — 가입 시 이메일·닉네임 저장
- [ ] 연락처 등록 화면·API + 미등록 시 상품 등록/입찰 차단 가드
- [ ] 이미지 업로드 (Supabase Storage) — 용량·형식 검증, 실패 시 허용 형식 안내
- [ ] 상품 등록 API — 필수 항목 검증(사진 3장·후원 인증·시작가 1,000원 이상), `pending` 저장
- [ ] 운영자 검수 API — 승인 시 다음 드롭 배정·`scheduled` 전환, 반려 시 사유 기록 (마감 지난 회차 배정 거부)
- [ ] 드롭 회차 생성·경매 `live` 전환 처리
- [ ] 입찰 API 라우트 — `place_bid` 호출만, 거부 사유 코드를 응답으로 전달
- [ ] 결제 연동 1 — 포트원 결제 요청 생성, 낙찰 시 24시간 기한 부여
- [ ] 결제 연동 2 — 결제 완료 웹훅 처리, 판매자 배송 요청 상태 전환
- [ ] 결제 기한 만료 처리 — `payment_failed` 전환 (마감 스케줄러와 동일 주기)
- [ ] 알림 발송 모듈 — 알림톡 발송, 실패 시 이메일 폴백 + 실패 기록
- [ ] 알림 트리거 연결 — 상위 입찰 / 낙찰·유찰 / 결제 기한 3시간 전 / 반려

## [화면]
- [ ] 드롭 목록 — 마감 임박순, 스켈레톤·빈 화면(다음 드롭 예정)·실패(재시도) 상태
- [ ] 상품 상세 / 입찰 — 현재가·남은 시간 Realtime 갱신, 최소 입찰가 기본값, 거부 사유별 문구, 연결 끊김 시 폴링 폴백
- [ ] 상품 상세 — 마감 후 결과 표시 전환
- [ ] 상품 등록 폼 — 업로드 진행률, 항목별 오류 표시(입력값 유지), 검수 대기 안내
- [ ] 마이페이지 — 내 입찰 / 낙찰 / 판매 탭, 빈 화면 안내
- [ ] 결제 화면 — 낙찰 정보·기한 표시, PG 오류 시 기한 내 재시도 안내
- [ ] 운영자 검수 화면 — pending 목록, 후원 인증 이미지 확인, 승인/반려
