## [기능]
> 아래 항목 중 Auth·Storage·Realtime 이 필요한 것은 이 환경에서 검증할 수 없다.
> Docker 이미지 CDN 이 막혀 `supabase start` 가 안 된다. DB 로 검증되는 것부터 먼저 했다.
- [ ] 카카오 로그인 연동 (Supabase Auth) — 가입 시 이메일·닉네임 저장 **(Auth 필요)**
- [x] 연락처 — `place_bid` 차단 + 등록·변경 화면(`/me`). 형식은 DB 제약으로도 못박음
- [ ] 이미지 업로드 (Supabase Storage) — 용량·형식 검증, 실패 시 허용 형식 안내
- [x] 상품 등록 — 폼(`/sell`)과 검증 완료. 사진은 아직 주소 입력 (업로드는 Storage 필요)
- [x] 운영자 검수 — DB 함수와 화면(`/admin`) 완료
- [x] 드롭 회차 생성·경매 `live` 전환 처리 (`start_due_drops`, 스케줄러에 통합)
- [ ] 입찰 API 라우트 — `place_bid` 호출만, 거부 사유 코드를 응답으로 전달
- [ ] 결제 연동 1 — 포트원 결제 요청 생성, 낙찰 시 24시간 기한 부여
- [ ] 결제 연동 2 — 결제 완료 웹훅 처리, 판매자 배송 요청 상태 전환
- [x] 결제 기한 만료 처리 — `payment_failed` 전환 (마감 스케줄러와 동일 주기)
- [ ] 알림 발송 모듈 — 알림톡 발송, 실패 시 이메일 폴백 + 실패 기록 **(외부 API 키 필요)**
      적재(아웃박스)는 완료. 남은 것은 pending 을 집어 실제로 보내는 부분
- [x] 알림 트리거 연결 — 6종 전부 적재 (낙찰·유찰·미결제·상위 입찰·결제 기한 임박·검수 반려)
