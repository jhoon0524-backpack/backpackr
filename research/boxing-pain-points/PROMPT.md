# 복싱·타격 수련자 페인포인트 조사

## 목적
복싱(및 킥복싱·무에타이 등 타격 계열)을 취미로 수련하는 사람을 위한 서비스를 만들려 한다.
서비스 형태는 아직 정하지 않았다. 지금 필요한 건 "이 사람들이 실제로 무엇 때문에 힘들어하고, 무엇을 원하는가"의 1차 원문 데이터다.
해석이나 서비스 아이디어를 먼저 내지 말고, 원문 수집 → 구조화 → 집계 순서로 진행한다.

## 시작 전 확인
아래 사이트에 curl -I로 접속되는지 먼저 확인하고, 결과(200/403/실패)를 skipped.md 첫 줄에 적는다.
- https://www.reddit.com
- https://cafe.naver.com
- https://gall.dcinside.com
- https://www.youtube.com
접속이 안 되는 곳은 시도하지 말고 건너뛴다. 로그인이 필요한 곳도 시도하지 않는다.

## 대상 커뮤니티
한국어(우선):
- 네이버 카페: "복싱" 검색 후 회원수 상위 3개 카페
- 디시인사이드 복싱 갤러리, 격투기 갤러리
- 에펨코리아·더쿠·클리앙에서 "복싱장", "복싱 배우" 키워드 검색 결과
- 네이버 블로그·브런치의 "복싱 N개월 후기" 류 글
- 유튜브 복싱 강의 영상의 댓글 (조회수 상위 10개 영상)
영어(보조):
- reddit r/amateur_boxing, r/Boxing, r/kickboxing, r/Muaythai
- sherdog, boxingforum24

## 수집 대상 (이 3종만)
1. 불만·어려움 — "힘들다", "모르겠다", "그만뒀다", "돈 아깝다", "못 찾겠다" 등
2. 질문 — "어떻게 하나요", "정상인가요", "추천해주세요" 류. 질문 자체가 미충족 니즈다
3. 소망 — "~있었으면", "왜 없지", "누가 만들어줬으면"

찬반 토론·선수 이야기·경기 감상·장비 리뷰 중 불만이 없는 것은 제외.

## 저장 형식
data/raw.jsonl에 한 줄 = 한 건. 필드:
- id
- source (커뮤니티명)
- url
- date (작성일, 모르면 null)
- quote (원문 그대로. 요약·번역 금지. 최대 300자)
- type (불만 / 질문 / 소망)
- stage (입문 전 / 입문 1~3개월 / 3개월~1년 / 1년 이상 / 불명)
- theme (아래 분류표 중 하나, 없으면 "기타"에 넣고 이유 적기)
- pain_intensity (1~3: 그냥 언급 / 구체적 불편 / 그만두거나 돈·시간 손실 언급)

theme 분류표(초기안, 수집하면서 늘려도 됨):
체육관 찾기·비교 / 비용 / 코치·지도 품질 / 혼자 연습(집·홈트) / 스파링·부상 공포 /
실력 정체·성장 확인 불가 / 체중·다이어트 / 장비 선택 / 시간·일정 / 동기·지속 / 기타

## 작업 순서
1. 접속되는 커뮤니티 하나당 최소 30건, 전체 300건 이상 수집. 한 커뮤니티가 전체의 30%를 넘기지 말 것
2. 50건 모을 때마다 progress.md 갱신(커뮤니티별 건수, 막힌 곳)하고 git commit
3. 수집 완료 후 summary.md 작성:
   - theme × stage 교차표 (건수)
   - theme별 pain_intensity 3점 비율
   - 각 theme 대표 원문 인용 3개 (가장 구체적인 것)
   - "기타"로 분류된 것들 목록 — 새 theme 후보
   - 한국어 vs 영어 커뮤니티에서 차이가 나는 theme
4. summary.md 끝에 "수집하면서 눈에 띈 것" 섹션을 두되, 반드시 근거 건수와 인용 id를 붙인다. 근거 없는 인상은 쓰지 않는다
5. 끝나면 PR을 연다. PR 본문에 아래 "마지막에 보고할 것"을 넣는다

## 금지
- 서비스 아이디어·해결책 제안
- 원문을 요약하거나 표현을 다듬어서 quote에 넣기
- 한 글에서 같은 불만을 중복 등록
- 수집 건수를 채우려고 관련 없는 글을 포함
- 접속 실패를 "수집했다"로 처리

## 마지막에 보고할 것
- 총 건수, 커뮤니티별 건수, 스킵한 곳과 이유
- theme 분류표에서 바꾸는 게 좋겠다고 판단한 항목과 이유
- 이 데이터로 답할 수 없는 질문 (예: 실제 이탈률, 지불의사 금액)
