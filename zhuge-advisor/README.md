# 제갈량 상소문

매일 아침 7시, 그리고 컴퓨터를 켤 때마다 제갈량이 올리는 조언 창이 뜹니다.

| 파일 | 하는 일 |
|---|---|
| `sangsomun.html` | 상소문 본문. 더블클릭하면 브라우저에서 열립니다 |
| `install.bat` | 자동 실행 등록 (더블클릭 한 번) |
| `uninstall.bat` | 자동 실행 해제 |
| `intro.mp4` | (선택) 힉스필드로 만든 45초 서막 영상. 이 자리에 넣으면 상소문 위에서 먼저 재생됩니다 |
| `higgsfield/storyboard.html` | 그 영상을 만드는 제작 키트. 장면별 프롬프트·카메라 프리셋·나레이션 대본 |

## 설치 (윈도우)

1. 이 폴더(`zhuge-advisor`)를 통째로 내 컴퓨터에 내려받습니다.
   예: `C:\Users\내이름\Documents\zhuge-advisor`
2. `install.bat` 을 더블클릭합니다.
3. "등록되었습니다"가 보이면 끝입니다. 확인 삼아 상소문이 바로 한 번 열립니다.

폴더를 다른 곳으로 옮기면 `install.bat` 을 다시 한 번 실행합니다. 등록된 경로가 바뀌기 때문입니다.

## 언제 뜨나

- 매일 오전 7:00
- 윈도우에 로그인할 때마다
- 7시에 컴퓨터가 꺼져 있었으면, 다음에 켰을 때

작업 스케줄러에 `Zhuge-Liang-Sangsomun` 이라는 이름으로 등록됩니다.

## 내용 고치기

`sangsomun.html` 을 메모장으로 열어 글을 고치면 됩니다.
"오늘의 계책" 한 줄은 파일 아래쪽 `tips` 목록에서 날짜에 따라 돌아가며 나옵니다.

## 서막 영상 붙이기 (힉스필드)

1. `higgsfield/storyboard.html` 을 더블클릭해 엽니다.
2. 순서대로 따라 힉스필드에서 여섯 장면을 만들고 이어 붙입니다. 프롬프트는 복사 단추로 그대로 씁니다.
3. 완성한 MP4 를 `intro.mp4` 로 이름을 바꿔 이 폴더(`sangsomun.html` 옆)에 넣습니다.

다음부터 상소문 창이 열리면 영상이 먼저 소리 없이 재생되고, 나레이션 문장이 자막으로 아래에 뜹니다.
"소리 켜기"를 누르면 처음부터 소리와 함께 다시 재생됩니다. 영상 파일이 없으면 그 자리는 보이지 않습니다.

## 해제

`uninstall.bat` 을 더블클릭합니다. 파일은 남고 자동 실행만 사라집니다.

## 맥을 쓴다면

작업 스케줄러 대신 `launchd` 를 쓰면 됩니다. 필요하면 클로드 코드에 "맥용으로 바꿔 줘"라고 하면 됩니다.
