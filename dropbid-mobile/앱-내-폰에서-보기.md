# 앱을 내 휴대폰에서 보기

앱은 링크로 못 엽니다. 설치해서 보는 물건이라 그렇습니다.
가장 빠른 길은 **Expo Go** 입니다. 앱을 따로 만들지 않고, 휴대폰에 깔린
Expo Go 안에서 우리 앱을 띄웁니다. 30분이면 됩니다.

> 여기 컴퓨터(클로드가 쓰는 곳)에서는 못 해 드립니다.
> Expo 서비스로 나가는 길이 조직 정책으로 막혀 있어서 QR 도, 설치 파일도 못 만듭니다.

---

## 준비물

- 컴퓨터 (윈도우/맥 아무거나)
- 휴대폰
- **둘이 같은 와이파이에 있어야 합니다.** 이게 제일 자주 걸리는 부분입니다

---

## 1. 휴대폰에 Expo Go 깔기

- 아이폰: App Store 에서 **Expo Go**
- 안드로이드: Play 스토어에서 **Expo Go**

---

## 2. 컴퓨터에 코드 내려받기

Node.js 가 없으면 먼저 https://nodejs.org 에서 LTS 를 깔아 주세요.

### 윈도우 — **명령 프롬프트(cmd)** 를 쓰세요

`Windows 키` → `cmd` 입력 → Enter.

> **PowerShell 로 하지 마세요.** 기본 보안 설정이 npm 을 막습니다
> ("이 시스템에서 스크립트를 실행할 수 없으므로 npm.ps1 파일을 로드할 수 없습니다").
> 굳이 쓰시려면 먼저 한 번만 —
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` (관리자 권한 불필요, 물으면 Y)

```cmd
cd %USERPROFILE%\Documents
git clone https://github.com/jhoon0524-backpack/backpackr.git
cd backpackr\dropbid-mobile
npm install
```

> **첫 줄을 빠뜨리지 마세요.** 창이 `C:\Windows\system32` 에서 열리는 경우가 있는데,
> 거기는 윈도우 시스템 폴더라 파일을 못 만듭니다
> (`could not create work tree dir 'backpackr': Permission denied`).

### 맥·리눅스

```bash
cd ~/Documents
git clone https://github.com/jhoon0524-backpack/backpackr.git
cd backpackr/dropbid-mobile
npm install
```

`npm install` 은 3~5분 걸립니다. 아무 말 없어 보여도 도는 중입니다.

---

## 3. 앱 띄우기

```bash
npm start
```

터미널에 **QR 코드**가 뜹니다.

- 아이폰: 기본 카메라로 QR 을 비춥니다 → "Expo Go 에서 열기" 를 누릅니다
- 안드로이드: **Expo Go 앱을 열고** 그 안에서 QR 을 찍습니다

---

## 4. 무엇이 보이나

앱은 **인터넷에 올라간 우리 서버**를 봅니다. 컴퓨터에 DB 를 깔 필요가 없습니다.

지금 되는 것

- 이번 회차 목록 (판매자·사진·현재가·경쟁 인원)
- 회차 마감까지 남은 시간 (1초씩 셉니다)
- 상품을 눌러 상세 보기
- 마감된 경매의 낙찰·유찰·결제 기한 화면

**아직 안 되는 것 — 입찰·상품 등록·검수**

로그인이 먼저입니다. 지금 웹의 "사람 고르기" 는 시연용이라, 그대로 앱에 열면
아무나 남의 이름으로 입찰할 수 있습니다. 카카오 로그인이 붙은 뒤 엽니다.
앱 안에도 그렇게 적어 뒀습니다.

## 안 될 때

| 증상 | 까닭 |
|---|---|
| QR 을 찍었는데 안 열림 | 휴대폰과 컴퓨터가 **다른 와이파이**입니다. 같은 곳으로 맞춰 주세요 |
| 열렸는데 "불러오지 못했습니다" | 휴대폰이 인터넷이 안 되거나, 서버가 잠깐 쉬는 중입니다. 아래로 당겨 새로 고쳐 보세요 |
| 회사·카페 와이파이라 안 됨 | 기기끼리 못 붙게 막아 둔 곳이 많습니다. 휴대폰 핫스팟에 컴퓨터를 물리면 됩니다 |
| `Permission denied` 로 clone 실패 | 창이 `C:\Windows\system32` 에서 열렸습니다. `cd %USERPROFILE%\Documents` 부터 하세요 |
| `npm.ps1 파일을 로드할 수 없습니다` | PowerShell 의 보안 설정입니다. **cmd 를 쓰시거나** 위의 `Set-ExecutionPolicy` 를 한 번 실행하세요 |
| `git`/`npm` 을 못 찾음 | Node.js(https://nodejs.org) 와 Git(https://git-scm.com) 을 깔고 창을 새로 여세요 |

## 진짜 설치 파일(.apk / .ipa)이 필요하면

앱스토어에 올리거나 남에게 보내려면 EAS Build 를 씁니다.
**여기서는 못 만듭니다** (Expo 서비스가 막혀 있습니다). 사장님 컴퓨터에서 —

```bash
npm install -g eas-cli
eas login          # Expo 계정이 필요합니다 (무료)
eas build --platform android --profile preview
```

빌드는 Expo 서버에서 돌고, 끝나면 내려받을 링크가 나옵니다.
아이폰은 애플 개발자 계정(연 $99)이 있어야 실기기에 넣을 수 있습니다.
