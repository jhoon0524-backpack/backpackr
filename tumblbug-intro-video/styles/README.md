# 텀블벅 소개영상 — 스타일 시안 4종

각 시안: 스토리보드 이미지(`out/*_storyboard.jpg`) + 16초 샘플 영상(`out/*.mp4`). 음악은 시안마다 직접 합성한 오리지널 곡.

| 시안 | 스타일 | 화면 | 톤 / 음악 | 추천 용도 |
|---|---|---|---|---|
| A | 키네틱 타이포그래피 — 검정 화면에 큰 글자가 비트에 맞춰 박힘 | 16:9 | 자신감·에너지 / 빠른 일렉트로닉 128BPM | 유튜브 프리롤, 행사 오프닝, 브랜드 캠페인 |
| B | 종이 위 손그림 스토리 — 연필 낙서·손글씨·종이 오리기 | 16:9 | 따뜻함·진정성 / 잔잔한 피아노 | 창작자 모집, 브랜드 필름, 연말 회고 |
| C | 레트로 픽셀 게임 — 캐릭터가 후원 하트를 모아 스테이지 클리어 | 16:9 | 유쾌함·게임 감성 / 칩튠(8비트) | 게임·보드게임 창작자 모집, 게임 행사, SNS |
| D | 세로형 숏폼 — 후원 알림이 쌓이며 달성률 링이 차오름 | 9:16 | 속도감·기대감 / 경쾌한 팝 | 인스타 릴스, 유튜브 쇼츠, 틱톡 광고 |

- 실제 수치(누적 5,000억 원+, 1,000만 건+, 약 8만 개)는 2026년 6월 29일 기준 텀블벅 발표. 그 외 달성률·후원자 이름·금액은 연출용 가상 예시.
- 폰트: Pretendard, 나눔펜(손글씨), 갈무리(픽셀) — 모두 SIL OFL 1.1 (`../fonts/`)
