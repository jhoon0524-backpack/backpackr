# 측정 스크립트

게임 손맛·흐름을 숫자로 재는 자동 측정입니다. 브라우저(크롬)를 화면 없이 띄워 게임을 한 프레임씩 직접 돌리며 잽니다.
**게임을 하는 데는 필요 없습니다.** 고친 뒤 "전과 똑같은지, 깨진 데 없는지" 확인할 때 씁니다.

## 돌리는 법
Node.js 18 이상이 설치돼 있어야 합니다. 처음 한 번만:
```
cd beltscroll/tests
npm install
npx playwright install chromium
```
전부 돌리기 (몇 분 걸림):
```
node run-all.js
```
각 측정의 마지막 줄이 화면에 나오고, 전체 출력은 `tests/out/results.txt` 에 남습니다. 마지막 줄의 `errors` 가 비어 있고 `기대 N / N` 이 맞는지 먼저 보되, **정상 여부의 판정은 고치기 전·후 results.txt 를 통째로 비교해 달라진 줄이 없는지**로 합니다(측정마다 출력 모양이 달라 마지막 줄만으로는 판정이 안 됩니다).

바꾸기 전 버전과 비교하려면, 전 버전 사본의 index.html 주소를 주고 한 번 더 돌린 뒤 두 results.txt 를 비교합니다:
```
GAME_URL=file:///전버전/폴더/index.html node run-all.js
```
(`touch` 는 실제 시간으로 기다리는 측정이라 걸은 거리가 돌릴 때마다 조금씩 다릅니다. 나머지는 같아야 합니다.)

## 무엇을 재나
| 파일 | 재는 것 |
|---|---|
| `rhythm` | 제자리에 선 thug·brute 에게 1→2→3타가 모두 맞는지 (헛스윙 0, 피격 0) |
| `still` | 히트스톱: 맞은 뒤 주인공·적이 몇 프레임 멈추는지 |
| `feel` | 타격감 숫자: 멈춤·번쩍임·카메라 킥·넉백 거리, 최속 연타 |
| `bufwin` | 선입력을 받아 주는 프레임 구간, 화면 끝 3타 |
| `jumpbuf` | 공격+점프 동시 입력 뒤 남은 입력이 저절로 공격으로 나가지 않는지 (모두 null 이 정상) |
| `combo` | 전체화면 × 기기(휴대폰·터치 노트북·PC) × 가로/세로 화면 배치 |
| `edge` | 주인공을 양쪽 벽에서 1px씩 옮겨 324가지: 적이 화면 안에서 공격하는지 |
| `wall2` | 벽 앞 적 2명에게 3타: 적이 벽 밖으로 안 나가는지 |
| `wallthrow` | 벽 앞에서 던지기 102가지: 주인공·적이 화면 밖으로 안 튀는지 |
| `stage4` | 4단계: 적 공격 예고·돌진·피하기, 착지 경직, 기상 무적, 사망, 추가타 |
| `s4f` | 4단계 후속: 화면 밖 적, 벽 앞 서는 자리 |
| `grab` · `grabfix` | 잡기·무릎·던지기 |
| `throwstomp` | 던진 적에게 달려가 내려찍기 |
| `sound` · `sound2` · `sound3` | 타격음 (`sound` 의 "1 기본 꺼짐" 이름은 소리 기본 켜짐으로 바뀌기 전 것) |
| `sfx` · `sfx2` | 효과음 4종, 첫 입력에 소리 장치 깨우기 |
| `ko` | 쓰러짐 소리 시점 |
| `vibe` · `vibe2` · `vibe3` | 진동, 기기별 진동 버튼 표시 |
| `touch` | 휴대폰 터치 조작 (스크린샷 `out/m*.png`) |
| `action` | PC 에선 터치 버튼이 안 보이고 휴대폰에선 보이는지 |
| `fix3` | 3단계 수정 확인: 적 2명 겹친 채 강타 멈춤 중 밀림 0, 게임오버 전환 때 화면 밀림 안 남음 |
| `fix4` | 4단계 수정 확인: 착지 경직 마지막 프레임 경계의 Z, 공중 피격 뒤 착지, 기상 직후 연타, 적 2명 |
| `determ` | 같은 입력이면 같은 판인지: 클리어까지 3판 기록 비교 |
| `addenemy` | data 파일만 고쳐 새 적을 넣으면 동작하는지 (사본에서) |
| `typo` | data 파일 이름 오타 알림창 |
| `test` | 자동 플레이로 웨이브 3개 클리어 (스크린샷 `out/0*.png`). 실제 시간으로 노는 측정이라 돌릴 때마다 위치 숫자가 다름 |
| `shots.js` (run-all 에 없음) | 전후 비교 사진: `node shots.js before` → 고친 뒤 `node shots.js after` |
