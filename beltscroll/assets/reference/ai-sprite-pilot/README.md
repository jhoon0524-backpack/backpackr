- 출처: 오너가 ChatGPT 로 만든 윤무겸 스프라이트 시트(`original_generated_sheet.png`)와 자동으로 잘라 낸 동작 15장(`frames/`), 인덱스(`frame_index.json`), 미리보기(`reference_contact_sheet.png`). 오너가 함께 준 안내문은 `README-from-owner.md`.
- **위상: 캐릭터 아트 레퍼런스(외관·자세 참고)이며 정식 디자인 기준(03 설정화)을 대신하지 않는다.** 게임이 직접 읽지 않는다. 본 게임 시트(`data/sprites.js`·`assets/sprites/mugyeom.png`)를 덮어쓰지 않는다.
- 이 폴더는 실험 브랜치 `experiment/mugyeom-ai-sprites` 에만 있다 (`joseon-p1-sprites` 는 그대로).
- 권리: AI 생성 이미지는 저작권 보호·양도 대상이 아닐 수 있고, 생성 서비스 이용 약관(상업적 이용)을 오너가 확인해야 한다 (`docs/p1-ai-experiment.md` 위험 절). 아티스트에게 참고로 넘길 때는 "AI 생성물"이라고 표기한다.
