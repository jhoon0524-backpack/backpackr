# 조선 퇴마전 윤무겸 — AI 생성 스프라이트 레퍼런스 15동작

이 파일들은 ChatGPT가 생성한 **콘셉트 스프라이트 시트를 자동 분할한 레퍼런스**입니다. 완성된 게임용 스프라이트가 아닙니다.

- 원본: `original_generated_sheet.png` (투명 RGBA, 1448x1086).
- `frames/`: 15개 개별 컷. 두 번째 줄의 베기 이펙트는 이웃 포즈와 근접해 일부 잘리거나 겹칠 수 있습니다. 프레임 경계/캐릭터 중심점/발바닥 위치가 일관되지 않습니다.
- `frame_index.json`: 컷 인덱스와 원본 위치.
- `reference_contact_sheet.png`: 보기 편하게 모은 미리보기.

## 바로 게임에 넣지 않는 이유
현재 게임 규격은 2px 도트, 64×64 단위 셀(scale 2), 캐릭터 약 110px, 1·2·3타 실제 공격 판정 57px 및 그림 칼끝 56px입니다. 이 AI 원본은 고해상도이고 동작별 크기/기준점이 달라 그 요건을 충족하지 않습니다. 투명도 가장자리도 다수 반투명 픽셀입니다.

## 다음 작업 (코드 담당에게)
1. 기존 `joseon-p1-sprites` 브랜치와 38개 테스트 기준선을 보존. 별도 `experiment/mugyeom-ai-sprites` 브랜치 생성.
2. 본 패키지는 **디자인과 포즈 참고용**으로만 `assets/reference/ai-sprite-pilot/`에 저장. 기존 정식 스프라이트/메인 게임에 직접 덮어쓰지 않음.
3. 서기(`00_idle`)와 1타(`07_downslash` 등을 참고) 두 장만 먼저 64×64 / scale 2에 맞춰 **수작업 리드로잉**. 단순 축소본(B1)과 도트 보정본(B2)을 따로 저장.
4. 칼끝 56px, 발 기준점, 배경과의 명암 대비, 모바일 실제 크기, 공격 동작 연속성을 확인. 이펙트는 본체와 분리 권장.
5. 기존 코드 시안(A), B1, B2의 PC/모바일 동일 장면 비교와 측정 기록. 실제 적용 전 오너 승인.

**중요:** AI 이미지는 외관 참조 자료입니다. 생성된 동작이 동일 인물, 정확한 프레임 배치, 검의 타격 궤적을 보장하지 않으므로 최종 승인 없이 배포하면 안 됩니다.
