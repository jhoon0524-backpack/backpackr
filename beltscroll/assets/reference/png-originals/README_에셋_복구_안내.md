# 조선 퇴마전: 기존 에셋 복구 및 검토 자료

이 패키지는 기존 작업물에서 이미 만들어 둔 그래픽을 **복구·비교**하기 위해 복사한 것입니다. 새로운 이미지를 생성하지 않았으며, GitHub 저장소는 수정하지 않았습니다.

## 출처
- `legacy_embedded_1.png`: 기존 `joseon-exorcism-mobile-fixed.html`에 data URI로 포함되어 있던 전투 배경(1254×1254)
- `legacy_embedded_2.png`: 같은 HTML 내부 전투 아틀라스(1536×1024). 화면은 5열 × 2행 구역을 선택해 캔버스로 복사하도록 구현되어 있음.
- 그 외 `.png` 5개: 기존 ChatGPT 파일 라이브러리에서 가져온 조선 퇴마전 캐릭터 설정화·전투/게임 아트 시트·UI 시안.

## 중요 구분
1. 시트/콘셉트는 **디자인 레퍼런스**입니다. 게임에서 쓸 수 있는 개별 투명 PNG 프레임/애니메이션이 모두 준비된 것은 아닙니다.
2. HTML 내 아틀라스에는 실제 사용 가능한 캐릭터/괴물 컷이 있지만 **턴제 전투용 정적 컷**이며, 3타·점프·잡기·피격/다운 동작 애니메이션이 아닙니다.
3. 레거시 배경은 **탑다운 전투 공간** 형태여서 그대로 좌우 진행 벨트스크롤 배경으로 쓰기보다 색감/소품 참고 또는 레이아웃 재구성이 필요합니다.
4. GitHub `backpackr`의 `beltscroll/art.js`에서 생성하는 파이널파이트 풍의 현대 도시/싸움꾼 그래픽과 섞지 마세요. 첫 전환 단계에서는 게임 로직을 남기고 조선풍 아트를 별도 스킨으로 교체합니다.
5. 기존 파일이나 다른 프로젝트를 삭제하지 마세요.

## 기술 방향
- GitHub 기준: `beltscroll/index.html` + `art.js` + `data/*.js` = 브라우저 Canvas 게임(지상 8방향 이동, 콤보, 점프/다운, 잡기, 터치 입력, 웨이브)
- 기존 검증 리듬/피격값 유지, 첫 직업 **벽사검객**으로 시작. 파귀무인·벽력포수·봉령술사 직업은 문서 정의 후 확장.
- `beltscroll/tests`의 Playwright 측정/회귀 테스트를 로컬에서 돌려 기준선 확보. 저장소의 progress.md 결과는 '기록'이며 이 패키지에서 재실행하지 않았습니다.
- Godot으로 즉시 전환하지 말고, 브라우저 플레이형 수직 슬라이스(조선 배경+벽사검객+귀물 1종+콤보)를 먼저 만듭니다. 추후 네이티브 출시 요건/성능이 정해지면 엔진 재평가.
