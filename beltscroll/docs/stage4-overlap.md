# 4단계 상태 겹침 점검표 (CLAUDE.md 4번 상태 겹침 규칙)

새 상태값마다 ① 설정·감소·초기화 지점 ② 기존 상태와 겹칠 때 누가 처리하는지.

| 새 상태 | 설정 | 감소/진행 | 비움 | 겹침 처리 |
|---|---|---|---|---|
| 적 방향 고정 (`e.attack > 0` 동안 `e.dir` 안 바뀜) | 공격 준비 시작 | — | 피격(`attack=0`), 다운 | 히트스톱: 적 처리 전체 멈춤 / 적끼리 밀기: 방향 무관 |
| 적 돌진 (공격 판정 직전 4프레임, 프레임당 최대 6px) | 공격 카운트다운 | 멈춤 게이트 안 | 피격 시 공격 취소 | 화면 제한: 적 루프 끝 + 밀기 뒤 `keepOnScreen` / 주인공을 뚫고 지나가지 않게 앞쪽 거리 20px에서 멈춤 |
| 동시 공격 제한 (살아있는 적 4명 이상이면 2명, 아니면 1명) | 공격 준비 시작 조건 | — | — | 히트스톱 중인 공격자도 계속 1명으로 셈 |
| 적 속도 1.5배 (주인공 공격 남은 프레임 1~10) | 매 프레임 계산 | — | — | 주인공 멈춤 중엔 남은 프레임이 안 줄어 그대로 / 추가타·점프 공격도 공격으로 셈 |
| 적 기상 무적 `e.invuln` 20 | 다운 끝(체력 남음) | 적 멈춤 게이트 안 | 피격 불가라 없음 | 주인공 공격·추가타·점프 공격 모두 건너뜀 / 깜빡임 표시 |
| 추가타 1회 `e.stomped` | 추가타 명중 | — | 새로 다운될 때 false | 다운 시간 연장 없음, 넉백 없음 / 처치면 heavy 손맛, 다운 끝날 때 사망 |
| 주인공 현재 기술 `p.move` | 공격·추가타 시작 | — | 공격 끝 / 피격 | 선입력·포즈·판정 범위 표시가 모두 `p.move` 를 본다 |
| 점프 공격 `p.jumpKick` (점프당 1회) | 공중에서 Z | 멈춤 게이트 안 | 착지, 피격 | 히트스톱 중 공중에서 멈춤(중력도 멈춤) / 선입력과 무관 |
| 착지 경직 `p.landLag` 6 | 모든 점프 착지 | 멈춤 게이트 안 | 피격 | 경직 중 이동·공격·점프 불가, 입력 버림 |
| 같은 프레임 Z+X (땅) | — | — | — | 공격 우선, 점프 무시 (공격 중 점프 불가) |
| 주인공 기상 무적 20 | 다운 끝(체력 남음) | 기존 `invuln` | — | 기존 깜빡임 |
| 주인공 사망 | 체력 0 피격 → 넘어짐(heavy 넉백) | 다운 50프레임 | — | 다운 끝나면 게임오버 / 적은 다운 중인 주인공을 공격하지 않음(기존) |

위치를 바꾸는 줄(`.x +=`, `.x =`) 실행 순서: 주인공 이동 → 주인공 전진(lunge) → 주인공 미끄러짐 → 주인공 화면 제한 → 적마다 [미끄러짐 → 화면 제한 → (공격 중) 돌진 → (걷기) 이동 → 화면 제한] → 적끼리 밀기 → 적 화면 제한.
