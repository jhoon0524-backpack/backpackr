아직 처리 안 한 겹침 (오너 판단 대기): 화면에 아직 안 들어온 적(`entered=false`)도 공격 준비·돌진을 할 수 있다 → 보이지 않는 적에게 맞을 수 있음. 시야 폭(검은 띠) 결정과 함께 오너 보고에 올림.

위치를 바꾸는 줄 실행 순서: 주인공 이동 → 주인공 전진 → 주인공 미끄러짐 → 주인공 화면 제한 → 적마다 [미끄러짐 → 화면 제한 → (공격 중) 돌진 → 화면 제한 → (걷기) 이동 → 화면 제한] → 적끼리 밀기 → 적 화면 제한.
