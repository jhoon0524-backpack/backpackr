## B. 3단계 — 타격감
그림·웨이브는 건드리지 않는다. 2단계 리듬 값은 바꾸지 않는다 (바꿔야 하면 바꾸기 전에 보고하고 멈춘다).
1. `FEEL`에 프리셋 2개: `normal`(1·2타, 플레이어 피격), `heavy`(3타, 적을 죽이는 타격; 점프 공격은 4단계에서 연결). 항목: 히트스톱 프레임, 카메라 킥 세기·지속, 넉백 초기 속도·감속, 플래시 지속.
2. 히트스톱: 맞는 순간 공격자와 맞은 쪽만 멈춘다. 그동안 스파크·파티클·카메라 킥은 계속 진행한다. 출발값 normal 4프레임, heavy 10프레임.
3. 넉백: 순간이동을 없애고 초기 속도 + 매 프레임 감속으로 미끄러지게 한다. normal은 2단계의 4px 유지, heavy는 60px 이상.
4. 카메라 킥: 무작위 떨림 대신 타격 방향으로 밀렸다 복귀. 출발값 normal 0~2px·3프레임, heavy 6~8px·8프레임.
5. 적을 죽이는 타격은 무조건 heavy, 흰 플래시 유지 시간 2배.
6. 디버그 키 `F`(모든 타격 normal↔heavy 강제 전환, 화면 구석에 현재 모드 표시), `G`(0.25배속).
7. 측정: 히트스톱 중에도 2단계 선입력이 정상 동작하는지(히트스톱 때문에 기억해둔 입력이 사라지거나 콤보 유효 시간이 끝나지 않는지) 2단계와 같은 24가지 경우로 다시 실측한다. MISS 0 유지가 조건이다.
8. CLAUDE.md 7번 순서대로 director 검수를 거친 뒤 보고한다.
