# 벽사검 사거리 확장 (전투 밸런스 변경)

오너 결정 (2026-10-27): 앞서 정한 "칼 54px, 공격 범위 유지"를 바꿔, **칼이 실제로 닿는 거리까지 명중**하게 한다.
P0 시각 전환(PR #30, 브랜치 `joseon-p0-assets`)과 별개의 전투 변경이라 브랜치 `joseon-sword-reach` 에서 따로 관리한다. 원래 게임(`ccr-05037f70-jcsww6`)과 PR #30 은 그대로.

## 1. 정한 방식
| 무엇 | 전 (PR #30) | 후 |
|---|---|---|
| 1타 | 칼 내려베기 그림(칼끝 39px), 판정: 적 **중심**이 몸 중심 앞 48px 안 | 칼을 앞으로 뻗은 45° 내려베기, 칼끝 57px. 판정: 적의 **몸(폭 w)** 앞면이 57px 안 = 칼끝이 몸에 닿으면 명중 |
| 2타 | 올려베기(칼끝 39px), 적 중심 48px | 45° 올려베기, 칼끝 57px, 몸 닿음 |
| 3타 | 발차기, 적 중심 58px | **내딛으며 수평 찌르기**, 칼끝 57px, 몸 닿음 (발차기로 두면 1·2타를 먼 거리에서 시작했을 때 3타가 헛나가 콤보가 끊김) |
| 점프 공격 | 발차기, 적 중심 50px | 그대로 (그림은 `airKick` 별칭으로 발차기 유지) |
| 쓰러진 적 추가타·잡기 | — | 그대로 |
| 뒤쪽 | 적 중심이 몸 뒤 10px 까지 맞음 | 그대로 (주인공 몸과 겹친 적만. 뒤 11px 부터 안 맞음) |
| 다른 줄 | 깊이 차 22px 미만만 | 그대로 |
| 공중 | 높이 차 40 미만 | 그대로 |

- **57px 를 고른 이유 (측정으로 결정):** 칼날 약 54px(17칸)을 45°로 뻗으면 칼끝이 몸 중심 앞 18칸에 닿고, 그 칸 오른쪽 끝이 57px. 40칸 캐릭터 프레임이 허용하는 가장 앞 자리(외곽선 1칸 남김)이기도 하다. 오너 임시 목표 54~60px 안. 수평 찌르기(3타)도 같은 자리에 맞춤.
- 적 중심 기준으로 환산하면 원귀(w 34) 74px, 도깨비(w 46) 80px 에서부터 맞는다 (예전 48px).
- 그림과 판정을 묶는 값: art.js `SWORD_TIP` = 18칸, index.html `ATTACKS[..].reach` = 57, `body: true`. `tests/reach.js` 가 칼끝 픽셀과 판정 끝 차이를 잰다 (지금 0px).
- 원래 그림(THEME street, 주먹)도 같은 판정을 쓴다 → 밤거리 그림에서는 주먹 끝(33px)보다 판정이 길다 (원래 버전은 브랜치 `ccr-05037f70-jcsww6`).

## 2. 적 접근·예고 거리 (일방적 제압 검토)
- 그대로 두면: 적이 공격 준비를 시작하는 거리(56px)가 새 사거리(원귀 74·도깨비 80) 안이라, 제자리 연타만으로 적이 **한 번도 공격 예고를 못 하고** 쓰러짐 (측정: 적 1~2명 4가지 경우 예고 0~2회·주인공 피격 0, 자동 플레이 체력 100 으로 무피해 클리어).
- 그래서 원래 설계 규칙("적은 주인공 사거리 8px 밖에서 예고")을 새 사거리에 맞춤:
  - 예고 시작 거리 `attackStartOf(e)` = 1타 사거리 57 + 몸 폭 절반 + 8 → 원귀 82, 도깨비 88 (예전 모두 56)
  - 돌진: 6프레임(예전 4), 돌진 거리 = 예고 시작 거리 − 32 → 원귀 50, 도깨비 56px (예전 24). 돌진을 마친 뒤 남는 거리가 예전(56 − 24 = 32)과 같아 **물러나 피할 수 있는 시간이 그대로**.
  - 적 공격 사거리(52)·속도·동시 공격 수·쿨다운·회수 구간 가속은 그대로.
- 측정 (`tests/dominance.js`, `BEFORE_URL` 로 PR #30 버전과 비교: 제자리 연타 900프레임, 적이 300px 밖에서 걸어옴)

| 경우 | 전 (예고 / 피격 / 전멸 프레임) | 후 |
|---|---|---|
| 원귀 1 | 1 / 1 / 231 | 1 / 1 / 216 |
| 도깨비 1 | 2 / 2 / 606 | 2 / 1 / 443 |
| 원귀 2 | 2 / 1 / 334 | 2 / 1 / 301 |
| 원귀 + 도깨비 | 3 / 3 / 627 | 2 / 1 / 448 |
| 자동 플레이 클리어 | 체력 76, 피격 3 | 체력 76, 피격 3 |
- 적은 여전히 예고하고 때린다. 칼이 길어진 만큼 처치가 빨라지고(약 10~30%), 덩치 적 상대 피격이 조금 줄었다.
- 물러나 피하기(원귀, `tests/stage4.js` 2번): 예고 후 12프레임 안에 물러나면 회피, 14프레임부터 맞음 — 전과 같음.

## 3. H 키 판정 표시
- 노란 상자 끝 = 다음 공격의 판정 끝 = 칼끝(57px). 적 발밑에 **몸 앞쪽 절반 막대**(빨강: 적 중심에서 주인공 쪽으로 w/2)를 새로 그림 — 칼 공격은 이 막대가 상자에 닿으면 맞는다 (앞·뒤 모두 성립: 뒤쪽 판정이 적 중심 기준이라 막대도 중심까지만). 점프 공격·추가타는 예전처럼 적 중심 십자가 상자 안이면 맞는다.

## 5. 검증
- 칼끝 vs 판정 (`tests/reach.js`): 1·2·3타 모두 칼끝 57px / 판정 57px / 차이 0px.
- 닿은 적만 맞음: 원귀·도깨비 × 좌우, 몸 앞면이 판정 끝 1px 안 → 맞음, 1px 밖 → 헛침.
- 반대쪽: 적 중심 몸 뒤 9px(주인공과 겹침) 맞음, 11px·30px 안 맞음.
- 다른 줄: 깊이 차 21px 맞음, 22px·40px 안 맞음.
- 콤보: 서 있는 적을 거리 20px ~ 최대 사거리(원귀 73·도깨비 79)에서 시작해 2px 간격 모두 1→2→3타 명중.
