## 3. H 키 판정 표시
- 노란 상자 끝 = 다음 공격의 판정 끝 = 칼끝(57px). 적 발밑에 **몸 앞쪽 절반 막대**(빨강: 적 중심에서 주인공 쪽으로 w/2)를 새로 그림 — 칼 공격은 이 막대가 상자에 닿으면 맞는다 (앞·뒤 모두 성립: 뒤쪽 판정이 적 중심 기준이라 막대도 중심까지만). 점프 공격·추가타는 예전처럼 적 중심 십자가 상자 안이면 맞는다. **(→ 8절: 막대 길이 = hurtHalfWidth 27)**

- 회귀 측정·테스트는 그대로 유지 (`node tests/run-all.js`, 새 `fists`·`fists-group` 포함 37개 — PR #31 당시. P1 브랜치에서 `sheets` 를 더해 38개 → `docs/p1-pilot.md`). PR #31 은 병합하지 않고 검수 가능한 상태로 둔다. 새 작업은 P1 브랜치.
