# 견적 요청 설명문 (초안 — 오너 승인 전 발송 금지)

아래 글은 픽셀 아티스트에게 견적을 물어볼 때 붙여 넣을 설명문 초안이다. 발송·계약·비용 지출은 오너가 결정한다. `[ ]` 안은 오너가 채운다.

---

## 한국어

안녕하세요, [이름/팀명]입니다. 브라우저용 2D 벨트스크롤 액션 게임 **"조선 퇴마전"**(조선 마을의 밤, 벽사청 검객이 귀물과 싸우는 게임)의 전투 캐릭터 도트 스프라이트 제작 견적을 여쭙고자 연락드립니다.

**1. 이번에 부탁드리는 것: 주인공 '윤무겸' 샘플 6칸**
- 서기 · 걷기 첫 장 · 1타 내려베기 · 3타 준비 · 3타 찌르기 · 3타 회수
- 샘플이 게임에 잘 맞으면 같은 규격으로 나머지(주인공 15칸, 적 2종 각 12칸, 총 약 39칸)를 이어서 의뢰드릴 계획입니다. 이번 견적은 샘플 6칸 기준으로 부탁드립니다.

**2. 규격 요약**
- 2px 도트: 칸 64×64, 게임에서 2배로 보임 (캐릭터 키 약 55칸 = 화면 110px), 오른쪽을 보는 방향, 투명 배경, 반투명 테두리 없이.
- 모든 칸에서 몸 중심·발바닥 위치가 같게.
- 공격 칸은 칼끝 위치 등 정해진 숫자가 있습니다. 칼끝은 몸 중심 앞 56px이고, 3타 칼날은 46~50px입니다. 자세 참고 그림과 기준선을 드립니다.
- 디자인은 저희 공식 캐릭터 설정화(일러스트)를 따릅니다. 도트 색감·표현은 참고 도트 이미지 2장을 따릅니다.

**3. 납품물**
- PNG 스프라이트 시트
- 원본 편집 파일(Aseprite 또는 레이어 PSD)
- 칸 이름표(JSON, 양식 제공)
- 사용한 팔레트

**4. 진행**
- 러프 확인 1회 → 완성본을 저희 게임에 넣어 확인 → 수정(기본 2회) → 승인.

**5. 권리 조건**
- 상업적 이용·수정·2차 제작이 모두 가능해야 합니다. 저작재산권 양도(2차적저작물 작성권 포함) 또는 이에 준하는 독점 이용허락을 희망합니다.
- 포트폴리오 공개 시기와 크레딧 표기는 협의하고 싶습니다.

**6. 여쭙고 싶은 것**
- 샘플 6칸 견적과 작업 기간
- 나머지 약 39칸을 이어서 할 경우의 예상 비용·기간
- 수정 횟수 기준과 추가 수정 비용
- 권리 조건(양도/독점 이용허락) 가능 여부, 포트폴리오 공개 희망 조건
- 이전 작업 중 비슷한 크기(키 100px 안팎) 전투 도트 애니메이션 예시

자세한 명세서와 참고 이미지(설정화 부분 확대)는 회신 주시면 보내드리겠습니다. 감사합니다.

> (내부 메모) 설정화 원본(03·06·07 전체 PNG)은 견적 단계에는 보내지 않고 계약 또는 간단한 비밀유지 합의 뒤에 보내는 것을 추천 — 오너 판단 대기.
