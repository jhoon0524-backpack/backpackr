## 6. 남은 문제
- 지금 윤무겸은 설정화를 기준으로 한 **임시 전투 스프라이트**(약 32칸 키 픽셀 그림)다. 설정화의 얼굴 표정·옷 무늬 수준은 정식 스프라이트가 필요하다. 필요 칸: `docs/sprite-spec.md` 의 14개(+ 잡기용 4개는 없으면 punch·stomp·windup·punch2 칸을 씀).
- **칼 길이 (오너 판단):** (가) 지금처럼 대각선 54px, 사거리 그대로 — 추천 (나) 설정화처럼 더 긴 칼(키의 70%) + 사거리 48→64 같은 전투 조정(제자리 연타·적 멈춤 거리까지 다시 맞추는 큰 작업) (다) 처음의 짧은 수평 찌르기.
- 키: 주인공(111px)이 도깨비(99px)보다 크다. 설정화 비율을 따른 결과인데, 덩치 적이 더 커 보여야 하면 도깨비 그림을 키울 수 있다(판정은 그대로).
- 판정 크기 `h`(주인공 76)는 판정에 안 쓰이고 연출에만 쓰인다(맞을 때 불꽃·파티클 높이, 적 체력바). 그래서 윤무겸이 맞을 때 불꽃이 허리 높이(발 위 49px)에 뜬다. 정식 스프라이트 키가 정해지면 맞출 것.
- **바닥 이음매 (오너 판단 대기):** 06 질감을 좌우로 번갈아 뒤집어 이어서, 이음매 3곳(951px 마다)에 좌우 대칭 바위 무늬가 보인다. (가) 추천: 06 에서 다른 높이의 띠를 하나 더 잘라 두 장을 번갈아(뒤집기 없음) (나) 그대로.
- 원귀·도깨비 선택: 설정화의 귀화는 사람 모양이 아니라 지금 포즈를 못 써서 원귀·도깨비를 골랐다.
- 바닥 질감은 위에서 본 그림이라 원근이 조금 다르다(디딤돌 줄이 경계를 가려 사진상 크지 않음). 고해상도 원본 PNG 는 받지 못했다.
- 타이틀 글꼴은 구글 글꼴에서 받는다(오프라인이면 기본 글꼴, 기존 Press Start 2P 와 같은 의존).
- file:// 로 열면 바닥·시트 그림 때문에 화면 캔버스 픽셀을 읽을 수 없다(브라우저 보안). 지금 게임·측정은 픽셀을 읽지 않아 영향 없음. 나중에 그림 자동 비교는 스크린샷 비교로 해야 한다.
- assets.html 의 설명 글자 일부("먼 빌딩·가게 거리")는 옛 문구.
