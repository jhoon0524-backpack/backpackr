# P1 AI 그래픽 품질 비교 실험 — 보류 기록 (2026-10-28)

오너 지시: 기존 코드 시안(A)과 AI 이미지 생성 후 2px 도트로 보정한 윤무겸(B)을 같은 게임 화면에서 비교(서기·1타 2칸). 외부 유료 서비스·비용 지출 금지, 도구가 없으면 결과를 꾸미지 말고 알릴 것.

| 도구 | 상태 | 판단 |

| Canva 이미지 생성 | 연결됨 | 오너 Canva 계정의 AI 생성 횟수(크레딧)를 쓰며, 무료 범위인지 이 세션에서 확인할 수 없음. 03 설정화를 기준 그림으로 쓰려면 Canva 에 올려야 해 "설정화 원본은 계약·비밀유지 합의 뒤에만 외부로" 결정과 부딪침 |

## 오너 결정 (2026-10-28)
- **AI 생성 없이 보고만.** 이미지를 만들지 않았고, A/B 비교 그림도 만들지 않았다 (꾸민 결과 없음). 실험 브랜치도 만들지 않았다.
- 게임·P1 작업물·원본 에셋·판정·38개 측정은 그대로.

## 나중에 실험할 때 (오너가 직접 만든 AI 이미지를 주는 경우)
1. 오너가 서기·1타 AI 이미지를 올려 주면, 새 실험 브랜치에서 (B1·B2 는 실험 브랜치의 게임 사본에만 끼우고, 본 게임 시트 `data/sprites.js`·`assets/sprites` 에는 넣지 않는다 — CLAUDE.md 5절):
   - B1 = 단순 축소: 배경 제거 → 키 110px(2px 칸 55칸)로 줄이기 → 색 수 줄이기만 (사람 손 없음).
   - B2 = 보정: B1 위에 2px 격자 정리, 외곽선 1칸, 칼끝 56px·발바닥 위치 맞추기, 03 6색 팔레트로 다시 칠하기.
2. A(지금 2px 코드 시안)·B1·B2 를 같은 장면·같은 크기로 PC 1440×900·휴대폰 915×412 사진 비교 (`tools/p1-draft/density-compare.js` 와 같은 방식).
3. `tests/sheets.js`(칼끝 56·발바닥·반투명 0), `tools/p1-draft/tip56-check.js`(칼끝 명중), 38개 회귀.
4. 평가 항목: 설정화 유사도, 얼굴·의상·무기 완성도, 실제 크기 가독성, 칼끝·판정 일치, 다른 공격 칸에서 같은 인물로 그릴 수 있는지(AI 는 칸마다 얼굴·옷이 달라지기 쉬움), 제작 시간·비용.

## 위험 (평가 항목과 별개로 오너가 먼저 정할 것)
- **설정화 원본 반출:** 오너가 직접 생성할 때도 03·06·07 원본(또는 부분 확대)을 외부 생성 서비스에 올리면 "원본은 계약·비밀유지 합의 뒤에만 외부로"(2026-10-28 결정)의 예외가 된다. 글 설명만으로 만들거나, 올린다면 예외임을 오너가 알고 정한다.
- **권리:** AI 생성 이미지는 저작권 보호·양도 대상이 아닐 수 있다. B 방식으로 정식 아트를 가면 발주 명세서 8절·견적 요청문 5절의 "저작재산권 양도" 조건이 그대로 맞지 않으므로 권리 조항을 다시 써야 한다. 생성 도구의 이용 약관(상업적 이용 허용 여부)도 오너가 확인해 함께 알려 준다.
- **표기:** 명세서 8절이 아티스트에게 "이미지 생성 도구 결과 사용 시 사전 고지"를 요구하므로, 우리 쪽 B 결과를 아티스트 참고 자료로 넘길 때도 같은 기준으로 "AI 생성물"임을 표기한다.
