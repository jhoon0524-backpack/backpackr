## 3. 공통 규격
- 투명 배경 PNG(RGBA). 캐릭터 둘레는 완전 투명 또는 완전 불투명만 (반투명 테두리 금지 — 맞을 때 흰 번쩍임이 번짐).
- 오른쪽을 보는 방향만 (왼쪽은 게임이 뒤집음).
- **발 기준점:** 모든 칸에서 몸 중심 가로 위치가 칸 가운데, 발바닥 아래끝이 같은 줄 (2px: 64칸 중 62번째 줄 아래끝 / 1px: 124). 점프 칸도 같은 기준점(높이는 게임이 올림). 쓰러진 칸은 몸이 발바닥 줄에 닿게.
- 칸 배치는 자유. 함께 주는 **칸 이름표(JSON)** 에 칸 이름 → [열, 행].
- 거리·높이는 모두 화면 px (2px 판은 칸 수 × 2) 이고 몸 기준점에서 잰다. 숫자 확인은 우리 쪽 `node tests/sheets.js` 로 한다 (아래 6절).

## 5. 넘겨받을 것
1. 투명 PNG 스프라이트 시트 (캐릭터별 1장).
2. **원본 편집 파일** (Aseprite `.aseprite` 또는 레이어가 살아 있는 `.psd`) — 칸·레이어 구분 유지.
3. **칸 이름표** JSON: `{ "frameW": 64, "frameH": 64, "frames": { "idle0": [0, 0], … } }` (우리 `data/sprites.js` 형식, `docs/sprite-spec.md`).
4. 팔레트 파일 (`.gpl` 또는 색 견본 PNG).
5. HUD 얼굴 영역 좌표 (서기 칸 기준, 21 또는 42px 정사각형 — 정수 배로 커지게).

## 9. 권리 조건 (계약서에 넣을 항목 — 실제 계약 전 법률 검토 권장)
- **상업적 이용·수정·2차 제작**이 모두 가능해야 한다: 게임 출시·광고·굿즈·후속작에 쓰고, 우리가 고치거나 새 동작을 덧그릴 수 있어야 함.
- 권장: 저작재산권 **양도** (또는 기간·지역 제한 없는 독점 이용허락). 한국 저작권법상 양도 계약에 **2차적저작물 작성권**을 따로 적지 않으면 양도에 포함되지 않은 것으로 추정되므로(제45조 제2항) 반드시 명시.
- 저작인격권: 수정·편집에 대해 행사하지 않는다는 특약.
- 원본 편집 파일 포함 인도. 아티스트의 포트폴리오 공개 범위·시기(출시 전 비공개 등)와 크레딧 표기를 합의.
- 다른 저작물·생성 이미지 무단 사용 금지(사용 시 출처·도구 고지)와 그에 대한 보증.
