## 2. 게임에 끼운 방법 (판정·타격감 그대로)
- `data/sprites.js` 에 두 시트를 적음. 시트에 없는 칸(점프·맞음·누움·내려찍기·잡기·점프 공격, 원귀 전부, 도깨비 서기·걷기·달려들기 외)은 지금 코드 그림.
  - 도깨비 달려들기(rush)는 시트의 공격 예고 칸을 씀 (규격대로).
- 3타 전용 칸 이름 2개 추가: 3타 준비 구간 = `kickPrep`, 회수 구간 = `kickRecover` (index.html 그림 이름 고르는 곳만). 시트에 없으면 예전처럼 `windup`·`idle0` 그림 → 코드 그림·밤거리 격투가는 화면이 그대로.
- 칼 든 캐릭터는 잡기·점프 공격 칸이 시트에 없을 때 시트의 칼 든 칸 대신 맨손 코드 그림을 씀 (art.js `frameOf`). 원래 규격대로면 잡는 동안 칼 휘두르는 시트 칸이 보였다.
- 발 높이: 규격(`docs/sprite-spec.md` 시트 규격)대로 발바닥 아래끝을 발 기준점보다 3px 아래로 (`footY` 121, 발바닥 아래끝 124) — 코드 그림과 같은 관례라 칸이 섞이거나 적과 나란히 서도 발이 튀지 않음.
- 시안을 빼려면 `data/sprites.js` 를 `BB_DATA.sprites = {}` 로 (코드 그림으로 돌아감).

## 5. 보이는 것 (자체 관찰, 오너 확인 필요)
- 좋아진 점: 03 의 옷 구성(상투·망토·속자락·술·띠)이 읽히고, 3타가 준비(몸을 뒤로 당기고 왼손으로 겨냥) → 찌르기(앞으로 내딛음) → 회수로 1·2타와 확실히 구분된다.
- 약해진 점: 같은 키에서 지금 코드 그림(굵은 3px 칸·넓은 몸)보다 **몸이 가늘고 작아 보여** 모바일 크기에서 실루엣이 덜 읽힌다. 세밀한 칸(눈·술·장식)은 모바일에서 거의 안 보인다. → 정식 시트에서 몸 폭·명암 대비를 더 키울지 판단 필요.
- 결 섞임: 시트에 없는 동작(점프·맞음·잡기)과 원귀·도깨비 서기는 굵은 코드 그림이라 한 화면에 두 결이 섞인다 (시범 범위라 예상한 것).
- 시안의 한계: 코드로 그린 그림이라 얼굴·손·옷 주름이 단순하고, 07 의 그림 같은 세밀함(재질·주름·광택)에는 못 미친다.

## 5-1. 2026-10-28 오너 결정 반영 (2차)
- 도트 밀도: 윤무겸 서기·1타 2칸만 2px 로 다시 그려 비교 → `docs/p1-density.md`. 1px 시안은 그대로 두고, 최종 결정 전엔 나머지 칸을 만들지 않음.
- 도깨비 4칸: 공격 예고·펀치 + **서기·걷기** 추가. 걷기는 2장(걷기 칸 = 내딛기, 서기 칸)을 번갈아 씀 (`data/sprites.js`: idle0·idle1 = 서기, walk0·walk2 = 내딛기, walk1·walk3 = 서기).
  - 가드 주먹은 코드 그림의 주먹 판정 칸과 같은 자리·크기로 그림: 판정 칸이 시트 그림으로 96~100% 차 있음, 주먹 끝 36px = 판정 칸 끝 36px (idle1 만 코드 판정 칸이 3px 낮아 80%).
  - 주먹 높이 밖의 몸 앞끝 25~26px (판정 hurtHalfWidth 27 ±3 안 — 처음엔 19px 이라 배·짚 치마를 앞으로 키움).
  - 공격 예고 자세를 더 크게 젖힘 (오른 주먹을 머리 위 뒤로). 서기 ↔ 예고 실루엣이 다른 칸 비율: 코드 그림 20% → 시안 40% (예고 ↔ 펀치 30% → 42%).
  - 걷기 → 예고 → 돌진(시트 예고 칸) → 펀치 연속 프레임: `docs/p1/dokkaebi-seq.png` (코드 그림 vs 시안, 2프레임마다). 판정·돌진 거리·공격 타이밍은 그대로 (같은 판에서 거리 102 → 91 → 88·79·66·50·31 → 펀치, 전후 같음).

- 즉시 수정 반영: 오너 PC 실측 조건(1440×900 창 → 게임 1.47배) 비교 추가(`docs/p1/density-pc-window.png`, 1px 선 1·2px 섞임 53:47 / 2px 선 모두 3px), 2px 추천 근거 순서(실제 크기 → PC 비정수 확대 → 칼날·윤곽, 배율 1 은 보조)와 "굵기 가독성만 비교, 얼굴은 둘 다 시안" 명시, 명세서 2px 칼끝 56px·짝수 수치·`footY` 60.5·`idle1` 주먹 3px 낮게·걷기 4장 다른 발, 옛 값 1줄과 작업량 비율 통일.
- 오너 판단: 도깨비 4칸으로는 "서기 → 예고" 읽힘만 판단 가능 — 돌진(rush)은 시트에 칸이 없어 예고 칸이 그대로 미끄러지고, 걷기는 2장 번갈아라 제자리 걸음처럼 보인다. (가) 추천: 이번엔 예고 읽힘만 확인하고 걷기·돌진 연결은 정식 12칸 때 (나) 달려들기 1칸만 더 — 밀도 확정 전 제작 금지와 충돌, 비추천.

## 9. 정식 아트 제작 기준 최종 승인 (2026-10-28 오너)
- 2px 확정, 도깨비 예고 평가 종료(서기 ↔ 예고 구분만, 걷기·돌진은 정식 12칸 때, 추가 임시 칸 없음), 칼끝 56px 승인(판정 57 유지), 윤무겸 샘플 6칸 발주 자료 준비 → `docs/p1-commission/`, 최종 명세서 `docs/p1-art-commission-spec.md`.

  - 1·2·3타 × 좌우 모두 화면 칼끝 56px (카메라 킥 빼고 잼, 좌우 반전에도 같음).

  - 가드 주먹: 3타가 서 있는 도깨비 주먹(56px)에 칼끝이 닿은 채 맞음, 57px 헛침.
  - 사진 `docs/p1/tip56-check.png` (맞는 가장 먼 거리, 좌우).
