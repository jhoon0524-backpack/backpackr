# P1 첫 시범: 정식 스프라이트 시안 + 전투 화면 적용 비교 (2026-10-28)

브랜치 `joseon-p1-sprites` (PR #31 최종 커밋 9322ef4 에서 갈라짐). 오너 지시: 윤무겸 11칸 + 도깨비 2칸, 디자인 기준 03, 세밀한 도트 기준 06·07, 첫 결과물 = 정식 스프라이트 시안 + 기존 전투 화면 적용 비교. 신규 직업·스킬·던전 없음.

## 1. 만든 것
| 대상 | 칸 | 파일 |
|---|---|---|
| 윤무겸 | 서기 1(서기 2장 모두에 씀)·걷기 4·1·2타 준비·1타 내려베기·2타 올려베기·**3타 전용 준비·찌르기·회수** = 11 | `assets/sprites/mugyeom.png` (128×128 칸 × 11) |
| 도깨비 | 공격 예고·펀치 = 2 | `assets/sprites/dokkaebi.png` (128×128 칸 × 2) |
- **누가·어떻게:** Claude 가 코드로 그린 **시안**이다 (`tools/p1-draft/draw.js`, 다시 만들기 `node tools/p1-draft/build.js`). 칸마다 관절 자리를 정하고 부위(도포·망토·속자락·띠·술·머리·칼 등)마다 4단 색(외곽·그림자·바탕·밝은 면)으로 칠했다. 이미지 생성 도구·외부 서비스는 쓰지 않았다. 픽셀 아티스트의 정식 그림이 아니므로 "방향 확인용 시안"으로 본다 (`docs/p1-art-plan.md` 4절 방법 (다)에 해당).
- **해상도:** 화면 1px = 그림 1px (scale 1). 지금 코드 그림(3px 칸)보다 3배 세밀. 키 윤무겸 110px·도깨비 116px.
- **색:** 03 "주요 색상" 6가지(먹색·남청·회갈·주홍·금속·누런 백색) + 07 처럼 어두운 외곽과 3단 명암.
- **03 에서 가져온 것:** 상투와 금속 관·붉은 끈, 얼굴 옆으로 흘러내린 머리, 남청 도포(정강이까지·앞이 갈라져 누런 백색 속자락), 먹색 어깨 망토(해진 끝), 주홍 가슴끈, 가죽 띠와 금속 장식, 주홍 술 두 줄, 가죽 팔토시, 검은 중목 신발, 벽사검(평소 왼허리 칼집, 공격 때 뽑음).
- **07 에서 가져온 것(도깨비):** 붉은 근육 몸, 상아색 뿔, 검은 갈기·수염, 새끼줄 띠와 짚 치마, 방울, 팔·정강이 붕대, 맨발.

## 2. 게임에 끼운 방법 (판정·타격감 그대로)
- `data/sprites.js` 에 두 시트를 적음. 시트에 없는 칸(점프·맞음·누움·내려찍기·잡기·점프 공격, 원귀 전부, 도깨비 서기·걷기·달려들기 외)은 지금 코드 그림.
  - 도깨비 달려들기(rush)는 시트의 공격 예고 칸을 씀 (규격대로).
- 3타 전용 칸 이름 2개 추가: 3타 준비 구간 = `kickPrep`, 회수 구간 = `kickRecover` (index.html 그림 이름 고르는 곳만). 시트에 없으면 예전처럼 `windup`·`idle0` 그림 → 코드 그림·밤거리 격투가는 화면이 그대로.
- 칼 든 캐릭터는 잡기·점프 공격 칸이 시트에 없을 때 시트의 칼 든 칸 대신 맨손 코드 그림을 씀 (art.js `frameOf`). 원래 규격대로면 잡는 동안 칼 휘두르는 시트 칸이 보였다.
- 발 높이: 코드 그림은 발바닥 줄이 바닥선 아래 3px 로 그려져, 시트 기준점을 3px 위(`footY` 121)로 적어 칸이 섞여도 발이 튀지 않게 맞춤.
- 시안을 빼려면 `data/sprites.js` 를 `BB_DATA.sprites = {}` 로 (코드 그림으로 돌아감).

## 5. 보이는 것 (자체 관찰, 오너 확인 필요)
- 좋아진 점: 03 의 옷 구성(상투·망토·속자락·술·띠)이 읽히고, 3타가 준비(몸을 뒤로 당기고 왼손으로 겨냥) → 찌르기(앞으로 내딛음) → 회수로 1·2타와 확실히 구분된다.
- 약해진 점: 같은 키에서 지금 코드 그림(굵은 3px 칸·넓은 몸)보다 **몸이 가늘고 작아 보여** 모바일 크기에서 실루엣이 덜 읽힌다. 세밀한 칸(눈·술·장식)은 모바일에서 거의 안 보인다. → 정식 시트에서 몸 폭·명암 대비를 더 키울지 판단 필요.
- 결 섞임: 시트에 없는 동작(점프·맞음·잡기)과 원귀·도깨비 서기는 굵은 코드 그림이라 한 화면에 두 결이 섞인다 (시범 범위라 예상한 것).
- 시안의 한계: 코드로 그린 그림이라 얼굴·손·옷 주름이 단순하고, 07 의 그림 같은 세밀함(재질·주름·광택)에는 못 미친다.
