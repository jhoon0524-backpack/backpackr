# 6단계 — 구조 정리 (설계·점검표)

## 바꾼 것
| 무엇 | 전 | 후 |
|---|---|---|
| 적 능력치 | index.html `ENEMY_TYPES` | `data/enemies.js` (`BB_DATA.enemies`). 숫자 그대로 + `art`(art.js 그림 이름), `knockdown`(맞으면 주인공이 넘어지는지) 추가 |
| 웨이브 구성 | index.html `WAVES` | `data/waves.js` (`BB_DATA.waves`), 숫자 그대로 |
| 타격감 | index.html `FEEL` | `data/feel.js` (`BB_DATA.feel`), 숫자 그대로 |
| "brute 면 넘어짐" | `e.type === 'brute'` | `e.knockdown` |
| 적 그림 | `ART.characters[f.type]` | `ART.characters[f.art]` |
| 무작위 | `Math.random` 3곳 (적 등장 깊이, 파티클, 적 공격 간격) | 시드 고정 난수 `rng()` 1개 (mulberry32, 시드 20261027) |

- 데이터 파일 모양: 첫 줄들은 설명, `BB_DATA.xxx =` 뒤는 JSON 과 같은 모양(따옴표 붙은 이름). 더블클릭·링크 둘 다 동작 (오너 결정 2026-10-27).
- index.html 안의 이름(`ENEMY_TYPES`·`WAVES`·`FEEL`)은 데이터 파일 내용을 가리키게만 바꿈 → 나머지 코드 그대로.
- 적 종류 늘리는 법: `data/enemies.js` 에 한 줄 + `data/waves.js` 에 이름. 그림은 art.js 에 있는 것(thug·brute) 중에서 고른다. 새 색·새 모양은 art.js 수정이 필요하다(이번 단계 범위 밖).
- 흔들림: 이미 무작위가 아닌 카메라 킥(규칙 4)이라 바꿀 것 없음.
- 소리 잡음(Math.random)은 그대로: 판에 영향이 없고, 시드 난수를 쓰면 소리를 켜고 끄는 것만으로 판이 달라진다.
- `KILL_FLASH_MULT`(처치 번쩍임 2배)도 `data/feel.js` 의 `killFlashMult` 로 (director 지적, CLAUDE.md 2번 "타격감 수치는 FEEL 한 곳").
- 데이터 이름 오타 점검: 페이지를 열 때 waves.js 의 적 이름이 enemies.js 에 있는지, enemies.js 의 그림 이름이 art.js 에 있는지 확인해 틀리면 어느 파일 어느 이름인지 알림창 (director 지적: 없으면 웨이브 시작 순간 화면이 말없이 굳음).
- 주의: 파티클도 같은 난수를 쓰므로, 나중에 파티클 개수만 바꿔도 그 뒤 적 등장 깊이·공격 간격 순서가 통째로 바뀐다 (같은 입력이면 같은 판이라는 성질은 유지).

## 상태 겹침 점검표 (새 상태값: `rngState`)
| 항목 | 내용 |
|---|---|
| 설정·초기화 | `reset()` 끝에서 `rngState = RNG_SEED`. reset 은 페이지 처음 열 때, 타이틀·게임오버·클리어에서 Enter(탭) 할 때 |
| 바뀌는 곳 | `rng()` 를 부를 때만: 웨이브 시작 때 적마다 1번(깊이), 파티클 1개마다 3번, 적이 공격 준비를 시작할 때 1번(다음 공격 간격) |
| 공격 중(콤보) | 맞을 때 파티클 → 같은 입력이면 같은 순서로 부름 |
| 점프·피격·다운 | rng 를 따로 쓰지 않음. 파티클·공격 간격만 위와 같이 |
| 히트스톱 | 멈춘 적은 공격 준비를 안 하므로 rng 도 안 부름 → 같은 입력이면 같음 |
| 적끼리 겹침 밀기 | rng 안 씀 |
| 게임오버·클리어 | Enter 로 다시 시작할 때 reset → 같은 시드부터. 이 화면에서는 판 갱신(파티클 포함) 안 함 |
| 타이틀 | 판 갱신 안 함, rng 안 씀 |
| 전체화면·가로세로·터치 여부 | 그림 배치만 바뀜, rng 안 씀 |
| 소리(M)·진동 | rng 안 씀 → 켜고 꺼도 같은 판 |
| F 타격감 강제 | 맞는 결과가 달라져 다른 판이 되지만, 같은 입력·같은 F 면 같은 판 |
| G 0.25배속 | 1초에 도는 횟수만 바뀜. 한 번 돌 때의 순서는 같음 |
| 데이터 이름 오타 | 페이지를 열 때 1번 점검, 틀리면 알림창. 판 갱신·rng 와 무관 |
| 위치·카메라 바꾸는 줄 | 이번 단계에서 새로 만들거나 바꾼 줄 없음 (적 등장 깊이 `y` 1곳만 값 출처가 rng 로 바뀜) |
