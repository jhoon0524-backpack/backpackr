# 잡아 던지기 단계 — 설계와 상태 겹침 점검표

오너 결정(2026-10-27): 적에게 붙어 앞으로 밀면 잡기, 잡은 상태에서 Z = 무릎치기, 점프 버튼 = 던지기. 4단계 뒤 별도 단계.
숫자는 `index.html` 의 `GRAB` 한 곳. 그림은 기존 포즈만 쓴다(잡기 = punch, 무릎 = stomp, 던지기 = windup → punch2, 잡힌 적 = hurt).

## 동작
1. **잡기**: 서 있는 적(다운·공중·기상 무적·공격 준비 중이 아님, 화면 안) 앞 34px 안에서 그 적 쪽으로 8프레임 계속 밀면 잡는다. 미는 동안 적과 24px보다 가까워지지 않는다(몸에 막힘). 경직 중인 적(맞고 휘청)도 잡을 수 있다 → 1·2타 뒤 밀어서 잡기.
2. **잡은 상태**: 적은 주인공 앞 24px에 붙들려 hurt 포즈. 주인공은 걷지 못한다. 최대 100프레임(약 1.7초) 지나면 적이 빠져나간다(서로 조금 밀려남).
3. **무릎치기 (Z)**: 준비 4 / 타격 3 / 회수 8프레임. 1·2번째 데미지 8 normal, 3번째 데미지 12 heavy(넘어뜨리며 놓음). 회수 중 누른 Z·점프는 기억했다가 바로 이어서.
4. **던지기 (점프 버튼)**: 방향키를 누르고 있으면 그쪽, 아니면 보는 쪽으로. 준비 6프레임(windup) 뒤 놓는다. 적은 위로 튀어 날아가고(가로 첫 속도 9, 남는 비율 0.92, 높이 속도 7) 착지할 때 데미지 20 + heavy 손맛("쿵"). 날아가는 동안 부딪힌 다른 적은 데미지 10 + heavy로 넘어진다(적마다 1번).
