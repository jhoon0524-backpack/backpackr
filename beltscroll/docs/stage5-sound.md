# 5단계 — 소리 비교 설계와 상태 겹침 점검표

지시(plan.md 5단계): WebAudio로 합성한 타격음 1종(normal·heavy 피치·길이만 다르게). 기본 꺼짐, `M` 키로 켜고 끈다. 오디오 파일을 쓰지 않는다.
실무자 추가: 휴대폰엔 M 키가 없어 전체화면 버튼 옆에 소리 버튼(🔇/🔊) 1개. 켤 때 확인용으로 normal 타격음 1번.

## 소리 (숫자는 `index.html` 의 `SOUND` 한 곳)
- 구성(1종): 낮은 사인파 "퍽"(음높이가 빠르게 떨어짐) + 짧은 잡음 "탁"(음높이에 맞춘 대역 필터). 시작 2ms 만에 최대, 지수로 사라짐.
- normal: 음높이 220Hz, 길이 0.09초 / heavy: 음높이 110Hz, 길이 0.20초. 그 밖의 값은 같다.
- 어떤 타격이 어떤 소리인지는 타격감(`FEEL`)을 따른다 → `impact()` 한 곳에서 낸다. F 키로 타격감을 강제하면 소리도 따라간다.

## 진동 (오너 요청, 2026-10-27)
- 휴대폰 진동 1종. 약타격 12ms 한 번, 강타격 35ms 한 번, 주인공이 맞을 때 35ms(오너 결정, 때릴 때와 구분). 길이만 다름. 숫자는 `HAPTIC` 한 곳.
- 기본 꺼짐. 소리 버튼 옆 진동 버튼(📳). 켤 때 확인 진동 1번. 휴대폰·태블릿에서만 버튼이 보이고, 그중 진동을 지원하지 않는 브라우저(아이폰 사파리)에선 숨김.
- 타격 순간 `impact()` 에서 소리와 같은 방식으로 모아 두고 프레임 끝에 가장 센 것 1번.

| 새 상태 | 설정 / 진행 / 비움 | 그 상태 중 입력 | 겹침 처리 | 증명 |
|---|---|---|---|---|
| 진동 켜짐 `debug.vibe` | 진동 버튼 / — / 다시 누르면 꺼짐. 재시작해도 유지 | 게임 입력과 무관 | 소리와 독립(소리 비교 실험은 진동 끈 채로) / 타이틀·게임오버에서도 전환됨 / 버튼 누른 뒤 blur | vibe #1, #2 |
| 이번 프레임 진동 `pendingVibe` | 타격 순간 모으기(이미 heavy면 그대로) / update() 끝에서 1번 내고 비움 / reset() 에서도 비움 | — | 순서 상관없이 가장 센 것 1번 / 프레임 번호를 저장하지 않아 재시작 영향 없음 | vibe #3 |
| 진동 버튼 위치·표시 | 소리 버튼 왼쪽. 전체화면 버튼이 없으면 한 칸씩 오른쪽으로 | 탭 | 게임 화면 안 / 터치 전용 기기(hover 없음·손가락 포인터)에서만 보임, 그중 진동 API 가 없으면(아이폰) 숨김. PC 크롬·터치 노트북은 API 가 있어도 숨김 | vibe #4, vibe2 |

## 5단계 후속: 소리 기본 켜짐 + 효과음 4종 (오너 결정, 2026-10-27)
- 소리 기본 켜짐. 브라우저는 사용자 입력 전에는 소리를 못 내게 하므로, 첫 키 누름·첫 탭에서 오디오 장치를 만들고 깨운다. 휴대폰은 손가락을 누를 때(pointerdown)가 아니라 뗄 때(pointerup·click)에 허락하므로 세 사건 모두에서 깨운다(자동 재생 규칙을 켠 실제 조건으로 측정: sfx2). 그 전의 타격은 무음(타이틀 화면이라 실제로는 없음).
- 효과음 4종 (모두 코드 합성, `SOUND` 한 곳): 휘두름 "휙"(헛스윙일 때만, 잡음이 높은 음→낮은 음으로), 잡기 "턱"(짧고 높은 퍽), 던진 적 착지 "쿵"(타격음보다 낮고 긴 퍽), 적 쓰러짐(사라지는 순간 내려가는 음).
- 한 프레임에 소리 1개, 우선순위: 쿵 > 강타격 > 쓰러짐 > 잡기 > 약타격 > 휙.

| 새 상태 | 설정 / 진행 / 비움 | 그 상태 중 입력 | 겹침 처리 | 증명 |
|---|---|---|---|---|
| 소리 기본 켜짐 `debug.sound=true` | 페이지 로드 / — / M·버튼으로 끔 | — | 오디오 장치는 첫 keydown·pointerdown·pointerup·click 에서 생성·깨움(그 전엔 소리가 안 남. 휴대폰은 첫 탭을 뗄 때 running) / 버튼 첫 표시 🔊 / 소리 버튼을 첫 탭으로 누르면 장치 생성과 끄기가 같은 탭에서 일어남 → 장치는 만들되 꺼짐 | sfx #1, #2 |
| 이번 프레임 소리 `pendingSound` (우선순위) | 각 사건에서 모으기 / update 끝 1번 / reset | — | 순서 무관 최댓값 / 재시작 영향 없음 | sfx #3~#6 |
| 휙 | 땅 공격·추가타 판정에서 아무도 안 맞음 | — | 맞으면 타격음만 / 점프 공격 헛방은 소리 없음 | sfx #3 |
| 턱 | 잡기 시작 | — | 같은 프레임 Z 대기 입력과 무관 | sfx #4 |
| 쿵 | 던진 적 착지 | — | 같은 프레임 강타격음 대신 쿵 | sfx #5 |
| 쓰러짐 | 처치된 적(체력 0, 다운 중)이 공중에서 바닥에 닿는 프레임 (오너 결정으로 사라지는 순간에서 옮김) | — | 던져 처치하면 쿵만 (착지 순간엔 아직 체력이 남아 쓰러짐이 쌓이지 않음) / 누워 있는 적을 추가타로 처치하면 바닥에 이미 있어 쓰러짐 소리 없이 강타격음만 / 사라질 때는 소리 없음 | ko |
