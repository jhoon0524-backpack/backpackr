# B5 걷기 다시 받기 — AI 요청문 (오너가 할 일, 2026-11-05)

오너 결정(2026-11-05 "좋아" = 추천 (가)): 지난번 GIF 의 걷기 3장(2·3·4번)은 같은 다리가 계속 앞이라 다리가 엇갈리지 않음 → 같은 AI 도구로 **걷기 한 바퀴**를 다시 받는다. 이 작업 환경엔 이미지 생성 도구가 없어 Claude 는 요청문만 준비한다. **AI 생성물** 표기, 비용은 오너의 기존 이용 범위 안에서만.

## 첨부할 것
- 지난번 GIF (`assets/reference/ai-sprite-gif/mugyeom-anim-15.gif`) 또는 그 0번 서기 장 — 같은 인물·같은 크기 기준

## 요청문 (그대로 붙여 넣기) — 걷기
```
첨부한 캐릭터(윤무겸)와 완전히 같은 인물·같은 그림체·같은 크기·같은 캔버스로, 오른쪽으로 걷는 "걷기 한 바퀴" 픽셀아트 애니메이션을 만들어 줘.
- 장 수: 8장 (6장도 괜찮음). 첫 장과 마지막 장이 자연스럽게 이어져 반복되게.
- 한 바퀴 안에 왼발이 앞으로 나가는 걸음과 오른발이 앞으로 나가는 걸음이 둘 다 있어야 해. 두 다리가 서로 엇갈려 지나가는 장면(다리 모음)도 넣어 줘.
- 걸을 때 몸이 살짝 오르내리고, 도포 자락·망토·머리카락이 걸음에 맞춰 흔들리게.
- 칼은 칼집에 꽂힌 채 왼손으로 칼집을 쥔다. 칼집은 검은색·짙은 남청색이고 금속 장식만 금색.
- 첨부 그림과 같은 키(발바닥~머리끝 약 298픽셀), 같은 캔버스(402×324), 같은 바닥 높이(모든 장의 발바닥이 같은 줄).
- 모든 장에서 몸통(허리)이 캔버스 가로 같은 자리에 있게 (제자리 걷기처럼 — 게임이 앞으로 옮겨 그림).
- 배경 투명, 베기 이펙트·잔상·먼지·그림자·글자 없이.
- GIF 한 개로 주거나, 장마다 PNG 로 줘.
```
- 받은 그림은 원본 그대로 이 대화에 올려 주면 된다. Claude 가 B5 와 같은 배율·칼집 보정으로 2px 로 바꿔 시험판 걷기에 넣는다 (`tools/ai-pilot/b5.py`).

## 받은 뒤 확인 4가지 (Claude)
1. 장마다 앞발이 왼발/오른발 중 어느 쪽인지 — 한 바퀴에 둘 다 나와야 함 (같은 다리만 앞이면 다시 요청)
2. 발밑 덩어리 수: 벌린 장 2 → 모은 장 1 → 벌린 장 2 (`report` 의 feet_blobs 와 같은 식)
3. 키 약 298px·캔버스 402×324·발바닥 줄 같음, 장마다 허리 가로 자리 차이(px)
4. 시험판 걷기 칸 수: 지금 B5 시험판은 걷기 4칸 순환(`b4_build.js` b5, 20px) — 받은 장 수(6·8)대로 순환 칸 수와 간격을 코드에서 바꿈

## (선택) 3타 찌르기 1장 요청문 — 오너가 3타 (나)를 고르면
```
첨부한 캐릭터와 같은 인물·그림체·크기·캔버스(402×324)로, 앞으로 한 걸음 내딛으며 칼을 수평으로 찌르는 순간 1장을 만들어 줘.
- 두 손은 몸 앞 가까이(가슴~배 앞), 칼은 곧은 칼로 수평. 칼날 길이는 캐릭터 키의 40% 남짓.
- 몸통(허리)은 서기 장과 캔버스 가로 같은 자리이거나 조금 앞, 앞발을 내딛고 상체가 앞으로 기울게.
- 칼집은 검은색·짙은 남청색, 금속 장식만 금색. 배경 투명, 이펙트·잔상·그림자 없이.
```
