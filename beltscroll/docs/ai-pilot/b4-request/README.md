# B4 — ChatGPT 로 윤무겸 준비·1타 새로 만들기 (오너가 할 일)

이 작업 환경에는 ChatGPT(이미지 생성)가 없어 Claude 가 그림을 만들 수 없다. 오너가 ChatGPT 에서 아래대로 만들어 이 대화에 올려 주면, Claude 가 2px 로 다듬고 연속 재생(GIF)으로 검수한다. 비용: 오너의 기존 ChatGPT 이용 범위 안에서만 (추가 결제 없이).
**AI 생성물** — 아티스트에게 넘길 때는 "AI 생성물"로 표기. 상업적 이용은 ChatGPT 약관을 오너가 확인 (`docs/p1-ai-experiment.md` 위험 절).

## 1. 올릴 참고 그림 (ChatGPT 에 첨부)
1. `ref-idle-dark-scabbard.png` — 디자인 기준 서기 (AI 원본 서기에서 칼집만 검은색·짙은 남청색, 금속 장식만 금색으로 바꿈)
2. (선택) `assets/reference/ai-sprite-pilot/reference_contact_sheet.png` — 같은 그림체의 동작 15장 (자세 참고. 칼집·칼 색은 1번을 따르라고 요청문에 적혀 있음)
- `b4-target-guide.png` 는 ChatGPT 에 안 올려도 된다 — 받은 그림을 오너·Claude 가 확인할 때 쓰는 목표선 (파랑 = 바닥·몸 중심, 초록 = 키 110, 노랑 = 공격 칸 최저 키 100, 빨강 = 1타 칼끝 목표: 앞 56·높이 31)

## 2. 요청문 (그대로 복사해 붙여 넣기 — 한 번에 한 자세씩 두 번)

**① 준비 자세**
```
첨부한 캐릭터(윤무겸)와 완전히 같은 인물·같은 그림체·같은 크기로, 내려베기 직전의 "준비 자세" 픽셀아트 한 장을 만들어 줘.
- 얼굴, 상투와 금장식, 남청 도포, 흰 소매, 검은 망토, 주홍 띠, 체형, 칼을 첨부 그림과 똑같이. 옷 디자인을 바꾸지 마.
- 칼: 곧은 외날, 금색 코등이, 검은 손잡이, 주홍 매듭. 칼집은 검은색·짙은 남청색이고 금속 장식만 금색. 칼집은 허리 왼쪽에 빈 채로 매달려 있다.
- 몸 쓰기: 뒷발에 체중을 싣고 무릎을 조금 굽힌다. 몸통을 뒤로 틀어 등이 조금 더 보이게, 앞 어깨가 올라가고 뒤 어깨는 내려간다. 두 손으로 칼을 잡아 어깨 위로 끌어올리고 칼날은 머리 뒤쪽으로 눕혀 뒤를 향한다.
- 칼끝과 손이 머리 꼭대기보다 높이 올라가지 않게 한다.
- 도포 자락과 망토는 몸을 튼 방향의 반대로 살짝 휘날린다.
- 오른쪽을 보는 옆모습(첨부와 같은 각도), 발끝부터 머리끝·칼끝까지 잘리지 않게 전신, 배경은 투명 또는 한 가지 단색.
- 베기 이펙트·잔상·속도선·먼지·그림자·글자 넣지 마.
- 캐릭터 키(발바닥~머리끝)는 첨부 그림과 같은 픽셀 크기로.
```

**② 1타 (내려베기 순간)**
```
첨부한 캐릭터(윤무겸)와 완전히 같은 인물·같은 그림체·같은 크기로, 앞의 준비 자세에서 이어지는 "내려베기가 막 끝나는 순간" 픽셀아트 한 장을 만들어 줘.
- 얼굴, 상투와 금장식, 남청 도포, 흰 소매, 검은 망토, 주홍 띠, 체형, 칼을 첨부 그림과 똑같이. 옷 디자인을 바꾸지 마.
- 칼: 곧은 외날, 금색 코등이, 검은 손잡이, 주홍 매듭. 칼집은 검은색·짙은 남청색이고 금속 장식만 금색, 허리 왼쪽에 빈 채로 매달려 있다.
- 몸 쓰기: 앞발을 크게 앞으로 내딛고 체중이 앞발로 넘어간다. 몸통이 앞으로 돌아오며 살짝 숙인다(깊게 웅크리지 않는다 — 머리 높이는 서 있을 때의 90% 이상). 두 팔을 앞아래로 뻗어 두 손으로 칼을 잡는다.
- 칼: 손은 가슴 높이 앞, 칼날은 앞아래로 약 40도. 칼끝은 앞으로 내딛은 앞발 발끝보다 발 하나 길이쯤 더 앞, 높이는 무릎 높이 정도(바닥에서 캐릭터 키의 약 28%).
- 도포 자락과 망토는 앞으로 내딛은 힘 때문에 뒤로 끌리듯 휘날린다.
- 오른쪽을 보는 옆모습(첨부와 같은 각도), 발끝부터 머리끝·칼끝까지 잘리지 않게 전신, 배경은 투명 또는 한 가지 단색.
- 베기 이펙트·잔상·초승달 궤적·속도선·먼지·그림자·글자 넣지 마.
- 캐릭터 크기는 첨부 그림과 같은 픽셀 크기로.
```
- 마음에 드는 것이 안 나오면 "같은 요청으로 2~3장 더"를 눌러 후보를 여러 장 받아도 된다 (자세마다 2~3장 추천 — Claude 가 수치·연결이 맞는 것을 골라 보고).
- 받은 그림은 **원본 그대로** (잘라 내거나 줄이지 말고) 이 대화에 올려 주면 된다. 파일 이름에 자세(준비/1타)를 적어 주면 좋다.

## 3. 받은 뒤 Claude 가 하는 일
- 크기·디자인 확인(서기와 같은 인물·같은 크기·칼집 색), 이웃 조각·반투명 정리, 이펙트가 섞였으면 떼어 냄.
- 서기와 **같은 배율**로 2px(64×64, scale 2)로 줄이고 보정 — 키 110(공격 칸 100~110), 1타 칼끝 56(판정 57)·칼끝 높이 31. 늘려서 키를 맞추지 않는다. 칼끝이 조금 어긋나면 칼날만 같은 칼 모양으로 다듬는다(몸 자세는 그대로).
- 몸 기준점(게임 속 위치)은 B3 와 같은 규칙(두 발 가운데)으로 잡되, 앞발 내딛기로 기준점이 앞으로 쏠려 서기→1타에서 몸이 미끄러져 보이면 뒷발·엉덩이 기준으로 바꾸고 그 사실을 표에 적는다. 칼끝 56 은 이 기준점에서 잰다.
- 서기 칸은 B3 서기에 칼집 색만 바꿔 B4 서기로. 세 칸 모두 칼집 색 같게.
- 서기 → 준비 → 1타 연속 재생 GIF(실제 속도·느린 판)와 PC·폰 같은 장면 비교 → director 검수 → 보고. 합격 기준 1순위는 "몸을 써서 베는 느낌".
- 받은 그림이 기준(같은 인물·전신·이펙트 없음)을 못 맞추면 그대로 보고하고 다시 요청할 점을 적어 드린다 — 억지로 맞춘 결과를 만들지 않는다.
