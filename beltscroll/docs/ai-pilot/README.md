# 윤무겸 AI 스프라이트 적용 실험 (2026-11-04)

브랜치 `experiment/mugyeom-ai-sprites` (`joseon-p1-sprites` 29bd5e6 에서 갈라짐). 오너가 ChatGPT 로 만든 윤무겸 스프라이트 시트·동작 15장을 2px 규격(64×64, scale 2, 키 110px, 칼끝 56px·판정 57px)으로 옮겨 기존 코드 시안과 같은 전투 화면에서 비교. 서기·1타 2칸만 (→ 7절 B3 는 서기·준비·1타 3칸, 8-1~8-3절 B4 는 오너 지시로 Claude 가 몸 쓰는 준비·1타·걷기 4·점프·맞음·점프 공격 10칸을 직접 그림, 8-1~8-7절).
본 게임 시트·전투 코드·판정·타격감·기존 브랜치·배포 링크는 그대로 (비교는 `tests/out/ai-pilot/game-*` 게임 사본에서).
