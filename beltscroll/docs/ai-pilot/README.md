# 윤무겸 AI 스프라이트 적용 실험 (2026-11-04)

브랜치 `experiment/mugyeom-ai-sprites` (`joseon-p1-sprites` 29bd5e6 에서 갈라짐). 오너가 ChatGPT 로 만든 윤무겸 스프라이트 시트·동작 15장을 2px 규격(64×64, scale 2, 키 110px, 칼끝 56px·판정 57px)으로 옮겨 기존 코드 시안과 같은 전투 화면에서 비교. 서기·1타 2칸만.
본 게임 시트·전투 코드·판정·타격감·기존 브랜치·배포 링크는 그대로 (비교는 `tests/out/ai-pilot/game-*` 게임 사본에서).

## 2. AI 원본 15장 일관성 검사 (`tools/ai-pilot/analyze.py`, 그림 `docs/ai-pilot/consistency.png` — 분홍 = 몸통과 떨어진 조각)
| 항목 | 결과 |
|---|---|
| 같은 인물로 보이나 | **예** — 상투와 금장식, 얼굴, 남청 도포, 흰 소매·바지, 검은 망토, 주홍 끈이 15장 모두 같다. 색 비율도 비슷하다 (남청 11~20%, 주홍 2~4%) |
| 크기 | 서 있는 컷(서기·걷기) 키 286~302px — 최대 5% 차. 컷마다 칸 크기·발 위치가 달라 그대로는 못 씀 → 변환 때 서기 키 기준 **같은 배율** + 발 기준 다시 맞춤 |
| 무기 | **불일치** — 06·07·10 은 크게 휜 칼, 09·12·13 은 거의 곧은 칼. 칼 길이도 컷마다 다름. 칼집은 금색(03 은 검은 칼집) |
| 잘린 부분 | 06 오른끝에 07 이펙트 조각, 07 왼쪽 위 06 조각·오른끝에서 칼날이 잘림·오른 아래 이웃 신발 조각, 08 왼쪽에 07 이펙트 조각, 11·13·14 작은 조각 (떨어진 조각 15px 이상: 6장) |
| 투명도 | 가장자리 반투명 칸 장당 약 1.2만~2.5만 px, 몸통 안쪽도 알파 250~254 (완전 불투명 아님) → 게임 규격(0/255) 아님, 변환에서 50% 로 자름 |
| 03 설정화와의 차이 | 흰 소매가 크게 부풀고 흰 바지가 보임(03 은 남청 소매·팔토시, 흰색은 속자락만), 어깨 망토 대신 땅까지 닿는 긴 검은 망토, 금색 칼집. 상투 금장식·주홍 끈·남청 도포는 03 과 같음 |
