# 텀블벅 트렌드 룰렛 스킬

키워드를 넣으면 슬롯머신이 돌아가며 **2025~2026 트렌드 심층 분석**을 뽑아주는 Cowork 아티팩트를 생성합니다.

## 아티팩트 구성

아티팩트 ID: `action-item-roulette`

출력 섹션:
1. **시장 모멘텀** — 성장률, 시장 규모, 성수기
2. **배경 & 트렌드 (2025–2026)** — 6개 카드 (검색·SNS·커머스·소비자·글로벌·경쟁강도)
3. **연관 키워드 & 해시태그** — 핵심 + 연관 키워드
4. **2026 전망** — AI 분석 기반 아웃룩

## 아티팩트 생성/업데이트 방법

### 기존 아티팩트가 있는 경우
`mcp__cowork__update_artifact`로 아래 HTML을 업데이트합니다.

### 새로 만드는 경우
`mcp__cowork__create_artifact`로 아래 HTML로 생성합니다:
- id: `action-item-roulette`
- title: `텀블벅 트렌드 룰렛`
- description: `텀블벅 키워드 트렌드 심층 분석 룰렛 — 2025-2026 시장 데이터 기반`

## 아티팩트 HTML 전문

사용자 요청 시 아래 HTML 전체를 아티팩트로 생성/업데이트하세요.

## 수정 요청 대응

- **섹션 추가 요청** (예: "레퍼런스 다시 넣어줘"): askClaude 프롬프트에 해당 필드 추가 후 아티팩트 HTML 업데이트

- **키워드 추가 요청** (예시 버튼): `.exs` 섹션의 예시 chip 추가
