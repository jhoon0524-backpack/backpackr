# 다음 3년 카테고리 가설 검증

> CORE 연결: 미연결 (CORE.md 미작성 — 작성 시 "카테고리 로테이션이 GMV를 만든다" 진단에 연결 예정)
> 상태: 활성
> 최종 갱신: 2026-08-02

가설: "한복(~2022) → 니치향수(~2023) → 보드게임(현재)처럼, 다음 3년을 끌어갈 카테고리가 존재하며 미리 찾을 수 있다."

## 1. 현황 (Facts)

- 연간 GMV(약정): 2021 388억 → **2022 644억(정점)** → 2023 626억 → 2024 654억 → 2025 522억 → 2026E ~445억 (텀블벅 2026 상반기 진단, 2026-07-13)
- 26H1 카테고리 로테이션: 게임 +49.9%(63.5억)·만화 +22.4% vs 패션 −41.2%·문구/굿즈 −35.4%·리빙 −32.3%. 게임은 와디즈가 −16%(3.9억)로 사실상 무주공산 (같은 문서)
- 한복 붐의 경로가 내부 문서로 확인됨: 와디즈 선행 검증(2019 억대 프로젝트) → 텀블벅 내 서브컬처 변형으로 사례 축적 → 인바운드 억대 브레이크스루(청현 장저고리, 언님팩토리 마고자) → 탑티어(리슬·하플리) 영입 → 2022 전통기획전 15억 확산 (텀블벅 한복 트렌드 히스토리, 2023-06)
- 향수 붐은 신규 유입 없는 붐이었음: 첫 후원자 비중 전체 대비 **−15.3%p**, 기존 후원자 풀 내 소비. 프로젝트 수 급증 시 다음 분기 프로젝트당 후원자·성사액 감소(카니발) 확인 (향수 카테고리 현황, 2023-06)
- 키링: 이미 만개한 트렌드 시점 진입 → 보부상 키링 기획전 16개 프로젝트 성과 2,700만 원으로 실패. 과공급·저단가 판정 (트렌드-키링, 2024)
- 주의(교란변수): 2022 정점에는 광고선전비 25.5억(역대 최대)이 동반 — 정점을 순수 카테고리 효과로 읽지 말 것 (2026 상반기 진단 P&L)
- 실물 카테고리는 와디즈 프리오더/커머스로 구조 이탈 중(리빙: 텀블벅 −32% vs 와디즈 +52%), 최소 2년째 지속되는 구조 (같은 문서)

## 2. 옵션 공간 (Options)

- **[채택 제안] 후향 검증 우선**: ① 붐 조작적 정의(예: 12개월 이동합 성사액 YoY +100% & 연 30억 도달) ② 과거 붐 6~8개(한복·향수·보드게임 + 뜨개·키링·키캡 미니붐)의 T-12~18개월 선행 신호 코딩 ③ 지속기간을 가르는 판별 변수 분석. 약 2주, 기존 데이터만으로 가능
- **[대기] 전향 검증**: 후보 워치리스트 분기 스코어링(외부 검색량·인바운드 수·억대 돌파·첫후원자 비중) + 상위 후보에 한복 플레이북 적용, 홀드아웃 비교 — H2 통과 후 착수
- **[폐기] "이미 만개한 외부 트렌드 추격" 소싱 기준** — 폐기 사유: 키링 기획전 실패 사례(과공급·저단가·팬덤 사이즈 한계). 대체 기준 = "타 플랫폼에서 억대로 검증됐는데 텀블벅에는 아직 없는 창작 카테고리" (한복이 정확히 이 패턴: 와디즈 2019 → 텀블벅 2021-22)

## 3. 핵심 가정 (Assumptions)

- H1 (패턴 존재): 3년짜리 붐에는 공통 선행 패턴이 있다 — 외부 검증 → 사례 축적 → 억대 브레이크스루 → 기획전·영입 확산 [미검증, 등록 2026-08-02 — 한복은 부합하나 n=1]
- H2 (판별 가능성): 3년형(한복)과 1년형(향수·키링)을 초기에 가르는 지표는 **붐 초기 신규(첫)후원자 비중**이다 [미검증, 등록 2026-08-02 — 한복 vs 향수 대조 1쌍뿐]
- H3 (재현 가능성): 아웃리치 개입(컨설팅→S급 영입→기획전)으로 다음 붐을 앞당길 수 있다 [미검증, 등록 2026-08-02]
- 다음 붐은 실물이 아니라 창작·IP 계열(게임 하위 장르, 만화 연계, 팬덤 실물)에서 나온다 — 실물은 와디즈 커머스로 구조 이탈 [미검증, 등록 2026-08-02]
