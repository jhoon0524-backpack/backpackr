# 전략 문서 스킬

PO 에이전트 범위 밖이라 `.claude/skills/`에 두지 않는다 (2026-08-02 결정).
스킬이 나빠서가 아니라 PO 산출물이 아니어서다.

`po/README.md`의 정보별 소유자 표에서 "개별 프로젝트 상태·결정"의 소유자가
이 스킬이므로, 폐기하지 않고 여기로 옮겨 기능을 살려둔다.

쓰려면 `~/.claude/skills/`로 복사하거나 별도 저장소로 옮긴다.
`.claude/skills/`로 되돌리려면 그것은 2026-08-02 결정을 뒤집는 것이므로
`po/context/decisions.md`에 기록한다.
