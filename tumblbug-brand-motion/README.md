# 텀블벅 브랜드 모션그래픽

홍보용 20초 브랜드 영상입니다 (1920×1080, 30fps, MP4, 무음).

- 완성 영상: `tumblbug-brand-motion.mp4`
- 원본(애니메이션): `motion.html` — 브라우저로 열면 첫 화면이 보입니다
- 영상 변환 스크립트: `render.js`

## 구성 (스토리보드)

| 시간 | 장면 | 문구 |
|---|---|---|
| 0–3초 | 빨간 점(아이디어)이 톡 등장하고 파동이 퍼짐 | 작은 아이디어 하나가 |
| 3–6.5초 | 사방에서 색색의 점(후원자)이 모여들며 점이 커짐 | 함께하는 마음을 만나 |
| 6.5–10초 | 펀딩 게이지가 0% → 100% 차오르고 축하 폭죽 | 현실이 됩니다 |
| 10–14.5초 | 밝은 배경으로 전환, 카테고리 카드 8개가 튀어나옴 | 모든 창작이 시작되는 곳 |
| 14.5–20초 | 브랜드 컬러로 화면이 채워지고 워드마크 등장 | tumblbug / 크리에이터를 위한 크라우드펀딩 / tumblbug.com |

## 수정하는 법

- 문구: `motion.html` 안의 한글 문장을 바꾸면 됩니다.
- 브랜드 컬러: `motion.html` 맨 위 `--brand` 값.
- 로고: 현재는 글자로 만든 워드마크입니다. 공식 로고 파일로 바꾸려면 `#logo` 부분을 이미지로 교체하세요.
- 다시 영상 만들기: `node render.js` (필요: Node.js, `playwright-core`, ffmpeg, Noto Sans CJK KR 폰트)
