# DESIGN — 무엇을 만드는가

> **기획 원본은 `MyAIGame/GAME_SPEC.md` 다.** 이 파일은 요약과 이정표만 담는다.
> 내용이 어긋나면 GAME_SPEC.md 가 맞다. (같은 내용을 두 곳에 적으면 반드시 어긋난다)

## 만들려는 것

**펀딩몬 (가칭)** — Godot 4 기반 2D 탑다운 수집형 턴제 RPG (포켓몬 스타일).
세상에 떠도는 '아이디어 생명체(아이디)'를 후원해 내 편으로 만들고,
펀딩 대결로 키워 지역 보스를 꺾으며 나아가는 게임. 스팀 출시 수준의 완성도 지향.

## 만들지 않는 것

- GAME_SPEC.md 에 없는 기능·시스템 (루프가 임의로 추가 금지)
- 어두운 연출, 죽음·패널티 요소 (톤앤매너: 가볍고 밝게)
- MyAIGame/ 폴더 밖의 어떤 변경도 이 루프의 범위가 아니다

## 기술 선택과 이유

- **Godot 4 (Compatibility 렌더러)** — 2D 픽셀 게임에 충분하고 무료·경량이라
- **픽셀 아트 640x360 기준** — 규격·팔레트는 `MyAIGame/ART_SPEC.md` 가 유일 기준
- **문서 기반 기억** — 세부 설계는 `BATTLE_FLOW.md`(전투), `IDI_DEX.md`(도감) 참조
