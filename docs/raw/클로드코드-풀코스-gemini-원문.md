### STEP 1. 개발 환경 세팅 & 프로젝트 헌법(CLAUDE.md) 만들기

순서대로 작업 공간을 세팅하고 AI의 지침서 역할을 하는 CLAUDE.md 파일까지 생성하는 과정입니다.

**1. VS Code 및 클로드 코드 확장 프로그램 설치**
- 웹 브라우저에서 **Visual Studio Code(VS Code)**를 검색해 다운로드 후 설치합니다.
- VS Code 실행 후 왼쪽 블록 아이콘(Extensions)을 클릭합니다.
- 검색창에 Claude Code를 입력하여 Claude Code for VS Code를 설치하고 로그인합니다.

**2. 작업 폴더 열기 및 패널 확인**
- VS Code 상단 메뉴에서 File > Open Folder를 선택하여 새 작업 폴더(예: my-ai-agent)를 만들어 열어줍니다.
- 화면 우측에 위치한 Claude AI 패널 하단에서 작업 모드를 Plan 모드로 설정합니다 (Shift + Tab 키로 전환 가능).

**3. CLAUDE.md 파일 생성**
- 폴더 최상단에 CLAUDE.md라는 이름의 파일을 만듭니다.
- 이 파일은 AI의 업무 SOP(표준 운영 절차)입니다. 아래 양식을 복사하여 붙여넣습니다.

```markdown
# 프로젝트 규칙 (CLAUDE.md)

## 역할
당신은 사업가의 업무를 돕는 AI 신입사원입니다.

## 업무 워크플로우 (SOP)
1. 요청을 받으면 실행 계획(Plan)을 먼저 작성합니다.
2. 파이썬 스크립트나 필요한 도구(Tool)를 활용해 작업을 수행합니다.
3. 작업 완료 후 문제점을 스스로 점검하고 테스트합니다.

## 보안 규칙
- API 키 등 민감한 정보는 절대 코드에 직접 적지 않고 `.env` 파일로 관리합니다.
```

**4. 프로젝트 초기화 명령 실행**
- 오른쪽 Claude 패널에 다음과 같이 입력하고 엔터를 누릅니다:
  "CLAUDE.md 파일 구조를 읽고 프로젝트를 초기화해 줘."

*(이미지: Obsidian 노드 간 연결 시각화. 출처: Reddit)*

### STEP 2. 옵시디언(Obsidian) 지식 관리 시스템 (LLM Wiki) 구축

외부 정보(Raw)를 수집하고, AI를 통해 내 사업에 꼭 필요한 정제된 지식(Wiki)으로 변환하는 가이드입니다.

**1. Obsidian 및 폴더 연동** — 로컬 디렉토리 기반 지식 저장소 구축
- Obsidian 공식 홈페이지에서 프로그램을 다운로드하여 설치합니다.
- Obsidian 실행 후 "Open folder as vault"(보관소로 폴더 열기)를 클릭하고, STEP 1에서 만든 VS Code 작업 폴더를 선택합니다.

**2. Raw / Wiki 폴더 및 커스텀 프롬프트 설정**
- VS Code의 Claude 패널에 아래 명령을 입력하여 지식 관리 폴더 구조를 자동 작성하게 합니다:
  "내 사업 지식을 정제할 수 있도록 /Raw 폴더와 /Wiki 폴더를 생성하고, 안드레 카파시의 LLM Wiki 패턴을 기반으로 /Raw 문서를 읽어 /Wiki로 정제하는 프롬프트를 세팅해 줘."

**3. 슬래시 커스텀 명령어 사용법**
세팅이 완료되면 생성된 단축 명령어를 사용해 다음과 같이 정보를 처리합니다:
- /ingest : Raw 폴더의 수집 자료(유튜브 대본, 아티클 등)를 읽어 중요한 내용만 추출 후 Wiki 문서로 변환.
- /query : Wiki에 누적된 내 사업 데이터에서 필요한 인사이트만 검색·큐레이션.
- /lint : 오래되었거나 구조가 어긋난 지식 노트를 자동 정돈 및 진단.

### STEP 3. 클로드 코드 토큰 절약 및 효율적 운용 5가지 수칙

클로드 코드 사용 시 토큰 한도 초과 및 비용 낭비를 방지하기 위한 핵심 운용 가이드입니다.

- **/context 사용량 주기적 확인**: 대화 패널에 /context를 입력하여 현재 컨텍스트 사용량을 확인합니다. 60~70%에 도달하면 대화를 리셋할 준비를 합니다.
- **수동 세션 정리 후 /clear**: /compact를 사용하면 AI가 지친 상태에서 중요한 내용을 누락할 수 있습니다. 대신 아래 메시지를 보낸 후 요약본을 복사하고 /clear로 새 세션을 시작하세요.
  "지금까지 진행된 내용 중 (1) 결정된 것 (2) 아직 안 정해진 것 (3) 다음 할 일을 요약해서 메모리로 정리해 줘."
- **CLAUDE.md 다이어트**: CLAUDE.md 파일은 세션 시작 시 매번 로딩되므로 200줄 이하로 가볍게 유지하고, 상세 규칙은 별도의 서브 MD 파일(예: feedback_guide.md)로 분리합니다.
- **마크다운(MD)으로 변환 후 투입**: PDF, HTML 등 원본 형식은 토큰 소비가 큽니다. Web2MD나 무자비한 텍스트 변환기를 통해 .md 파일로 변환한 뒤 Claude에게 전달하세요 (최대 90% 토큰 절감).
- **작업 취소 시 /rewind 활용**: AI가 지시를 잘못 이해하고 코드를 꼬아놓았을 때는 말을 이어가지 말고 ESC 키를 두 번 누르거나 /rewind를 입력해 정상 동작했던 이전 시점으로 되돌립니다.
