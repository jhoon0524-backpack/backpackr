# 규칙·지시서 변경 이력

loop/PROMPT.md 나 MyAIGame/CLAUDE.md 의 규칙, 또는 스킬 문서를 고칠 때마다
아래에 한 항목씩 추가(append)한다. **채택뿐 아니라 기각된 변경도 반드시 남긴다** —
"해봤는데 안 됐다"가 남아 있어야 같은 제안이 반복되지 않는다.
**절대 지우거나 리셋하지 않는다.**

형식:

## YYYY-MM-DD · 대상 파일
- 변경 요약: 무엇을 어떻게 바꾸려 했는가
- 근거: 어떤 패턴(docs/wiki/patterns.md 항목명)에서 나왔는가
- 결과: 채택 / 기각 — 사유 (검증했다면 전/후 결과 포함)
