# 패턴 카탈로그 (지식층)

루프가 겪은 실패 모드와 성공 전략을 쌓는 문서다.
**절대 지우거나 리셋하지 않는다.** 항목은 아래로 계속 추가(append)만 한다.
여기 쌓인 패턴이 2회 이상 반복 확인되면 그때 MyAIGame/CLAUDE.md 의
[QA 규칙 목록]이나 loop/PROMPT.md ③의 규칙으로 승격한다.

형식 (항목 하나 = 실패 모드 하나 또는 성공 전략 하나):

## [패턴 이름]
- 현상: 언제 이 패턴이 나타나는가
- 근거: 어떤 실행에서 관찰됐는가 (로그 날짜·커밋·태스크명 인용)
- 대응: 실행 가능한 구체적 해법 또는 회피법
- 반복 횟수: 1회 (2회째 확인되면 승격 검토)
