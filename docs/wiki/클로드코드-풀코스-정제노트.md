# 클로드 코드 풀코스 정제 노트

> 원문(Raw)은 [[클로드코드-풀코스-gemini-원문]]. 이 노트는 그 내용을 "텀블벅 사업총괄이 비개발자로서 바로 쓸 수 있는가"를 기준으로 걸러낸 것이다.

## 한 줄 요약

클로드 코드는 "채팅"이 아니라 "내 폴더에서 일하는 AI 직원"이다. 직원에게 매뉴얼(CLAUDE.md)을 주고, 반복 업무는 스킬로 굳히고, 지식은 Raw→Wiki로 정제하고, 정기 업무는 클라우드 루틴에 맡긴다.

## 지금 우리 상황과의 연결

| 영상 내용 | 우리 저장소 / 환경에서의 현재 상태 |
|---|---|
| CLAUDE.md = 프로젝트 헌법 | 이미 있음. 루트 `CLAUDE.md` + `agent-starter/CLAUDE.md` |
| 서브 에이전트 MD 분리 | 이미 있음. `agent-starter/.claude/agents/` (deep-reasoner, runner) |
| Raw / Wiki 지식층 | 이 노트가 첫 적용. 예전 `docs/wiki/`는 ai-loop-kit 저장소로 이사함 |
| 클라우드 루틴(Routines) | 사용 가능. 이 저장소로 여는 클라우드 세션에서 Gmail·캘린더·드라이브·슬랙·노션 커넥터가 이미 연결되어 있음 |
| GWS CLI (구글 워크스페이스 CLI) | 클라우드 세션에는 불필요. 커넥터가 같은 역할. 로컬 VS Code에서 쓸 때만 검토 |
| 스킬(Skill Creator 등) | Skill Creator는 이미 설치되어 있음. 나머지는 아래 "도입 후보" 참고 |

## 바로 적용할 것 (우선순위 순)

1. **정기 업무는 클라우드 루틴으로.** 영상의 "매일 8시 트렌드 수집 → 카톡/메일 발송" 시연은 우리 환경에서 그대로 가능하다. 후보: 주간 텀블벅 카테고리 트렌드 메일, 주요 창작자 문의 요약.
2. **Raw → Wiki 습관.** 영상·아티클·뉴스레터는 원문을 `docs/raw/`에 그대로 두고, 우리 기준으로 걸러낸 것만 `docs/wiki/`에 쓴다. 이 노트가 예시.
3. **세션 리셋 습관.** 컨텍스트 사용량이 60~70%가 되면 "결정된 것 / 안 정해진 것 / 다음 할 일"을 정리시킨 뒤 새 세션을 연다. 자동 압축(/compact)보다 정확하다는 주장인데, 우리 경험과도 맞다.
4. **큰 문서는 마크다운으로 바꿔서 투입.** PDF·HTML보다 .md/.txt가 토큰을 훨씬 덜 쓴다. 절감률 숫자(최대 90%)는 검증되지 않은 수치이므로 "많이 준다" 정도로만 받아들인다.

## 원문에서 걸러낸 것 (그대로 믿지 말 것)

- **"클로드 코드는 Pro 이상 구독 필수"**: 구독 없이 API 종량제로도 쓸 수 있다. 다만 사업 용도라면 구독이 관리가 쉽다.
- **"CLAUDE.md 200줄 이하"**: 공식 기준이 아니라 영상 제작자의 경험 규칙이다. 방향(짧게, 세부는 분리)만 취한다.
- **"MD 변환 시 최대 90% 절감"**: 출처 불명 수치.
- **에이전트 팀(Agent Teams)**: 여러 AI가 서로 대화하며 개발하는 기능. 파일 20개 미만 소규모에는 단일 에이전트가 낫다는 영상 자체의 조언대로, 우리 실험 규모에서는 당분간 불필요.
- **GWS CLI**: 로컬 환경용 도구. 클라우드 세션의 커넥터로 대체 가능하므로, 이 저장소 기준으로는 우선순위 낮음.
