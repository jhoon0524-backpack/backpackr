# 텀블벅 공급 갱신 구조 · 북극성 지표 검증 분석 지시서

> 이 문서는 Superset에 연결된 Claude Code에 그대로 전달해 실행하는 분석 지시서다.
> 배경: 장기 창작자(데이오프) 이탈 → 증분 가치 → 북극성 지표 → "텀블벅은 공급을 계속 갱신해야 하는 마켓플레이스" 논의에서 나온 가설을 데이터로 검증한다.

---

## 0. 작업 규칙 (먼저 읽을 것)

1. **읽기 전용.** SELECT만 사용한다. 테이블·뷰 생성, 수정, 삭제 금지.
2. **스키마부터 확인.** 분석 전에 아래 "필요 데이터"에 해당하는 테이블·컬럼을 찾아 표로 정리하고, 정의가 애매하면 가정을 명시한다. 찾지 못한 데이터는 지어내지 말고 "데이터 없음"으로 보고한다.
3. **기간.** 2024-01 ~ 2026-10 (완결된 월만). 2026년은 10개월치이므로 연간 비교는 반드시 **전년 동월** 또는 **1~10월 누적**끼리 비교한다.
4. **제외 대상.** 테스트·내부 계정, 취소·환불 완료 후원, 비공개 처리된 프로젝트. 제외 기준과 제외 건수를 함께 보고한다.
5. **결과물.** 분석별로 ① 사용한 SQL ② 결과 CSV ③ 핵심 숫자 3줄 요약 ④ 데이터 품질 이슈. 마지막에 전체 요약 1페이지.
6. **해석 주의.** 시간적 선후나 상관관계만으로 인과를 단정하지 않는다. "~와 함께 움직였다", "~가 먼저 감소했다"로 쓴다.

## 1. 공통 정의

| 용어 | 정의 |
|---|---|
| 성사 후원 | 성사된 프로젝트의 결제 완료 후원. **프로젝트·후원자 쌍당 1건**으로 집계 |
| 집계 월 | 최종 성과는 **펀딩 종료월** 기준. (운영 참고용으로 약정 발생일 기준도 병기 가능) |
| 창작자 | 프로젝트를 공개한 계정(또는 창작자 ID). 동일 창작자 판별 기준을 명시할 것 |
| 카테고리 | 프로젝트 1차 카테고리 |
| 후원 유형 ① | 해당 후원이 그 후원자의 **텀블벅 생애 첫 후원** |
| 후원 유형 ② | 텀블벅 기존 후원자이지만 **해당 창작자에게는 첫 후원** |
| 후원 유형 ③ | 해당 창작자에게 **이전에 후원한 적 있는** 후원자 |
| 진행 중 프로젝트 | 특정 날짜에 펀딩 기간(시작일 ≤ 날짜 ≤ 종료일)에 있는 공개 프로젝트 |
| 발견 매력도 | 공개 후 **첫 7일** 동안, 상세 페이지 방문자 중 ①·② 유형으로 후원한 비율. 상세 방문자 최소 100명 이상 프로젝트만 산출 |
| 재방문 매력도 | 해당 창작자의 기존 후원자(③ 대상자) 중 이번 프로젝트에 후원한 비율 |
| 매력 프로젝트 | 같은 카테고리·같은 분기 안에서 발견 매력도 **상위 30%** 또는 재방문 매력도 상위 30%. (기준은 민감도 확인용으로 20%/40%도 산출) |
| 탐색 기원 후원 | 외부 링크로 프로젝트에 바로 들어와 한 후원이 아니라, **텀블벅 홈·탐색·카테고리·검색·기획전**에서 시작된 세션의 후원 |

> 상세 페이지 방문, 유입 경로는 DB가 아니라 로그·분석 도구 데이터일 수 있다. Superset에서 접근 불가하면 해당 지표는 "데이터 없음"으로 두고, 대체 가능한 근사치(예: UTM, referrer)를 제안만 한다.

## 2. 분석 목록 (우선순위 순)

### 분석 1. 공급 갱신 구조 — 공급이 먼저 줄었나, 수요가 먼저 줄었나
**질문:** 매력적인 프로젝트 공급이 줄어 후원자가 줄었는가, 후원자가 줄어 매력 프로젝트가 줄었는가?

카테고리별 × 월별로 산출:

| 지표 | 비고 |
|---|---|
| 신규 공개 프로젝트 수 | |
| 일평균 진행 중 프로젝트 수 | |
| 일평균 진행 중 **매력** 프로젝트 수 | 정의 1 참고 |
| 주간 신규 공개 매력 프로젝트 수의 **주별 편차**(표준편차/평균) | 공급 신선도·고르기 |
| 홈·탐색 직접 방문자 수 | 플랫폼 기대(수요) 신호 |
| 외부 → 프로젝트 직행 방문자 수 | 공급(창작자 외부 홍보) 신호 |
| 월간 성사 후원 건수 | 북극성 지표 후보 |
| GMV(성사 약정액) | 기준선 |

출력:
- 각 지표의 **전년 동월 대비 증감률** 시계열
- 2025→2026 하락 구간에서 **어느 지표가 먼저 꺾였는지** 카테고리별 표
- 카테고리 간 비교: 공급이 크게 변한 카테고리에서 홈·탐색 방문이 따라 움직였는지

### 분석 2. 탐색 기원 후원 비중 — 플랫폼 자체의 경쟁력
**질문:** 텀블벅은 "특정 프로젝트를 보러 오는 곳"에서 "무엇이 있는지 보러 오는 곳"으로 가고 있는가, 멀어지고 있는가?

- 월별·카테고리별: 성사 후원 중 탐색 기원 후원 비중
- 후원 유형(①②③)별로 나눠서도 산출

### 분석 3. 북극성 지표 후보 비교
**질문:** 새 지표가 기존 지표와 다른 정보를 주는가?

월별로 다음을 산출하고 상관계수 및 함께 그린 차트:
- 성사 후원 건수 (프로젝트·후원자 쌍)
- 원시 후원 건수 (중복 포함)
- 월간 창작자·후원자 고유 쌍 수
- 순 후원자 수
- 성사 프로젝트 수
- GMV

추가로 성사 후원 건수를 ①②③으로 분해한 월별 추이 (③은 12개월 이동합계도 병기).

### 분석 4. 후원자 코호트 — 관계·발견이 미래 거래를 만드는가
**질문:** 첫해에 여러 창작자·카테고리를 경험한 후원자가 이듬해 더 많이, 더 오래 후원하는가?

- 코호트: 첫 후원 연도 2024, 2025
- 첫 후원 후 12개월 동안: 후원한 **서로 다른 창작자 수**, **서로 다른 카테고리 수**
- 그다음 12개월의 후원 여부(리텐션), 후원 건수, 후원액
- 구간별(1 / 2 / 3~4 / 5+) 표. 첫 12개월 총 후원액이 비슷한 사람끼리 비교한 버전도 함께 (많이 쓰는 사람이라서 다양하게 후원한 효과를 분리)

### 분석 5. 다음 후원 패턴 — 후원자는 무엇 때문에 돌아오는가 (관측 행동)
**질문:** 후원 다음의 후원은 어떤 유형인가?

모든 성사 후원에 대해 그 후원자의 **다음 후원**을 다음 셋으로 분류:
1. 같은 창작자의 다른 프로젝트
2. 다른 창작자, 같은 카테고리
3. 다른 창작자, 다른 카테고리
(+ 다음 후원 없음 / 관측 기간 부족은 별도)

유형별: 후원자 수, 후원 건수, 후원액, 다음 후원까지 걸린 일수(중앙값). 연도별 변화도 산출.

> 이건 행동 관측이지 동기 확정이 아님. 결론에 그렇게 명시할 것.

### 분석 6. 성숙 창작자의 수요 측 기여
**질문:** 장기 창작자는 GMV 외에 후원자를 데려오는 통로 역할을 하는가?

- 성숙 창작자: 첫 공개 후 3년 이상 + 성사 프로젝트 3회 이상 (기준 명시)
- 성숙 창작자 프로젝트별: ① 유형(생애 첫 후원자) 수
- 그 ① 후원자들이 이후 12개월 동안 **다른 창작자**에게 후원한 건수·금액
- 같은 카테고리의 비성숙 창작자와 비교

### 분석 7. 성숙 창작자 이탈 규모
**질문:** 성공한 창작자가 실제로 더 많이 떠나고 있는가?

- 창작자 활동 연차 × 과거 성사 약정액 등급별
- 마지막 프로젝트 종료 후 **12개월 / 18개월 / 24개월** 내 재공개율
- 같은 조건의 과거 집단(예: 2022~2023년 기준)과 비교
- 재공개하지 않은 상위 30명 목록(창작자 ID, 카테고리, 마지막 프로젝트, 누적 약정액) → 졸업/활동 중단 여부는 사람이 수기로 확인

### 분석 8. 습관적 방문의 기준선
**질문:** "무엇이 있는지 보러 오는 후원자"는 지금 얼마나 되는가?

- 연 2회 이상 후원한 후원자 중, 그 해 후원 중 하나라도 탐색 기원 후원이 있는 사람의 비율 (2024, 2025, 2026 1~10월)

## 3. 보류 (이번 범위 밖)

- 배송 지연과 재후원율 비교: 지연이 무작위가 아니므로 상품 유형·규모·창작자 역량을 맞춘 비교 설계가 필요. 별도 진행.
- 증분 거래액(플랫폼이 없었다면 생기지 않았을 거래액) 추정: 위 결과를 본 뒤 설계.

## 4. 최종 요약에 담을 것

1. 분석 1의 결론: 공급·수요 중 무엇이 먼저 꺾였나 (카테고리별)
2. 분석 2·8: 탐색 기원 후원 비중의 추이와 현재 기준선
3. 분석 3: 북극성 지표 후보 중 단순한 쪽으로 충분한지
4. 분석 4·5·6: 발견·관계가 미래 거래를 만드는지에 대한 증거 강도
5. 분석 7: 성숙 창작자 이탈이 구조적 확대인지 개별 사례인지
6. 데이터로 답하지 못한 질문과 필요한 추가 데이터
