- [x] 스키마 정의 2 — `requests`(의뢰 내용·참고 링크·상태 6종·기본가/최종가·마감일·전달물·거절 사유), 대기 의뢰 1인 1건 인덱스

## [기능]
- [ ] 카카오 로그인 연동 (Supabase Auth) — `lib/session.ts` 만 바꾸고 사용자 전환기 제거 **(Auth 필요)**
- [x] 커미션 열기 폼과 검증 (`/open`)
- [x] 커미션 열기/닫기 (`/me`)
- [x] 의뢰 보내기 — 닫힘·자리 없음·내 커미션·중복 의뢰를 사유별 문구로 (`/commissions/[id]`)
- [x] 수락(최종가 조정)·거절(사유 필수) (`/requests/[id]`)
- [x] 전달(주소 또는 메모)·완료 확정·취소 (`/requests/[id]`)
- [ ] 이미지 업로드 — Supabase Storage **(Storage 필요)**. 지금은 주소 입력
- [ ] 알림 — 의뢰 도착·수락·전달·완료 4종 (카카오 알림톡 또는 메일) **(외부 API 키 필요)**
- [x] 메뉴 고치기 — 제목·분류·안내·가격·기간·동시 진행·샘플. **주소는 그대로**라 이미 보낸 링크가 산다.
      동시 진행 건수는 지금 진행 중인 건수보다 작게 못 줄인다 (`__tests__/db/update_commission.test.ts`)
- [x] 텀블벅 펀딩 이력 표시 자리 — 후원자 수·만족도(의뢰인) / 팔로워(창작자 본인). **값은 아직 더미다**
- [ ] 텀블벅 펀딩 이력 **실연동** — 지금은 `profiles` 의 더미 열이다. 본 서비스에서 채우거나 조회해야 한다 **(텀블벅 DB 접근 필요)**
- [ ] 확인 필요: 만족도가 창작자 단위로 합산 가능한가 / 응답 수가 30 이상인 창작자가 몇 명인가 (모수가 작으면 이 차별점이 성립하지 않는다)
- [ ] "메뉴를 붙이면 팔로워 N명에게 알림" — 알림 기능이 붙어야 참이 되는 약속. 그 전까지 화면에 쓰지 않는다
