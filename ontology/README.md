# 텀블벅 온톨로지 (자동 학습)

매일 아침 슬랙을 훑어서 **회사 지식을 스스로 쌓아가는 지식 지도**입니다.
사람이 채워 넣는 위키가 아니라, 대화에서 자동으로 자라납니다.

## 어디를 보면 되나요

| 보고 싶은 것 | 파일 |
|---|---|
| 전체 현황 한눈에 | [views/index.md](views/index.md) |
| 누가 뭘 하는지 | [views/people.md](views/people.md) |
| 프로젝트·제품 | [views/projects.md](views/projects.md) |
| 사내 용어·지표 | [views/terms.md](views/terms.md) |
| **의사결정 타임라인** | [views/decisions.md](views/decisions.md) |
| **이슈 목록** | [views/issues.md](views/issues.md) |
| 어제 무슨 일이 있었나 | `daily/YYYY-MM-DD.md` |

`views/` 아래 파일은 **자동 생성됩니다. 직접 고치지 마세요** (다음 날 덮어써집니다).

## 어떻게 "스스로 학습"하나요

```
매일 아침 7:20 (KST)
  → 슬랙 35개 채널의 지난 하루 대화를 읽고
  → 사람 / 조직 / 프로젝트 / 용어 / 지표 / 의사결정 / 이슈 를 뽑아내서
  → 기존 지식과 합치고 (같은 대상이면 id 로 합쳐집니다)
  → 확신도를 올리고
  → 사람이 읽을 요약을 만들고
  → 저장소에 커밋합니다
```

핵심은 **확신도**입니다.

- 처음 발견하면 `0.40` (🟡 추정)
- 다른 날 또 확인되면 올라갑니다 (0.55 → 0.66 → 0.75…)
- `0.75` 넘으면 ✅ 확정. 이때부터 믿고 인용해도 되는 정보입니다.
- 90일 넘게 안 나오면 🕸️ 오래됨 — **지우지는 않습니다.** 과거 사실도 지식이니까요.

즉, 자주 이야기되는 것일수록 확실해지고, 한 번 스친 것은 추정으로 남습니다.
사람이 정답을 입력하지 않아도 시간이 지날수록 정확해집니다.

## 틀린 걸 발견했을 때

`corrections.md` 에 **한국어로 그냥 적으면 됩니다.** 형식 안 맞아도 됩니다.
다음 날 아침 에이전트가 읽고 반영합니다. 사람이 적은 정정은 슬랙 추론보다 항상 우선합니다.

```markdown
- [ ] 2026-09-03: "소상공인지원사업"의 리드는 A가 아니라 B입니다.
- [ ] 2026-09-03: "BOC"는 회의체 이름이 아니라 목표 수립 제도입니다.
```

## 어떤 채널을 보나요

`config.json` 에 있습니다. 지금은 업무 채널 35개(g_, project_, svc_, tf_ 등)만 봅니다.
바꾸려면 `enabled` 를 `true`/`false` 로 고치거나 채널을 추가하면 됩니다.

**비공개(private) 채널은 기본으로 꺼져 있습니다.** (`g_leader`,
`project_bpk_growth_committee`) 슬랙 내용 요약이 이 저장소에 남기 때문입니다.
저장소를 볼 수 있는 사람 범위를 확인한 뒤 `enabled: true` 로 켜세요.

## 안전장치

- 슬랙 **원문은 저장하지 않습니다.** 근거 인용은 한 줄(120자)까지만.
- 개인 평가·인사·급여·건강 정보는 스키마상 수집 대상이 아닙니다.
- 지식은 지워지지 않고 `stale` 로만 표시되므로 이력이 남습니다.
- 모든 변경은 git 커밋으로 남아 "어제 대비 뭐가 늘었나"를 추적할 수 있습니다.

## 자동 실행 끄기 / 바꾸기

claude.ai 의 **Routines** 목록에서 `텀블벅 온톨로지 데일리 학습` 을 끄거나 시간을 바꿉니다.

## 파일 구조

```
ontology/
  README.md        ← 지금 보는 문서
  SCHEMA.md        ← 무엇을 어떻게 담을지 정한 규칙
  RUNBOOK.md       ← 매일 아침 에이전트가 따르는 절차
  corrections.md   ← 사람이 정정을 적는 곳
  config.json      ← 스캔 대상 채널
  state.json       ← 채널별 마지막 스캔 지점 (자동)
  ontology.json    ← 누적 지식 그래프 (기계용, 자동)
  daily/           ← 날짜별 델타(.json) + 사람용 요약(.md)
  views/           ← 사람이 읽는 화면 (자동 생성)
  tools/ontology.py← 병합·렌더 도구
```
