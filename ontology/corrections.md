# 정정 노트

온톨로지에서 틀린 걸 발견하면 여기에 **한국어로 그냥 적으세요.** 형식은 자유입니다.
다음 날 아침 학습 에이전트가 읽고 반영한 뒤 `- [x]` 로 체크합니다.
사람이 적은 정정은 슬랙에서 추론한 내용보다 **항상 우선**합니다.

예시:
```
- [ ] 2026-09-03: "소상공인지원사업"의 리드는 A가 아니라 B입니다.
- [ ] 2026-09-03: "그로스위원회"와 "성장위원회"는 같은 조직입니다. 합쳐주세요.
- [ ] 2026-09-03: "프리오더"는 제품이 아니라 기능입니다. type을 product로 두되 텀블벅의 하위로 연결해주세요.
```
